02

Cookie Security Attributes

Security-sensitive cookies should be configured carefully. The following attributes are commonly important in production web applications.

Attribute Purpose
Secure Sends the cookie only over HTTPS connections.
HttpOnly Prevents JavaScript from directly accessing the cookie.
SameSite Controls cookie sending behavior in cross-site contexts.
Max-Age Defines how long the cookie should remain valid.
