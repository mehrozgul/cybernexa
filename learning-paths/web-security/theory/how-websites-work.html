01

What is a Website?

Core Definition

A website is a collection of web resources that users access through a web browser. These resources may include HTML documents, CSS stylesheets, JavaScript files, images, APIs and data generated by a server-side application.

02

Basic Website Request Flow

When a user enters a website address, the browser communicates with different components to retrieve and display the requested content.

STEP 01

Browser

The user enters a URL and the browser prepares a request for the website.

STEP 02

DNS

DNS helps resolve the domain name to an IP address.

STEP 03

Web Server

The server receives the request and determines how to respond.

STEP 04

Response

The browser receives the response and renders the website for the user.

03

Modern Website Architecture

04

Role of Architecture Components

CLIENT
The browser runs on the user's device and interprets HTML, CSS and JavaScript to create the visible web interface.
DNS
The Domain Name System translates human-readable domain names into IP addresses used for network communication.
WEB SERVER
Receives HTTP requests and returns static resources or forwards dynamic requests to application components.
APPLICATION
Processes business rules, authentication, authorization, validation and application functionality.
DATABASE
Stores application information such as user accounts, products, messages and other persistent data.
05

HTTP Request & Response

HTTP is an application-layer protocol used for communication between a client and a web server. A browser sends an HTTP request and the server returns an HTTP response.

06

Frontend vs Backend

Web applications are commonly divided into frontend and backend responsibilities. The frontend is primarily responsible for the user interface, while the backend handles server-side processing and data operations.

FRONTEND
HTML → Structure
CSS → Presentation
JavaScript → Interaction
BACKEND
Server → Request Processing
Application → Business Logic
Database → Data Storage
07

Why Website Architecture Matters to Security

Every component in a web architecture can introduce security risks. Understanding how data moves between components is therefore fundamental to web security.

🛡 WEB SECURITY CONNECTION

Security testing examines how browsers, servers, applications and databases interact. Weak input validation, insecure authentication, incorrect authorization or unsafe data handling can create vulnerabilities across these layers.

08

Key Terms

URL

The address used to identify and access a resource on the web.

DNS

Resolves domain names into IP addresses.

HTTP

Application-layer protocol used for web communication.

HTTPS

HTTP protected using TLS to provide encrypted communication.

Client

A device or application that requests a service or resource.

Server

A system that receives requests and provides services or resources.

Module Summary

Understand the Architecture. Understand the Attack Surface.

A modern website is more than a single HTML page. The browser, DNS, web server, application layer and database work together to deliver web functionality. Understanding this architecture provides the foundation for learning HTTP, authentication, SQL injection, XSS, CSRF and other web security concepts.
