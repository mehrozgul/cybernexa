01

What is Scanning?

Core Definition

Scanning is the process of examining an authorized network, system or application environment to discover reachable hosts, available services, communication endpoints and other technical information that can help a security professional understand the target.

02

Why Scanning Matters

A security tester needs an accurate picture of the authorized environment before assessing vulnerabilities. Scanning helps transform an unknown environment into a structured set of observable technical information.

The results can help identify unnecessary services, unexpected exposure, configuration issues and areas that require further security assessment.

✓

03

Major Types of Scanning

Scanning can focus on different types of information. In professional assessments, the exact technique depends on the objective and the approved scope.

TYPE 01

Host Discovery

Determines which authorized systems appear reachable within the testing environment.

TYPE 02

Port Scanning

Examines communication ports to determine which services may be accessible.

TYPE 03

Service Detection

Attempts to determine what service is associated with an accessible communication point.

TYPE 04

Version Detection

Helps identify software or service versions when the authorized environment permits such analysis.

TYPE 05

Configuration Review

Examines discovered services and configurations for potential security concerns.

TYPE 06

Vulnerability Scanning

Uses security assessment tools to identify potentially vulnerable components.

04

Important Scanning Concepts

🔎
Host Discovery Finding systems that are reachable within the authorized scope.
🔌
Ports Logical communication endpoints used by network services.
⚙
Services Applications or processes that provide network functionality.
📊
Scan Results Technical observations that require interpretation rather than automatic classification as vulnerabilities.
05

Authorization and Scope

Scanning can generate network traffic and may affect systems depending on the technique and intensity used. Therefore, security professionals must establish the permitted scope before scanning.

⚠ AUTHORIZED ENVIRONMENT ONLY

Perform scanning only against systems you own or systems for which you have explicit permission. For learning, use local virtual machines, dedicated cybersecurity labs, CTF environments or intentionally vulnerable training systems.

06

Professional Scanning Workflow

A professional tester normally follows a controlled sequence instead of immediately scanning everything.

AUTHORIZED SCANNING WORKFLOW

First, confirm authorization and scope. Next, identify approved systems, examine relevant communication points, collect service information, review the results and document observations. Findings can then be passed to the vulnerability assessment stage.

07

Key Terms

Host

A device or system connected to a network.

Port

A logical communication endpoint associated with network communication.

Service

A network-accessible application or process providing a specific function.

Scan

A systematic examination of an authorized environment to collect technical information.

Module Summary

Discover the Surface. Understand the Services.

Scanning is an important stage of ethical hacking because it helps security professionals understand what is reachable and exposed within an authorized environment. The results provide technical context for later stages such as enumeration and vulnerability assessment. Always perform scanning within a clearly defined scope.
