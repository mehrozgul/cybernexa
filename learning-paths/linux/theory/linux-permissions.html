Linux File Permissions

Linux file permissions control who can read, modify and execute files and directories. Understanding permissions is essential for Linux administration and cybersecurity.

🔍
🔐

What are File Permissions?

Simple Definition Linux file permissions define which users can read, write or execute a file or directory.
🛡

Why File Permissions Matter

Permissions help protect files and system resources from unauthorized access or modification.

Three Basic Permissions

r

Read

Allows a user to view the contents of a file.

w

Write

Allows a user to modify or change the contents of a file.

x

Execute

Allows a user to execute a file when the permission is applicable.

U

Permission Categories

Linux permissions are assigned to three main categories of users.

u

User

The owner of the file or directory.

g

Group

Users who belong to the file's associated group.

o

Others

All other users who are not the owner or members of the associated group.

Viewing File Permissions

The ls -l command displays detailed information about files, including their permissions.

ls -l
+

Changing Permissions with chmod

The chmod command is used to change file and directory permissions.

chmod permissions filename
chmod +x script.sh

Adds execute permission to the file.

chmod u+w file.txt

Adds write permission for the owner.

chmod g+r file.txt

Adds read permission for the group.

chmod o-r file.txt

Removes read permission from others.

Changing File Ownership

The chown command can be used to change the owner of a file or directory.

sudo chown username file.txt

Changing Group Ownership

The chgrp command changes the group associated with a file or directory.

sudo chgrp developers file.txt

Quick Summary

  • Linux permissions control access to files and directories.
  • Read permission is represented by r.
  • Write permission is represented by w.
  • Execute permission is represented by x.
  • Permissions apply to the user, group and others.
  • ls -l can be used to view permissions.
  • chmod changes file permissions.
  • Numeric permissions use values 4, 2 and 1.
  • chown changes file ownership.
  • chgrp changes group ownership.
  • Proper permissions are important for cybersecurity.
