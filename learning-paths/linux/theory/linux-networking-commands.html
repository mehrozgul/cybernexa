Linux Networking Commands

Linux provides powerful networking commands for checking network configuration, connectivity, interfaces, routes and active connections.

🌐

What are Linux Networking Commands?

Simple Definition Linux networking commands are command-line tools used to view, configure, test and troubleshoot network connections and settings.
IP

ip Command

The ip command is commonly used to view and manage network interfaces, IP addresses and routing information.

ip addr
ip link
ip route
P

ping Command

The ping command tests whether another host is reachable over a network using ICMP echo requests and replies.

ping 8.8.8.8

ss Command

The ss command displays information about network sockets and active connections.

hostname Command

The hostname command displays the system's hostname.

hostname
DNS

nslookup Command

The nslookup command can be used to query DNS information and resolve domain names to IP addresses.

nslookup example.com
D

dig Command

The dig command is a detailed DNS lookup tool commonly used for DNS troubleshooting and analysis.

dig example.com
dig example.com A
C

curl Command

The curl command is used to transfer data between a system and a server. It is frequently used for testing HTTP and HTTPS services.

curl https://example.com
curl -I https://example.com
R

Routing Information

Linux routing information determines how network traffic is forwarded to different destinations.
