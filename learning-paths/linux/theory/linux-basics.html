What is Linux?

Simple Definition Linux is an open-source operating system used to manage computer hardware, software, files, users and system resources.
OS

Linux as an Operating System

An operating system acts as a bridge between computer hardware and the applications that users run.

Linux Kernel

The kernel is the core component of a Linux operating system. It communicates with hardware and manages important system resources.

Process Management

Manages running processes and CPU resources.

Memory Management

Manages RAM and memory allocation between processes.

Device Management

Provides communication between software and hardware devices.

File System Management

Provides the mechanisms used to manage files and storage resources.

Linux Distributions

A Linux distribution combines the Linux kernel with system software, package management tools and other components to provide a complete operating system.

Ubuntu

A widely used Linux distribution suitable for desktops, servers and learning.

Debian

A community-developed distribution known for stability.

Fedora

A Linux distribution focused on newer technologies and development.

Kali Linux

A security-focused distribution commonly used for penetration testing and security research.

The terminal provides a command-line interface through which users can interact with the Linux system using commands.

Shell

A shell is a command interpreter that accepts commands from the user and communicates with the operating system.

Bash

Bash is one of the most commonly used shells on Linux systems.

Command

A command tells the shell to perform a particular operation.

Basic Terminal Concepts

Prompt

Shows that the shell is ready to receive a command.

Command

The instruction entered by the user.

Argument

Additional information provided to a command.

Option

Modifies how a command performs its operation.

C

Essential Linux Commands

These commands are commonly used when beginning to work with Linux.

whoami

Displays the current username.

pwd

Displays the current working directory.

ls

Lists files and directories.

cd

Changes the current directory.

mkdir

Creates a directory.

touch

Creates an empty file when used in the usual way.

cp

Copies files or directories.

mv

Moves or renames files and directories.

rm

Removes files or directories when used with the appropriate options.

clear

Clears the terminal display.

$

Simple Command Examples

pwd
ls
mkdir test
cd test
touch file.txt
ls

These commands demonstrate a simple workflow: check the current location, view its contents, create a directory, enter it, create a file and then view the file.

U

Root and Regular Users

Root User

The root account has extensive administrative privileges.

Regular User

A regular account normally operates with more limited privileges.

sudo command

The sudo command can allow an authorized user to execute a command with elevated privileges.
