Linux File System

The Linux file system organizes files, directories, system resources and configuration files in a hierarchical structure. Understanding this structure is essential for Linux administration and cybersecurity.

🔎
/

What is the Linux File System?

Simple Definition The Linux file system is the hierarchical structure used to organize files and directories. It starts from the root directory represented by /.
/

Root Directory

The root directory is the top-level directory of a Linux file system. Every other directory and file exists somewhere below it.

Important Linux Directories

Linux contains several standard directories. Each directory has a specific purpose.

/

The root of the entire Linux file system.

/home

Contains personal directories and files belonging to regular users.

/root

Home directory of the root administrator.

/etc

Contains many system-wide configuration files.

/var

Contains variable data such as logs, caches and other changing files.

/tmp

Used for temporary files created by the system and applications.

/usr

Contains many user-space programs, libraries and related resources.

/bin

Contains essential user command binaries on systems that use this traditional layout.

/sbin

Contains important system administration binaries on systems using this traditional layout.

/dev

Contains device files used to represent hardware and devices.

/proc

Provides a virtual view of process and kernel-related information.

/opt

Commonly used for optional or additional application software.

#

Absolute and Relative Paths

Absolute Path

An absolute path starts from the root directory and gives the complete location of a file or directory.

Relative Path

A relative path describes a location from the current working directory.

/home/user/Documents/file.txt
Documents/file.txt
$

File System Navigation Commands

Linux provides simple commands for moving through directories and checking the current location.

pwd

Displays the current working directory.

ls

Lists files and directories.

cd

Changes the current directory.

cd ..

Moves one level up in the directory tree.

cd ~

Moves to the current user's home directory.

ls -la

Lists files including hidden files with detailed information.

Copying, Moving and Removing Files

cp file.txt backup.txt

Creates a copy of a file.

mv file.txt folder/

Moves a file to another location.

rm file.txt

Removes a file.

rmdir folder

Removes an empty directory.

Quick Summary

  • Linux uses a hierarchical file system.
  • The root directory is represented by /.
  • All files and directories exist below the root.
  • /home commonly contains regular users' home directories.
  • /etc contains many system configuration files.
  • /var commonly contains changing data such as logs.
  • /tmp is commonly used for temporary files.
  • pwd displays the current working directory.
  • ls lists files and directories.
  • cd changes the current directory.
  • Absolute paths start from the root directory.
  • Relative paths are interpreted from the current directory.
  • Understanding the file system is important for Linux security.
