What is Linux Security?

Simple Definition Linux security is the practice of protecting a Linux system and its resources from unauthorized access, misuse, modification and other security threats.
🛡

Core Linux Security Principles

Linux security uses multiple controls to reduce unauthorized access and protect system resources.

Authentication

Verifies the identity of a user before allowing access to the system.

Authorization

Determines what an authenticated user is allowed to access or modify.

Least Privilege

Users and services should receive only the privileges required for their tasks.

Access Control

Controls access to files, directories, processes and other resources.

File Permission Security

Linux file permissions determine who can read, write or execute a file or directory.

ls -l
chmod 755 file.sh
chown user:group file.txt

Read (r)

Allows reading the contents of a file.

Write (w)

Allows modifying the contents of a file.

Execute (x)

Allows execution of a file when applicable.

Ownership

Defines the user and group associated with a resource.

Root Account Security

The root account has extensive administrative privileges. Because of these privileges, unnecessary use of root should be avoided.

Security Principle Use administrative privileges only when required. The principle of least privilege helps reduce the impact of mistakes or unauthorized activity.

sudo and Privilege Management

The sudo command allows an authorized user to execute specific commands with elevated privileges.

sudo command

Executes a command with elevated privileges.

sudo -l

Shows commands the current user may run with sudo.

sudo -u user command

Runs a command as a specified user when permitted.

visudo

Safely edits the sudoers configuration.

🔑

SSH Security

SSH provides secure remote access to Linux systems. Its configuration should be managed carefully to reduce unauthorized remote access.

Strong Authentication

Use strong authentication methods and appropriate account controls.

Key-Based Authentication

SSH keys can provide secure authentication without relying only on passwords.

Restrict Access

Limit SSH access to users and networks that actually require it.

Monitor Login Activity

Review authentication and system logs for unusual SSH activity.

🔥

Firewall Security

A firewall controls network traffic entering or leaving a Linux system according to configured rules.

ufw status

Displays the current UFW firewall status.

sudo ufw enable

Enables UFW when it is configured for the system.

sudo ufw allow 22

Allows traffic for SSH port 22 when appropriate.

sudo ufw deny 23

Denies traffic for port 23 when the rule is applied.

⚙

Service Security

Unnecessary services can increase the attack surface of a Linux system. Administrators should identify services and disable those that are not required.

systemctl status service-name
systemctl list-units --type=service
sudo systemctl stop service-name

Basic Linux Security Checklist

  • Use strong authentication.
  • Apply the principle of least privilege.
  • Keep file permissions properly configured.
  • Avoid unnecessary root access.
  • Protect SSH access.
  • Use a properly configured firewall.
  • Disable unnecessary services.
  • Install security updates regularly.
  • Monitor important system and authentication logs.
  • Review users, groups and privileges regularly.
✓

Quick Summary

  • Linux security protects the system and its resources.
  • Authentication verifies user identity.
  • Authorization controls permitted actions.
  • Least privilege limits unnecessary permissions.
  • File permissions control resource access.
  • sudo provides controlled administrative access.
  • SSH should be configured and monitored securely.
  • Firewalls control network traffic.
  • Security updates help address known vulnerabilities.
  • Logs help administrators monitor system activity.
