Linux Processes

A Linux process is a running instance of a program. Understanding processes is essential for system administration, troubleshooting and cybersecurity.

⌕
⚙

What is a Linux Process?

Simple Definition A process is a program that is currently running in the Linux operating system. Every running process uses system resources such as CPU time, memory and other resources.
P

Process Basics

When you execute a program, Linux creates a process to manage its execution. The operating system assigns each process a unique Process ID called a PID.

PID

Process ID is a unique numerical identifier assigned to a running process.

Parent Process

A process can create another process. The process that creates it is called the parent.

Child Process

A process created by another process is known as a child process.

Process Owner

A process runs under a user account and is associated with that user's permissions.

#

Process ID (PID)

Linux assigns a unique number to each running process. This number is called the Process ID or PID.

ps

The ps command can display information about currently running processes.

$

Viewing Running Processes

Linux provides several commands for viewing and monitoring running processes.

ps

Displays processes associated with the current shell.

ps aux

Displays detailed information about running processes.

top

Shows processes and resource usage dynamically.

htop

Provides an interactive process monitoring interface when installed.

Foreground and Background Processes

Foreground Process

A foreground process normally occupies the terminal and interacts directly with it.

Background Process

A background process can continue running while the terminal is available for other work.

Terminating a Process

The kill command can send a signal to a process. A PID is normally specified to identify the target process.

kill PID
kill -9 PID

Use stronger signals such as -9 carefully because they immediately terminate the selected process.

Important Process Commands

ps

View running processes.

top

Monitor processes and system resources.

pgrep

Find process IDs by process name.

Send a signal to a process.

pkill

Send a signal to processes matching a name.

Display jobs running in the current shell.

Process monitoring is important in cybersecurity because suspicious or unauthorized programs may consume resources, establish connections or execute malicious activity.

Quick Summary

  • A process is a running instance of a program.
  • Linux assigns every process a unique PID.
  • Processes can have parent and child relationships.

  • top provides dynamic process monitoring.
