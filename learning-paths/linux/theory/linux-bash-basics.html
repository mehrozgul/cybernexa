Bash Basics

Bash is a command-line shell commonly used on Linux systems. Learning Bash basics helps with system administration, automation and cybersecurity tasks.

⌕
$

What is Bash?

Simple Definition Bash stands for Bourne Again Shell. It is a command-line shell and scripting language widely used on Linux systems.
>

Bash, Shell & Terminal

These terms are related but are not exactly the same. The terminal provides an interface, while the shell interprets commands entered by the user.

Terminal

A program that provides a text-based interface for interacting with the system.

Shell

A command interpreter that receives commands and communicates with the operating system.

Bash

A popular Unix shell that can also be used to write automation scripts.

Prompt

The prompt shows that the shell is ready to receive a command.

#

Basic Bash Commands

Bash allows users to perform common Linux tasks directly from the command line.

pwd

Displays the current working directory.

ls

Lists files and directories.

cd

Changes the current directory.

mkdir

Creates a new directory.

touch

Creates an empty file.

cat

Displays file contents.

E

echo Command

The echo command displays text or variable values in the terminal.

echo "Hello CyberNexa"
Example Output Hello CyberNexa
V

Bash Variables

A variable stores a value that can be used later in a Bash script or command.

username="Gul"
echo "$username"
Example Output Gul

User Input with read

The read command allows a Bash script to receive input from the user.

echo "Enter your name:"
read name
echo "Hello $name"
IF

if Statement

The if statement allows Bash scripts to make decisions based on conditions.

if [ "$user" = "admin" ]; then
    echo "Access granted"
else
    echo "Access denied"
fi

for Loop

A for loop repeats a command or block of commands for each item in a sequence.

for user in Alice Bob Charlie
do
    echo "$user"
done
Example Output Alice
Bob
Charlie
∞

while Loop

A while loop repeatedly executes commands while a condition remains true.

count=1
while [ $count -le 3 ]
do
    echo $count
    ((count++))
done
./

Basic Bash Script

A Bash script is a text file containing commands that can be executed as a program.

#!/bin/bash
echo "Welcome to CyberNexa"
echo "Learning Linux Bash"

The first line identifies Bash as the interpreter for the script.

▶

Running a Bash Script

After creating a Bash script, execution permission can be given with chmod.

chmod +x script.sh
./script.sh
