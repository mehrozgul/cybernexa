Linux Package Management

Linux package management allows users and administrators to install, update, remove and maintain software packages efficiently.

📦

What is Package Management?

Simple Definition Package management is the process of installing, updating, removing and managing software packages on a Linux system.
P

What is a Package?

A package is a collection of files and information required to install a software application on a Linux system.

Application Files

Files required by the software to run correctly.

Dependencies

Other software libraries or packages that the application requires.

Configuration

Information used to configure the installed software.

Metadata

Information such as package name, version and dependencies.

#

Common Linux Package Managers

Different Linux distributions use different package management systems.

APT

Commonly used on Debian-based distributions such as Ubuntu and Debian.

DNF

Used by modern RPM-based distributions such as Fedora.

YUM

An older package management tool used on several RPM-based Linux systems.

Pacman

The primary package manager used by Arch Linux.

A

APT Package Manager

APT is widely used on Debian-based Linux distributions. It can install, update and remove software packages.

sudo apt update
sudo apt upgrade
sudo apt install package-name
sudo apt remove package-name
$

Basic APT Commands

sudo apt update

Refreshes the package lists from configured repositories.

sudo apt upgrade

Upgrades installed packages to available newer versions.

sudo apt install nginx

Installs the specified package.

sudo apt remove nginx

Removes the specified package.

apt search nginx

Searches available package information.

apt show nginx

Displays information about a package.

D

DNF Package Manager

DNF is a package management utility commonly used on Fedora and other RPM-based distributions.

sudo dnf check-update
sudo dnf upgrade
sudo dnf install package-name
sudo dnf remove package-name
P

Pacman Package Manager

Pacman is the package manager commonly associated with Arch Linux.

sudo pacman -Syu
sudo pacman -S package-name
sudo pacman -R package-name
