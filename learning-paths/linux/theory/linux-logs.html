Linux Logs

Linux logs record important system, authentication, service and application events. Understanding logs is essential for troubleshooting, monitoring and cybersecurity investigation.

📋

What are Linux Logs?

Simple Definition Linux logs are records of events generated by the operating system, services, applications and users. They help administrators understand what is happening on a Linux system.
🔎

Why Linux Logs Matter

Logs provide useful information for troubleshooting, system monitoring and security investigations.

Troubleshooting

Logs can help identify errors and problems affecting the operating system or applications.

Security Monitoring

Security-related events can be reviewed to identify suspicious activity.

Authentication

Authentication logs can help track login attempts and account activity.

Incident Investigation

Investigators can examine logs to understand events that occurred on a system.

/

Important Linux Log Locations

Traditional Linux systems commonly store many log files inside the /var/log directory.

/var/log

Main directory containing many system and application log files.

/var/log/auth.log

Commonly contains authentication-related events on Debian-based systems.

/var/log/syslog

Commonly contains general system events on Debian-based systems.

/var/log/kern.log

Commonly contains kernel-related messages on systems that use this log.

$

Basic Log Commands

Linux provides commands that can be used to view and analyze log information.

ls /var/log
cat /var/log/syslog
less /var/log/syslog
tail /var/log/syslog
tail -f /var/log/syslog
→

Using tail to Monitor Logs

The tail command displays the last part of a file. It is especially useful for monitoring logs.

tail /var/log/syslog

The -f option continuously displays new lines added to the log.

tail -f /var/log/syslog
J

journalctl

On systems using systemd, journalctl is commonly used to view logs stored by the system journal.

journalctl

Displays journal entries.

journalctl -b

Shows messages from the current boot.

journalctl -u ssh

Displays journal entries for a specified service.

journalctl -f

Follows new journal entries in real time.

#

Searching Logs

Log files can contain a large amount of information. Tools such as grep can be used to search for specific words or patterns.

grep "error" /var/log/syslog
grep "failed" /var/log/auth.log
grep -i "warning" /var/log/syslog

Practical Example

Suppose an administrator wants to find failed authentication attempts. A log file can be searched for relevant entries.

grep "failed" /var/log/auth.log

The resulting entries can then be reviewed to understand when and where failed authentication activity occurred.
