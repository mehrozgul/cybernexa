Linux SSH

SSH (Secure Shell) is a secure protocol used to remotely access and manage Linux systems over a network. It is an essential tool for Linux administration and cybersecurity.

🔍
🔐

What is SSH?

Simple Definition SSH stands for Secure Shell. It is a network protocol that allows a user to securely connect to and control a remote computer through an encrypted connection.
✓

Why is SSH Used?

SSH is commonly used by system administrators, developers and cybersecurity professionals to securely manage remote Linux systems.

Remote Access

Allows a user to access a Linux system from another computer over a network.

Secure Management

Administrators can securely execute commands and manage remote systems.

File Transfer

SSH-based tools such as SCP and SFTP can securely transfer files.

Cybersecurity

SSH is widely used for secure administration, server management and security testing.

How SSH Works

A client starts an SSH connection to a remote server. The server authenticates the user and, after successful authentication, provides a secure remote session.

Default Port

Protocol

Basic SSH Command

The ssh command is used to connect to a remote Linux system.

ssh username@server_ip

Example:

ssh gul@192.168.1.20

SSH Key Authentication

SSH can use cryptographic keys instead of passwords for authentication. Key-based authentication is commonly used for secure server administration.

Private Key

The private key must be kept secret and should not be shared with others.

Public Key

The public key can be placed on the remote server for authentication.

ssh-keygen
/

Important SSH Files

/etc/ssh/sshd_config

Main configuration file for the OpenSSH server.

~/.ssh/

User's SSH configuration and key directory.

~/.ssh/authorized_keys

Contains public keys that are allowed to authenticate to a user's account.

~/.ssh/known_hosts

Stores information about previously known SSH hosts.

⚙

Managing the SSH Service

On systems using systemd, the SSH server service can commonly be managed using systemctl.

sudo systemctl status ssh

Checks the SSH service status.

sudo systemctl start ssh

Starts the SSH service.

sudo systemctl stop ssh

Stops the SSH service.

sudo systemctl restart ssh

Restarts the SSH service.
