What are Linux Commands?

Simple Definition Linux commands are text instructions entered in the terminal to perform tasks such as navigating directories, managing files, checking system information and controlling processes.

Directory Navigation Commands

These commands are commonly used to move through directories and understand the current location.

pwd

Displays the current working directory.

ls

Lists files and directories in the current location.

cd

Changes the current working directory.

cd ..

Moves one directory level back.

cd ~

Moves to the current user's home directory.

ls -la

Displays detailed information including hidden files.

F

File Management Commands

Linux provides simple commands for creating, copying, moving and deleting files.

touch file.txt

Creates an empty file.

cp file.txt backup.txt

Copies a file to another location or name.

mv file.txt new.txt

Moves or renames a file.

rm file.txt

Removes a file.

D

Directory Management Commands

mkdir projects

Creates a new directory.

rmdir projects

Removes an empty directory.

cp -r folder backup

Copies a directory and its contents.

rm -r folder

Removes a directory and its contents.

V

Viewing File Content

cat file.txt

Displays the contents of a file.

less file.txt

Opens a file for controlled page-by-page viewing.

head file.txt

Displays the beginning of a file.

tail file.txt

Displays the end of a file.

?

Searching Commands

find

Searches for files and directories based on specified conditions.

grep

Searches text for matching patterns.

which

Shows the location of a command executable.

locate

Searches a file database for matching file paths.

#

System Information Commands

whoami

Displays the current username.

hostname

Displays the system hostname.

uname -a

Displays detailed system and kernel information.

uptime

Shows how long the system has been running.

%

Disk & Memory Commands

df -h

Displays available and used disk space.

du -h

Shows disk usage of files and directories.

free -h

Displays memory and swap usage.

top

Displays active processes and system resource usage.

🔐

Privilege & Permission Commands

chmod

Changes file and directory permissions.

chown

Changes the owner of a file or directory.

sudo

Executes an authorized command with elevated privileges.

su

Switches to another user account.
