Linux Users & Groups

Linux uses users and groups to manage identity, access and permissions. Understanding them is essential for Linux administration and cybersecurity.

What are Linux Users & Groups?

Simple Definition A user represents an account that can access a Linux system, while a group is a collection of users used to manage access and permissions more easily.
U

Linux Users

Every person or service that needs access to a Linux system can have a user account.

Root User

The root account is the administrator account with extensive privileges over the system.

Regular User

A normal user account is generally used for everyday activities with limited privileges.

System User

System accounts are commonly used by services and applications rather than interactive users.

User ID (UID)

Linux identifies users internally using numerical User IDs called UIDs.

G

Linux Groups

A group allows multiple users to share access permissions to files, directories and resources.

Primary & Secondary Groups

Primary Group

The primary group is the main group associated with a user's account and is used as the default group for many file operations.

Secondary Group

A user can belong to additional groups. These are called secondary groups and can provide additional access.

ID

UID and GID

UID

UID stands for User ID. It is the numerical identifier assigned to a Linux user.

GID

GID stands for Group ID. It is the numerical identifier assigned to a Linux group.

Important User & Group Files

/etc/passwd

Contains information about Linux user accounts.

/etc/shadow

Stores protected password-related information.

/etc/group

Contains information about groups.

/etc/gshadow

Contains protected group-related information.

$

Basic User & Group Commands

Linux provides commands for viewing and managing users and groups.

whoami

Displays the username of the current user.

id

Displays UID, GID and group information.

who

Shows users currently logged into the system.

groups

Shows the groups associated with a user.

passwd

Changes or manages a user's password.

getent group

Displays group information from configured system databases.

+

Creating a User

The useradd command can be used to create a new user account.

sudo useradd username

A password can then be assigned using the passwd command.

sudo passwd username
+

Creating a Group

The groupadd command creates a new group.

sudo groupadd developers
↔

Adding a User to a Group

A user can be added to an existing group using the usermod command.

sudo usermod -aG developers username
−

Removing a User from a Group

On many Linux systems, a user can be removed from a secondary group using the gpasswd command.

sudo gpasswd -d username developers

Why Users & Groups Matter in Cybersecurity

User and group management is important in cybersecurity because access should be limited according to a user's required responsibilities.

Quick Summary

  • Linux uses users to identify accounts.
  • Groups allow multiple users to share access.
  • UID identifies a user numerically.
  • GID identifies a group numerically.
  • A user can have a primary group and additional secondary groups.
  • /etc/passwd contains user account information.
  • /etc/shadow contains protected password-related information.
  • /etc/group contains group information.
  • useradd can create a user.
  • groupadd can create a group.
  • usermod can modify user membership and properties.
  • Proper user and group management supports least-privilege security.
