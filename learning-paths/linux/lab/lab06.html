Lab 06 - Linux Processes

In this practical lab, you will learn how Linux processes work, how to view running processes, identify process IDs, monitor processes and safely terminate processes using basic Linux commands.

Hands-On Lab • Beginner
🎯

Lab Objective

What You Will Practice By completing this lab, you will learn how to view running processes, identify process IDs, monitor processes, find a specific process, understand process states and terminate a process safely.
⚙

Lab Requirements

01

Linux System

Ubuntu, Kali Linux, Debian or another Linux distribution.

02

Terminal

Open the Linux Terminal to execute process-management commands.

03

Sudo Access

Administrative access may be required for some process-management operations.

04

Basic Linux Knowledge

You should know how to open a terminal and execute basic Linux commands.

01

Step 1 — View Running Processes

The ps command displays information about processes currently running in the terminal session.

ps
Example Output 
PID TTY          TIME CMD
2145 pts/0    00:00:00 bash
2198 pts/0    00:00:00 ps
02

Step 2 — View All Running Processes

Use ps aux to display processes from all users along with CPU and memory information.

ps aux
Example Output 
USER       PID %CPU %MEM    VSZ   RSS TTY      STAT START   TIME COMMAND
root         1  0.0  0.1  22500  12000 ?        Ss   10:00   0:01 /sbin/init
student   2145  0.0  0.2  18000   4500 pts/0    Ss   10:10   0:00 bash
student   2205  0.0  0.1  12000   3000 pts/0    R+   10:15   0:00 ps aux
03

Step 3 — Monitor Processes in Real Time

The top command provides a continuously updated view of running processes, CPU usage and memory usage.

top
Important

Press q inside the top interface to exit and return to the terminal.

04

Step 4 — Identify a Process ID

Every running Linux process has a unique Process ID (PID). Use pgrep to find the PID of a process.

pgrep bash
Example Output 
2145
05

Step 5 — Display Process Details

Use the ps -p command to display detailed information about a process with a known PID.

ps -p 2145 -f
Example Output 
UID        PID  PPID  C STIME TTY          TIME CMD
student   2145  2100  0 10:10 pts/0    00:00:00 bash
06

Step 6 — Find a Specific Process

The pgrep command can search for processes by name. For example, search for processes containing the name ssh.

pgrep ssh
Example Output 
1532
07

Step 7 — Understand Process States

Linux uses process states to describe what a process is currently doing. The STAT column in process output shows these states.

R

Running

The process is running or ready to run.

S

Sleeping

The process is waiting for an event or resource.

T

Stopped

The process has been stopped.

Z

Zombie

The process has finished but its parent has not yet collected its status.

08

Step 8 — Terminate a Process

The kill command sends a signal to a process. The normal termination signal is SIGTERM.

kill 2145
Safety Note

Replace 2145 with the PID of a process you own and intend to terminate. Do not randomly terminate system-critical processes.

09

Step 9 — Force Terminate a Process

If a process does not respond to a normal termination signal, SIGKILL can be sent using signal number 9.

kill -9 2145
Important

SIGKILL immediately terminates the process and does not allow it to perform normal cleanup. Use it only when necessary.

10

Step 10 — View Process Tree

The pstree command displays processes in a parent-child tree structure.

pstree
Example Output 
systemd
 ├─NetworkManager
 ├─sshd
 │  └─bash
 └─cron
11

Step 11 — Check Process Priority

Linux processes have a scheduling priority. The nice value influences how much CPU scheduling preference a process receives.

ps -eo pid,ni,comm
Example Output 
PID  NI COMMAND
1     0 systemd
2145  0 bash
2205  0 ps

Your Practical Task

Now perform the following tasks yourself in your Linux terminal.

  • Display the processes running in your current terminal.
  • Display all processes using ps aux.
  • Open the top process monitor.
  • Find the PID of a bash process.

  • Display the process tree using pstree.
  • Identify the process state from the STAT column.
  • Safely terminate a test process that you started yourself.

Cybersecurity Connection

Process management is an important part of Linux security. Security analysts use process information to identify suspicious programs, investigate system activity and detect potentially malicious processes.

Lab Summary

  • ps displays information about processes.
  • ps aux displays processes from all users.
  • top provides real-time process monitoring.
  • pgrep searches for processes by name.
  • PID uniquely identifies a running process.
  • kill sends a signal to a process.
  • kill -9 sends SIGKILL for immediate termination.
  • pstree displays parent-child process relationships.
  • nice is related to process scheduling priority.
  • Process monitoring is useful for Linux system administration and cybersecurity.
