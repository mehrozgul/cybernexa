LINUX PRACTICAL LAB

Lab 10 - Networking Commands

In this practical lab, you will learn how to inspect network interfaces, check IP addresses, view routing information, test connectivity, inspect network connections, perform DNS queries and communicate with web servers using Linux networking commands.

Platform Ubuntu / Debian Linux
Tool Linux Terminal
Level Beginner
🌐

Lab Objective

The objective of this lab is to understand the practical use of Linux networking commands for network configuration, troubleshooting and basic network analysis.

What You Will Practice IP address inspection, interface status, routing table, connectivity testing, DNS lookup, active connections and HTTP communication.
01
$

Open the Linux Terminal

Open the Terminal application in your Ubuntu or Debian-based Linux system.

Instruction Press Ctrl + Alt + T to open the terminal.
Expected Result A Linux terminal window should appear and you should be ready to enter networking commands.
02
IP

Display IP Address Information

Use the ip addr command to display network interfaces and their assigned IP addresses.

Linux Terminal 
ip addr
Explanation This command displays network interfaces, IPv4 addresses, IPv6 addresses, MAC addresses and interface status.
Expected Result Network interfaces such as lo and eth0 or ens33 should be displayed with their IP information.
03
↔

Check Network Interface Status

Use ip link to check the available network interfaces and whether they are UP or DOWN.

Linux Terminal 
ip link
Expected Result Linux displays available network interfaces and their operational state.
04
R

View the Routing Table

Use the ip route command to view how Linux decides where network traffic should be sent.

Linux Terminal 
ip route
Explanation The routing table contains routes for local networks, remote networks and the default gateway.
Expected Result You should see routing entries including a default route such as default via ....
05
P

Test Network Connectivity

Use ping to test whether another host is reachable over the network.

Linux Terminal 
ping -c 4 8.8.8.8
Explanation The command sends four ICMP echo requests to Google's public DNS IP address 8.8.8.8.
Expected Result If the destination is reachable, you should receive ICMP replies along with latency information.
Important If there is no Internet connection, the command may show packet loss or "Destination Host Unreachable".
06
T

Trace the Network Path

Use traceroute to observe the network hops between your system and a destination.

Linux Terminal 
traceroute google.com
If Command Is Missing On some Ubuntu installations, install it using:

sudo apt install traceroute
Expected Result The terminal displays network hops between your computer and the destination.
07
S

View Active Network Connections

Use ss to view listening ports and active network connections.

Linux Terminal 
ss -tuln
Option Meaning -t = TCP connections
-u = UDP connections
-l = Listening sockets
-n = Numeric addresses and ports
Expected Result Listening TCP and UDP ports should be displayed, such as port 22 for SSH if SSH is enabled.
08
D

Perform a DNS Lookup

Use nslookup to query DNS information for a domain name.

Linux Terminal 
nslookup google.com
Expected Result The command should display the DNS server used and IP address information for the requested domain.
Security Connection DNS investigation is commonly used during network troubleshooting and cybersecurity reconnaissance.
09
D

Perform an Advanced DNS Query

The dig command provides detailed DNS query information.

Linux Terminal 
dig google.com
Useful Information The output contains the DNS question, answer section, query time and DNS server information.
Expected Result A detailed DNS response should be displayed in the terminal.
10
H

Check the Hostname

Use the hostname command to display the system's hostname.

Linux Terminal 
hostname
Expected Result The hostname assigned to your Linux system should be displayed.
11
W

Test HTTP Connectivity with curl

Use curl to send an HTTP request to a web server.

Linux Terminal 
curl -I https://example.com
Explanation The -I option requests only the HTTP response headers instead of the complete webpage.
Expected Result You should receive HTTP response information such as the status code and server headers.
12
↓

Download a File with wget

The wget command can download files from HTTP or HTTPS servers.

Linux Terminal 
wget https://example.com
Expected Result wget connects to the specified server and attempts to download the requested resource.
Safety Note Download files only from trusted sources. Never execute unknown downloaded files without verifying them.

Important Linux Networking Commands

ip addr Displays IP addresses and network interfaces.
ip link Displays network interface status.
ip route Displays the routing table.
ping host Tests network connectivity.
traceroute host Displays the path to a destination.
ss -tuln Displays listening TCP and UDP ports.
nslookup domain Performs a DNS lookup.
dig domain Performs a detailed DNS query.
hostname Displays the system hostname.
curl -I URL Checks HTTP response headers.
wget URL Downloads resources from a web server.
ip neigh Displays the local neighbor/ARP cache.

Why Networking Commands Matter in Cybersecurity

Linux networking commands are important in cybersecurity because security professionals need to understand network configuration, connectivity, services, DNS and active connections.

  • IP commands help identify network interfaces and addresses.
  • Routing information helps understand where network traffic is sent.
  • Ping helps test basic network connectivity.
  • ss helps identify listening services and ports.
  • DNS tools help investigate domain resolution.
  • curl helps inspect HTTP communication.
  • These commands are useful for network troubleshooting and defensive security analysis.
