Lab 11 - Bash Basics

In this practical lab, you will learn the fundamentals of Bash scripting in Linux. You will practice commands, variables, user input, arithmetic operations, conditional statements, loops, functions and basic script execution.

Platform Ubuntu / Debian Linux
Tool Linux Terminal + Bash
Level Beginner
#

Lab Objective

The objective of this lab is to understand the basic concepts of Bash scripting and automate simple tasks using the Linux shell.

What You Will Practice Bash commands, variables, input, arithmetic, conditions, loops, functions and basic shell scripting.
01
$

Check the Bash Shell

First, check which shell is currently being used by your Linux terminal.

Linux Terminal 
echo $SHELL
Explanation The $SHELL environment variable contains the path of the user's default shell.
Expected Result You may see a result such as /bin/bash.
02
E

Display Text with echo

The echo command is commonly used to display text in the terminal.

Linux Terminal 
echo "Hello CyberNexa"
Expected Result The terminal should display:
Hello CyberNexa
03
V

Create and Use a Variable

Bash variables are used to store values such as text or numbers.

Linux Terminal 
name="Gul"
echo $name
Important Rule Do not put spaces around the = sign when assigning a Bash variable.
Expected Result The value stored in the variable should be displayed in the terminal.
04
I

Take User Input

The read command allows a Bash script to receive input from the user.

Linux Terminal 
read -p "Enter your name: " name
echo "Hello $name"
Explanation The read command waits for user input and stores it in the variable name.
Expected Result The terminal asks for your name and then displays a greeting.
05
+

Perform Arithmetic Operations

Bash supports arithmetic operations using arithmetic expansion.

Linux Terminal 
a=10
b=5
sum=$((a+b))
echo $sum
Common Operators + Addition
- Subtraction
* Multiplication
/ Division
% Modulus
Expected Result The result of adding 10 and 5 should be 15.
06
F

Use an if Statement

The if statement allows a Bash script to make decisions based on a condition.

Linux Terminal 
age=20

if [ $age -ge 18 ]; then
    echo "Adult"
else
    echo "Minor"
fi
Condition -ge means "greater than or equal to".
Expected Result Because the value is 20, the script should display Adult.
07
L

Use a for Loop

A for loop can repeat a command for multiple values.

Linux Terminal 
for i in 1 2 3 4 5; do
    echo "Number: $i"
done
Expected Result The numbers 1 through 5 should be displayed one per line.
08
W

Use a while Loop

A while loop repeatedly executes commands while a condition remains true.

Linux Terminal 
count=1

while [ $count -le 5 ]; do
    echo "Count: $count"
    ((count++))
done
Important The counter must change inside the loop. Otherwise, the loop may continue indefinitely.
Expected Result The values 1, 2, 3, 4 and 5 should be displayed.
09
F

Create a Bash Function

Functions allow you to group commands and execute them when needed.

Linux Terminal 
greet() {
    echo "Welcome to CyberNexa"
}

greet
Explanation The function is defined first and then called using its name.
Expected Result The terminal should display Welcome to CyberNexa.
10
#

Create a Bash Script File

Now create a simple Bash script file instead of entering every command directly in the terminal.

Linux Terminal 
nano hello.sh
Add the Following Code Type the following inside the file:
hello.sh 
#!/bin/bash

echo "Hello from CyberNexa"
Expected Result A file named hello.sh should be created in the current directory.
11
>

Give Execute Permission

Before directly executing a Bash script, give the file execute permission.

Linux Terminal 
chmod +x hello.sh
Explanation chmod +x adds execute permission to the script.
Expected Result The script becomes executable.
12
▶

Execute the Bash Script

Run the script using the relative path ./.

Linux Terminal 
./hello.sh
Alternative Method You can also run the script with:

bash hello.sh
Expected Result The terminal should display:
Hello from CyberNexa
$

Important Bash Basics

echo Displays text or variable values.
read Takes input from the user.
variable=value Stores a value in a Bash variable.
$variable Accesses the value stored in a variable.
$((expression)) Performs arithmetic operations.
if Performs conditional decision making.
for Repeats commands for multiple values.
while Repeats commands while a condition is true.
function() Groups commands into a reusable function.
chmod +x Gives execute permission to a file.
./script.sh Executes an executable Bash script.
bash script.sh Runs a Bash script using Bash.
→

→
Write Commands

Why Bash Matters in Cybersecurity

Bash is widely used in Linux environments and is useful for automating repetitive tasks, checking system information, managing files and performing security-related operations.

  • Bash can automate repetitive security tasks.
  • Variables allow scripts to store and process information.
  • Conditions allow scripts to make decisions.
  • Loops allow repeated operations.
  • Functions make scripts easier to organize and reuse.
  • Bash scripts can help automate Linux administration tasks.
  • Security professionals commonly work with Linux command-line environments.

Create a Bash script named cybernexa.sh and perform the following tasks:

  • Display a welcome message.
  • Create a variable containing your name.
  • Display the variable using echo.
  • Ask the user for their age.
  • Use an if statement to check whether the user is an adult.
  • Use a for loop to display numbers 1 to 5.
  • Create a simple function and call it.
  • Give execute permission to the script.
  • Execute the script using ./cybernexa.sh.
Practical Goal Complete the basic Bash scripting workflow: Variables → Input → Condition → Loop → Function → Execute
!

Bash Safety Note

Bash commands can directly interact with the Linux system. Always understand a command before executing it, especially commands involving files, permissions or system configuration.

Important Practice commands inside your own Linux virtual machine or authorized lab environment. Do not execute unknown scripts from untrusted sources.
