Lab 02 — Linux File System

In this practical lab, you will learn how to navigate the Linux file system, create files and directories, copy and move files, remove files, and work with absolute and relative paths.

Lab Objectives

After completing this lab, you should be able to perform basic Linux file-system operations.

  • Understand the Linux root directory.
  • Navigate between directories.
  • Create directories and files.
  • Copy and move files.
  • Remove files and empty directories.
  • Understand absolute and relative paths.
  • Understand why file-system knowledge is important in cybersecurity.

Lab Requirements

You need a Linux terminal for this practical lab.

Recommended Environment
  1. Open Ubuntu, Kali Linux, or another Linux distribution.
  2. Open the Terminal.
  3. Run the commands given in each step.
  4. Read the expected result before moving to the next step.
01

Step 1 — Check Current Directory

1

Use the pwd command

The pwd command displays the current working directory.

pwd
How to perform it
  1. Open the Linux Terminal.
  2. Type or paste the command.
  3. Press Enter.
  4. Check the path displayed by Linux.
Expected Result Linux should display your current working directory, for example /home/user.
02

Step 2 — List Files and Directories

2

Use the ls command

The ls command lists files and directories in the current location.

ls
How to perform it
  1. Open the terminal.
  2. Make sure you know your current location using pwd.
  3. Run ls.
  4. Observe the displayed files and directories.
Expected Result Linux displays the files and directories available in your current directory.
03

Step 3 — Move to the Home Directory

3

Use cd ~

The cd ~ command moves you to the current user's home directory.

cd ~
How to perform it
  1. Open the terminal.
  2. Copy the command.
  3. Paste it into the terminal.
  4. Press Enter.
  5. Run pwd to verify your location.
pwd
04

Step 4 — Create a Directory

4

Create a folder using mkdir

The mkdir command creates a new directory.

mkdir cybernexa_lab
How to perform it
  1. Make sure you are in your home directory.
  2. Run the mkdir command.
  3. Press Enter.
  4. Use ls to verify the directory.
ls
Expected Result A directory named cybernexa_lab should appear in the output.
05

Step 5 — Enter the Directory

5

Use cd

The cd command changes the current working directory.

cd cybernexa_lab
How to perform it
  1. Make sure the directory exists.
  2. Run the cd command.
  3. Press Enter.
  4. Run pwd to verify the location.
pwd
06

Step 6 — Create a File

6

Use touch

The touch command can be used to create an empty file.

touch notes.txt
How to perform it
  1. Make sure you are inside cybernexa_lab.
  2. Run the touch command.
  3. Press Enter.
  4. Use ls to verify the file.
ls
Expected Result The file notes.txt should appear.
07

Step 7 — Copy a File

7

Use cp

The cp command creates a copy of a file.

cp notes.txt backup.txt
How to perform it
  1. Make sure notes.txt exists.
  2. Run the cp command.
  3. Press Enter.
  4. Run ls.
Expected Result Both notes.txt and backup.txt should be visible.
08

Step 8 — Move a File

8

Create a folder and move the file

The mv command can move a file to another directory.

mkdir backup
mv backup.txt backup/
How to perform it
  1. Create the backup directory.
  2. Move backup.txt into it.
  3. Run ls to check the current directory.
  4. Run ls backup/ to check the destination.
ls backup/
09

Step 9 — Remove a File

9

Use rm

The rm command removes a file.

rm notes.txt
How to perform it
  1. Confirm that notes.txt exists.
  2. Run rm notes.txt.
  3. Press Enter.
  4. Run ls to verify that the file has been removed.
Expected Result notes.txt should no longer appear in the current directory.
10

Step 10 — Move One Level Up

10

Use cd ..

The cd .. command moves one level up in the directory tree.

cd ..
How to perform it
  1. Make sure you are inside cybernexa_lab.
  2. Run cd ...
  3. Press Enter.
  4. Run pwd to verify that you moved to the parent directory.
pwd

Absolute vs Relative Path

Linux supports both absolute and relative paths. Understanding the difference is important when navigating the file system.

Absolute Path

Starts from the root directory / and gives the complete location.

Relative Path

Describes a location relative to the current working directory.

/home/user/Documents/file.txt
Documents/file.txt
🔐

Why This Matters in Cybersecurity

Linux file-system knowledge is important for cybersecurity because security analysts often need to locate configuration files, logs, user data and system resources.

/etc

Common location for system-wide configuration files.

/var

Common location for changing data, including logs.

/home

Common location for regular users' personal files.

/tmp

Common location for temporary files created by applications and users.
