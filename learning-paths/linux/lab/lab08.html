What is SSH?

SSH stands for Secure Shell. It is a network protocol used to securely access and manage a remote computer through a command-line interface.

Default Port

SSH normally uses TCP port 22.

Security

SSH encrypts the communication between the client and server.

Client

The computer from which you initiate the SSH connection.

Server

The Linux system that accepts SSH connections.

Lab Requirements

You need a Linux system with terminal access. Ubuntu, Debian, Kali Linux, or another Debian-based distribution can be used.

Recommended Environment
  1. Open your Linux virtual machine or physical Linux system.
  2. Make sure the system has network access.
  3. Open the Terminal.
  4. Run the commands in the following steps.
01

Step 1 — Check Your Current User

1

Use whoami

The whoami command displays the username of the currently logged-in user.

whoami
How to perform it
  1. Open the Linux Terminal.
  2. Type or paste the command.
  3. Press Enter.
  4. Observe the username.
Expected Result Linux should display your current username, such as user.
02

Step 2 — Check SSH Installation

2

Check the SSH client

Linux systems commonly include an SSH client. Use the following command to check whether SSH is available.

ssh -V
Expected Result The terminal should display an OpenSSH version, for example OpenSSH 9.x.
03

Step 3 — Install OpenSSH Server

3

Install the SSH server

The OpenSSH server allows your Linux system to accept incoming SSH connections.

sudo apt update sudo apt install openssh-server
How to perform it
  1. Run the first command to update package information.
  2. Run the second command.
  3. If prompted, type Y and press Enter.
  4. Wait for the installation to finish.
Expected Result The OpenSSH server package should be installed successfully.
04

Step 4 — Check SSH Service

4

Check ssh service status

The systemctl command can be used to check whether the SSH service is running.

sudo systemctl status ssh
Expected Result Look for a status similar to active (running).
05

Step 5 — Start and Enable SSH

5

Start the SSH service

If the SSH service is not running, start it and enable it so that it can start automatically when the system boots.

sudo systemctl start ssh sudo systemctl enable ssh
sudo systemctl status ssh
Expected Result The SSH service should show active (running).
06

Step 6 — Find Your IP Address

6

Use the ip command

An SSH client needs the IP address of the remote system. Use the following command to view your network interfaces.

ip addr
What to look for
  1. Find your active network interface.
  2. Look for an inet address.
  3. Note the local IPv4 address.
Example You may see an address such as 192.168.1.20. Your actual IP address may be different.
07

Step 7 — Test SSH Locally

7

Connect to localhost

You can test the SSH server on the same Linux machine by connecting to localhost.

ssh localhost
How to perform it
  1. Run the SSH command.
  2. If asked whether you want to continue, type yes.
  3. Enter your Linux user's password.
  4. Observe the new shell session.
Expected Result You should successfully enter an SSH session on your own Linux machine.
08

Step 8 — Verify the SSH Session

8

Check the connected user

After connecting through SSH, use whoami and hostname to verify the current session.

whoami hostname
Expected Result The commands should display your Linux username and the hostname of the system.
09

Step 9 — Exit the SSH Session

9

Use exit

The exit command closes the current SSH session and returns you to the original terminal.

exit
Expected Result The SSH connection should close and you should return to your previous shell.
10

Step 10 — Connect Using IP Address

10

Use username and IP address

SSH can connect to a remote Linux machine using its username and IP address.

ssh username@192.168.1.20
Important
  1. Replace username with the actual Linux username.
  2. Replace 192.168.1.20 with the actual server IP.
  3. Enter the password when prompted.
Expected Result If the remote system is reachable and SSH is configured correctly, an SSH session should be established.

Why SSH Matters in Cybersecurity

SSH is widely used by system administrators, security professionals, and penetration testers to securely manage Linux systems remotely.

Secure Remote Access

SSH provides encrypted remote terminal access to Linux systems.

Port 22

SSH commonly listens on TCP port 22.

Authentication

SSH can use passwords or stronger public-key authentication.

Security Monitoring

SSH login activity can be monitored through system logs.
