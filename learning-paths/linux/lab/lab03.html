Lab 03 - Linux Commands

In this practical lab, you will practice basic Linux commands for directory navigation, file management, file viewing, searching, system information and permissions.

Lab Objective

By completing this lab, you will practically execute the Linux commands introduced in the Linux Commands topic.

  • Navigate directories using Linux commands.
  • Create, copy, rename and remove files.
  • Create and manage directories.
  • View the contents of files.
  • Search for files and text.
  • Check basic system information.
  • Check disk, memory and process information.
  • Understand basic permission commands.
>

Before You Start

Open a Linux terminal. You can perform this lab on a Linux system or a Linux virtual machine.

How to start: Open Terminal and wait until the command prompt appears. Then perform the tasks below one by one.
/

Task 1 — Check Your Current Location

1

Use the pwd command

The pwd command displays the current working directory.
  1. Open your Linux terminal.
  2. Click the Copy Command button.
  3. Paste the command into the terminal.
  4. Press Enter.
Command
pwd
Expected Result: The terminal displays your current directory path, for example /home/user.
L

Task 2 — List Files and Directories

2

Use ls

The ls command lists files and directories in the current location.
  1. Copy the command.
  2. Paste it into the terminal.
  3. Press Enter.
  4. Observe the files and directories displayed.
Command
ls
Expected Result: A list of files and directories appears.
3

Display Detailed Files

Use ls -la to display detailed information, including hidden files.
  1. Copy the command below.
  2. Paste it into the terminal.
  3. Press Enter.
Command
ls -la
Expected Result: Detailed file information is displayed, including hidden files such as .bashrc when present.
F

Task 3 — Create and Manage a File

4

Create a File

The touch command creates an empty file.
  1. Copy the command.
  2. Paste it into the terminal.
  3. Press Enter.
Command
touch notes.txt
Expected Result: An empty file named notes.txt is created.
5

Copy the File

The cp command creates a copy of a file.
  1. Copy the command.
  2. Paste it into the terminal.
  3. Press Enter.
Command
cp notes.txt backup.txt
Expected Result: A second file named backup.txt is created.
6

Rename the File

The mv command can be used to rename a file.
  1. Copy the command.
  2. Paste it into the terminal.
  3. Press Enter.
Command
mv backup.txt backup-copy.txt
Expected Result: The file is renamed to backup-copy.txt.
7

Remove the File

The rm command removes a file.
  1. Copy the command.
  2. Paste it into the terminal.
  3. Press Enter.
Command
rm backup-copy.txt
Expected Result: The specified file is removed.
Safety Note: The rm command permanently removes files. Only run it on files you intentionally created for this lab.
D

Task 4 — Create and Manage a Directory

8

Create a Directory

The mkdir command creates a new directory.
  1. Copy the command.
  2. Paste it into the terminal.
  3. Press Enter.
Command
mkdir cybersecurity
Expected Result: A directory named cybersecurity is created.
9

Enter the Directory

The cd command changes the current working directory.
  1. Copy the command.
  2. Paste it into the terminal.
  3. Press Enter.
  4. Run pwd afterward to confirm your location.
Command
cd cybersecurity
Expected Result: Your current directory changes to cybersecurity.
10

Create a File Inside the Directory

Create an empty file inside the current directory.
  1. Copy the command.
  2. Paste it into the terminal.
  3. Press Enter.
Command
touch notes.txt
Expected Result: The file notes.txt is created inside the directory.
11

List the Directory Contents

Use ls to confirm that the file exists.
  1. Copy the command.
  2. Paste it into the terminal.
  3. Press Enter.
Command
ls
Expected Result: notes.txt appears in the output.
V

Task 5 — View File Content

12

Display File Content

The cat command displays the contents of a file.
  1. Create or use an existing text file.
  2. Copy the command below.
  3. Paste it into the terminal.
  4. Press Enter.
Command
cat notes.txt
Expected Result: The terminal displays the contents of notes.txt. If the file is empty, no text appears.
13

View the Beginning of a File

Command
head notes.txt
Expected Result: The beginning portion of the file is displayed.
14

View the End of a File

Command
tail notes.txt
Expected Result: The end portion of the file is displayed.
?

Task 6 — Search for Files and Commands

15

Search for a File

The find command searches for files and directories based on conditions.
  1. Make sure you are in your home directory.
  2. Copy the command.
  3. Paste it into the terminal.
  4. Press Enter.
Command
find . -name "notes.txt"
Expected Result: The path of matching notes.txt files is displayed.
16

Find the Location of a Command

The which command shows the location of an executable command.
Command
which ls
Expected Result: The path of the ls executable is displayed.
17

Search Text with grep

The grep command searches text for a matching pattern.
Command
grep "Linux" notes.txt
Expected Result: Lines containing the word Linux are displayed. If no matching text exists, no matching line is displayed.
#

Task 7 — Check System Information

18

Check Current Username

Command
whoami
Expected Result: Your current Linux username is displayed.
19

Check Hostname

Command
hostname
Expected Result: The system hostname is displayed.
20

Check Kernel Information

Command
uname -a
Expected Result: Detailed system and kernel information is displayed.
21

Check System Uptime

Command
uptime
Expected Result: The amount of time the system has been running is displayed.
%

Task 8 — Check Disk and Memory Usage

22

Check Disk Space

Command
df -h
Expected Result: Used and available disk space is displayed in a human-readable format.
23

Check Memory Usage

Command
free -h
Expected Result: RAM and swap memory usage is displayed.
24

Check Running Processes

Command
top
Expected Result: The terminal displays active processes and system resource usage.
Important: The top command provides a live process view. Press q to exit the display.
🔐

Task 9 — Practice Permissions

25

Change File Permissions

The chmod command changes file permissions.
  1. Make sure you are working with a test file.
  2. Copy the command.
  3. Paste it into the terminal.
  4. Press Enter.
Command
chmod 600 notes.txt
Expected Result: The permissions of notes.txt are changed.
Safety Note: Only change permissions on your lab files. Do not modify important system files.
26

Use sudo for Authorized Privileges

The sudo command executes an authorized command with elevated privileges.
Example Command
sudo whoami
Expected Result: If your account is authorized to use sudo, the command runs with elevated privileges and the result is displayed.
Safety Note: Use sudo only for commands you understand and are authorized to execute.
