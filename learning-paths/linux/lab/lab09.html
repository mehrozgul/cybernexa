Lab 09 - Package Management

In this practical lab, you will learn how to update package repositories, search for packages, install software, check installed packages, upgrade packages and safely remove software using the APT package manager.

Platform Ubuntu / Debian Linux
Tool APT Package Manager
Level Beginner
📦

Lab Objective

The objective of this lab is to understand the basic practical use of Linux package management. You will use APT commands to manage software packages from the Linux terminal.

What You Will Practice Repository update, package search, package installation, package information, package upgrade and package removal.
01
$

Open the Linux Terminal

Open the Terminal application in your Ubuntu or Debian-based Linux system.

Instruction Press Ctrl + Alt + T to open the terminal.
Expected Result A Linux terminal window should appear and you should be ready to enter commands.
02
↻

Update Package Information

First, update the local package information from the configured software repositories.

Linux Terminal 
sudo apt update
Expected Result APT contacts the configured repositories and refreshes available package information.
03
?

Search for a Package

You can search the package repositories to find available software.

Linux Terminal 
apt search nginx
Explanation This command searches the configured package repositories for packages related to Nginx.
Expected Result A list of matching packages and their descriptions should be displayed.
04
i

View Package Information

Before installing software, you can view information about a package.

Linux Terminal 
apt show nginx
Expected Result Information such as package version, description, dependencies and package details should be displayed.
05
+

Install a Package

Now install the Nginx web server package using APT.

Linux Terminal 
sudo apt install nginx
Instruction If APT asks for confirmation, type Y and press Enter.
Expected Result APT downloads the required package and dependencies and installs Nginx.
Safety Note Only install packages from trusted repositories and verify the package name before confirming installation.
06
✓

Verify the Installation

After installation, verify that the Nginx package is installed on the system.

Linux Terminal 
apt list --installed 2>/dev/null | grep nginx
Expected Result The installed Nginx package should appear in the command output.
07
↑

Upgrade Installed Packages

APT can upgrade installed packages when newer versions are available in the repositories.

Linux Terminal 
sudo apt upgrade
Expected Result APT checks for available upgrades and installs them after confirmation.
Safety Note Review the packages that will be upgraded before confirming important system changes.
08
-

Remove a Package

APT can remove software packages that are no longer required.

Linux Terminal 
sudo apt remove nginx
Expected Result The Nginx package is removed from the system.
09
C

Remove Unused Dependencies

After removing software, some dependencies may no longer be required.

Linux Terminal 
sudo apt autoremove
Expected Result APT identifies packages that are no longer required and offers them for removal.
Safety Note Always review the removal list before confirming an autoremove operation.

Important APT Commands

sudo apt update Updates package repository information.
sudo apt upgrade Upgrades installed packages.
apt search package Searches for available packages.
apt show package Displays package information.
sudo apt install package Installs a package.
sudo apt remove package Removes a package.
sudo apt autoremove Removes unused dependencies.
apt list --installed Lists installed packages.

Why Package Management Matters in Cybersecurity

Package management is important in cybersecurity because Linux systems need regular security updates and vulnerability patches.

  • Security updates can fix known vulnerabilities.
  • Updated software reduces exposure to known security issues.
  • Trusted repositories help maintain software integrity.
  • Dependency management helps keep required software components organized.
  • Security professionals frequently use package managers when maintaining Linux systems.
