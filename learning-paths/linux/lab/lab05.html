Lab 05 - File Permissions

In this practical lab, you will create files, inspect Linux permissions, modify permissions using chmod, change ownership using chown, and verify the results from the terminal.

Difficulty Beginner
Platform Linux / Ubuntu
Focus File Security
✓

Lab Objectives

  • Understand Linux file permission notation.
  • Create and inspect files from the terminal.
  • Use ls -l to view permissions.
  • Change permissions using chmod.
  • Understand numeric permissions such as 755 and 644.
  • Understand basic file ownership using chown.
01

Step 1 — Create a Lab Directory

First create a separate directory for this practical.

Terminal 
mkdir permissions-lab
cd permissions-lab
Expected Result
You are now inside the permissions-lab directory.
02

Step 2 — Create a File

Create a simple text file that we will use throughout the practical.

Terminal 
touch secret.txt
echo "CyberNexa Linux Lab" > secret.txt
Verify File
ls
03

Step 3 — View File Permissions

Use ls -l to display the file permissions.

Terminal 
ls -l secret.txt
Example Output
-rw-r--r-- 1 user user 20 Sep 22 12:00 secret.txt
Understand the Permission String
  1. First character = file type
  2. Next three characters = owner permissions
  3. Next three characters = group permissions
  4. Last three characters = others permissions
R

Step 4 — Permission Values

Linux also uses numeric values to represent permissions.

Permission Symbol Numeric Value
Read r 4
Write w 2
Execute x 1
05

Step 5 — Change Permissions with chmod

Change the file permission so that only the owner can read and write the file.

Terminal 
chmod 600 secret.txt
ls -l secret.txt
Expected Permission
-rw------- secret.txt
Why 600?
  1. Owner = 6 = 4 + 2 = read + write
  2. Group = 0 = no permission
  3. Others = 0 = no permission
06

Step 6 — Make a Script Executable

Create a simple shell script and give the owner execute permission.

Terminal 
touch test.sh
echo '#!/bin/bash' > test.sh
echo 'echo "CyberNexa Lab"' >> test.sh

chmod u+x test.sh

ls -l test.sh
Expected Result
-rwx------ test.sh
Security Concept

Execute permission determines whether a file can be executed by a particular user category. Permissions should follow the principle of least privilege.

07

Step 7 — Use chmod Symbolic Mode

Linux also allows permissions to be changed using symbols.

chmod u+r file

Add read permission for the owner.

chmod u-w file

Remove write permission from the owner.

chmod g+r file

Add read permission for the group.

chmod o-r file

Remove read permission from others.

08

Step 8 — Set Standard 755 Permissions

Apply 755 permissions to the script.

Terminal 
chmod 755 test.sh
ls -l test.sh
Expected Permission
-rwxr-xr-x test.sh
Understand 755
  1. 7 = read + write + execute
  2. 5 = read + execute
  3. 5 = read + execute
09

Step 9 — Check File Ownership

Use ls -l to identify the owner and group of a file.

Terminal 
ls -l secret.txt
Important Fields
permissions → owner → group → filename
10

Step 10 — Change Ownership

If you have administrator privileges, ownership can be changed with chown.

Terminal 
sudo chown username secret.txt
Important

Replace username with an actual Linux user account. Do not change ownership of system files during this lab.

!

Practical Challenge

Complete the following tasks without looking at the previous commands.

Challenge Tasks
  1. Create a file named private.txt.
  2. Give the owner read and write permission only.
  3. Verify the permission using ls -l.
  4. Create a script named backup.sh.
  5. Give the script execute permission.
  6. Set the script permissions to 755.
  7. Verify the final permissions.
$

Quick Command Reference

ls -l

View detailed file information.

chmod 600 file

Owner read/write only.

chmod 755 file

Owner full access; group and others read/execute.

chmod +x file

Add execute permission.

chmod u+w file

Add write permission for the owner.

chown user file

Change file owner.

✓

Lab Completion

What You Should Know Now

You should now be able to read Linux permission strings, identify owner/group/others permissions, use ls -l, modify permissions using chmod, understand numeric permissions such as 600 and 755, and understand basic ownership management.
