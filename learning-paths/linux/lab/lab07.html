LINUX PRACTICAL LAB

Lab 07 - Linux Services

In this practical lab, you will learn how Linux processes work, identify running processes, inspect process information, monitor system activity and safely terminate processes using basic Linux commands.

Hands-On Lab • Beginner
🎯

Lab Objective

What You Will Practice By completing this lab, you will learn how to identify processes, view process IDs, monitor running processes, search for specific processes, inspect process trees and terminate processes using appropriate Linux commands.
⚙

Lab Requirements

01

Linux System

Ubuntu, Kali Linux, Debian or another Linux distribution.

02

Terminal

Open the Linux Terminal to execute process-management commands.

03

Sudo Access

Administrative access may be required for some process-management operations.

04

Basic Linux Knowledge

You should know how to open a terminal and execute basic Linux commands.

01

Step 1 — View Running Processes

The ps command displays information about currently running processes.

ps
Example Output 
    PID TTY          TIME CMD
   2145 pts/0    00:00:00 bash
   2198 pts/0    00:00:00 ps
02

Step 2 — View All Processes

Use ps aux to display processes from all users with detailed information.

ps aux
Important Columns 
USER     PID     %CPU     %MEM     COMMAND

USER     = Process owner
PID      = Process ID
%CPU     = CPU usage
%MEM     = Memory usage
COMMAND  = Process command
03

Step 3 — Find a Process by Name

The pgrep command searches for process IDs based on a process name.

pgrep bash
Example Output 
2145
Remember

The number returned by pgrep is the PID of the matching process.

04

Step 4 — Check Process ID

The pidof command can be used to find the PID of a running program.

pidof bash
Example Output 
2145
05

Step 5 — Monitor Processes in Real Time

The top command provides a continuously updated view of running processes and system resource usage.

top
Exit the Command

Press q to exit the top interface.

06

Step 6 — View Process Tree

The pstree command displays processes in a parent-child tree structure.

pstree
Example 
systemd
 ├─sshd
 │  └─bash
 │     └─pstree
 └─NetworkManager
Why This Matters

A process tree helps you understand which processes are parents and which processes were created by them.

07

Step 7 — Create a Test Process

Create a simple process using the sleep command. The process will remain active for 60 seconds.

sleep 60 &
Example Output 
[1] 3250
Background Process

The & symbol starts the command as a background process, allowing you to continue using the terminal.

08

Step 8 — Find the Test Process

Use pgrep to find the PID of the sleep process.

pgrep sleep
Example Output 
3250
09

Step 9 — Terminate a Process

The kill command sends a signal to a process. Use it with the PID of the test process created in the previous step.

kill 3250
Important

Replace 3250 with the actual PID returned on your system. Do not randomly terminate important system processes.

10

Step 10 — Check Process Status

Use the ps -p command to inspect a specific process by its PID.

ps -p 3250
Example 
    PID TTY          TIME CMD
   3250 pts/0    00:00:00 sleep
◉

Linux Process States

Linux processes can have different states. The STAT column in commands such as ps provides information about the current process state.

State Meaning Description
R Running Process is running or ready to run.
S Sleeping Process is waiting for an event.
D Uninterruptible Sleep Usually waiting for I/O.
T Stopped Process has been stopped.
Z Zombie Process has finished but still has an entry waiting for its parent.
ℹ

Important Process Information

PID

Process ID uniquely identifies a process while it exists.

PPID

Parent Process ID identifies the process that created the current process.

CPU Usage

Indicates how much processor time a process is using.

Memory Usage

Shows the amount of system memory being used by a process.

Cybersecurity Connection

Process management is an important part of Linux security. Security professionals monitor processes to identify unusual activity, unauthorized programs and resource abuse.

⚠

Security Note

Use Process Commands Carefully

Do not terminate processes simply because their names are unfamiliar. System processes may be required for Linux to operate correctly. Practice process termination only on processes that you created or clearly understand.
