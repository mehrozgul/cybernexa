LINUX PRACTICAL LAB

Lab 04 - Users & Groups

In this practical lab, you will create Linux users and groups, assign group membership, inspect UID/GID information and verify access using basic Linux commands.

Hands-On Lab • Beginner
🎯

Lab Objective

What You Will Practice By completing this lab, you will learn how to create users and groups, set a password, add a user to a secondary group, check UID/GID details, and verify the configuration.
⚙

Lab Requirements

01

Linux System

Ubuntu, Kali Linux, Debian or another Linux distribution.

02

Terminal

Open the Linux Terminal to execute the commands.

03

Sudo Access

Your account should have permission to execute administrative commands.

04

Basic Linux Knowledge

You should know how to open a terminal and execute basic commands.

01

Step 1 — Check Current User

First, check which user is currently logged into the Linux system.

whoami
Example Output 
student
02

Step 2 — Check User Information

The id command displays the current user's UID, primary GID and groups.

id
Example Output 
uid=1000(student) gid=1000(student) groups=1000(student),27(sudo)
03

Step 3 — Create a New User

Create a new Linux user named labuser.

sudo useradd labuser
Important

The command creates the account. A password should be assigned separately in the next step.

04

Step 4 — Set User Password

Assign a password to the newly created labuser account.

sudo passwd labuser
Expected Result 
New password:
Retype new password:
passwd: password updated successfully
05

Step 5 — Create a Group

Create a new group named developers.

sudo groupadd developers
Verification 
getent group developers
06

Step 6 — Add User to Group

Add labuser to the developers group.

sudo usermod -aG developers labuser
Why use -aG?

The -aG option adds the user to the supplementary group without removing the user's existing supplementary memberships.

07

Step 7 — Verify Group Membership

Check whether labuser is now a member of the developers group.

groups labuser
Example Output 
labuser : labuser developers
08

Step 8 — Check UID and GID

Use the id command to inspect the UID, primary GID and supplementary groups of the new user.

id labuser
Example Output 
uid=1001(labuser) gid=1001(labuser) groups=1001(labuser),1002(developers)
09

Step 9 — View User Database

Linux stores user account information in /etc/passwd.

grep '^labuser:' /etc/passwd
Example Output 
labuser:x:1001:1001::/home/labuser:/bin/sh
10

Step 10 — View Group Database

Check the entry for the developers group.

getent group developers
Example Output 
developers:x:1002:labuser

Your Practical Task

Now perform the following tasks yourself in your Linux terminal.

  • Create a user named student01.
  • Set a password for student01.
  • Create a group named cyberlab.
  • Add student01 to the cyberlab group.
  • Verify the group membership.
  • Display the UID and GID of the user.
  • Verify the group using getent.
✓

Final Verification

Run the following commands to verify that your practical lab configuration is correct.

id student01 groups student01 getent group cyberlab grep '^student01:' /etc/passwd
Expected Result

The output should show the user's UID, primary GID, the cyberlab group membership and the user's entry in /etc/passwd.

Cybersecurity Connection

User and group management is directly related to Linux security. Properly configured accounts help enforce authentication, authorization and least-privilege access.

Lab Summary

  • whoami identifies the current user.
  • id displays UID, GID and group information.
  • useradd creates a user account.
  • passwd sets or changes a password.
  • groupadd creates a new group.
  • usermod -aG adds a user to a secondary group.
  • groups displays group membership.
  • /etc/passwd contains user account information.
  • getent group can be used to verify group information.
