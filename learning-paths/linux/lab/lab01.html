Lab 01 — Linux Basics

In this practical lab, you will learn how to identify the current Linux user, navigate the file system, create a directory, create a file and verify your work using basic Linux commands.

Level Beginner
Category Ubuntu/Debian Linux
Lab 01 / Linux Basics
01

Open the Linux Terminal

What to do? Open your Linux terminal. If you are using Kali Linux or Ubuntu, open the Terminal application.
Expected: You should see a terminal window where you can type Linux commands.
02

Check the Current User

Where to write the command? Type the following command directly into your Linux terminal and press Enter.
whoami
Expected: Linux will display the username of the account currently being used.
03

Check Your Current Directory

What to do? Copy the command below, paste it into the terminal and press Enter.
pwd
Expected: The terminal displays the full path of your current working directory.
04

List Files and Directories

What to do? Use the following command to see the files and directories in your current location.
ls
Expected: Linux displays the files and directories available in the current location.
05

Create a Lab Directory

What to do? Create a new directory named cybernexa-lab. Copy the command and run it in the terminal.
mkdir cybernexa-lab
Expected: No error message normally means the directory was created successfully.
06

Enter the New Directory

What to do? Move into the directory you created in the previous step.
cd cybernexa-lab
Expected: Your terminal prompt changes to show that you are working inside the cybernexa-lab directory.
07

Create a File

What to do? Create an empty file named notes.txt inside your current directory.
touch notes.txt
Expected: The file notes.txt is created. The command normally produces no output when successful.
08

Verify the File

What to do? Use ls again to verify that notes.txt exists.
ls
Expected: You should see notes.txt in the output.
09

Verify Your Final Location

What to do? Finally, use pwd to confirm that you are inside the cybernexa-lab directory.
pwd
Expected: The displayed path should end with: /cybernexa-lab
Important: These commands should be executed in your own Linux practice environment such as Kali Linux, Ubuntu or another Linux system. Do not run commands on systems that you do not own or have permission to use.

Lab 01 Completion

If you have completed all the steps and verified the final result in your Linux terminal, click the button below to mark Lab 01 as completed.
