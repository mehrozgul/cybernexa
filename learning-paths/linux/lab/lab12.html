Lab 12 - Linux Security

In this practical lab, you will learn basic Linux security commands for checking users, permissions, file ownership, firewall status, SSH security, system updates and security-related logs.

Platform Ubuntu / Debian Linux
Focus Linux Security
Level Beginner
🔐

Lab Objective

The objective of this lab is to understand basic Linux security practices through practical terminal commands.

What You Will Practice User identification, permissions, ownership, sudo privileges, firewall status, SSH status, system updates and security logs.
01
$

Check Current User

The whoami command displays the username of the currently logged-in user.

Linux Terminal 
whoami
Expected Result Your current Linux username should be displayed.
02
U

Check User and Group Information

The id command displays the current user's UID, GID and group membership information.

Linux Terminal 
id
Expected Result The terminal displays your user ID, group ID and groups.
03
P

Check File Permissions

Linux uses permissions to control who can read, write or execute a file.

Linux Terminal 
ls -l
Understanding Permissions The output shows permissions for owner, group and others.
Expected Result Files and directories are displayed together with their permission information.
04
+

Create a Security Test File

Create a simple file that will be used to practice Linux permissions.

Linux Terminal 
touch security-test.txt
Expected Result A file named security-test.txt is created in the current directory.
05
#

Change File Permissions

The chmod command changes file permissions.

Linux Terminal 
chmod 600 security-test.txt
Meaning of 600 The owner gets read and write permission, while group and other users get no permissions.
Expected Result The file permissions should become -rw-------.
Security Note Restrictive permissions can help protect sensitive files from unauthorized access.
06
S

Check Sudo Privileges

The sudo -l command shows which commands the current user is allowed to run with sudo privileges.

Linux Terminal 
sudo -l
Expected Result Linux displays the sudo privileges available to the current user.
Safety Note Sudo provides elevated privileges. Run administrative commands only when required and understand their effect.
07
F

Check Firewall Status

Ubuntu commonly uses UFW (Uncomplicated Firewall) as a simple interface for firewall management.

Linux Terminal 
sudo ufw status
Expected Result The command displays whether UFW is active and lists configured firewall rules.
08
S

Check SSH Service Status

SSH is commonly used for secure remote administration. You can check whether the SSH service is running.

Linux Terminal 
sudo systemctl status ssh
Expected Result If SSH is installed, the terminal shows the current status of the SSH service.
Security Note If remote SSH access is not required, unnecessary remote services should not be exposed.
09
↑

Check Available System Updates

Keeping packages updated is an important part of Linux security because updates can include security fixes.

Linux Terminal 
sudo apt update
Next Step After updating package information, you can review available upgrades using:
Linux Terminal 
apt list --upgradable
Expected Result The system displays packages for which newer versions are available.
10
L

View Authentication Logs

Linux authentication logs can help security professionals investigate login and authentication-related events.

Linux Terminal 
sudo journalctl -u ssh --no-pager -n 20
Expected Result The terminal displays recent SSH service log entries when the SSH service exists.
Security Note Logs may contain sensitive system information. Do not share authentication logs publicly.
11
X

Find SUID Files

SUID is a Linux permission mechanism that allows a program to run with the permissions of its file owner.

Linux Terminal 
find /usr/bin -perm -4000 -type f 2>/dev/null
Expected Result The command displays files in /usr/bin that have the SUID permission set.
Security Note SUID programs should be reviewed carefully because incorrectly configured privileged programs can increase security risk.
12
C

Remove the Test File

After completing the permission exercise, remove the test file created during the lab.

Linux Terminal 
rm security-test.txt
Expected Result The temporary security-test.txt file is removed.

Important Linux Security Commands

whoami Shows the current username.
id Displays user and group information.

sudo -l Displays sudo privileges.
sudo ufw status Checks firewall status.

apt list --upgradable Lists packages with available updates.

Why Linux Security Matters

Linux security commands are important for cybersecurity professionals because they help administrators and security analysts inspect and protect Linux systems.

  • File permissions help control unauthorized access.
  • User and group information helps identify privileges.
  • Firewalls can control network traffic.
  • Security updates can fix known vulnerabilities.
  • SSH status helps identify remote administration services.
  • Logs help investigate system and authentication events.
  • SUID files should be reviewed because they can run with elevated privileges.
