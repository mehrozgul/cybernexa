John the Ripper

Learn how John the Ripper is used in authorized password-security auditing, password-hash analysis and security testing.

What is John the Ripper?

John the Ripper, commonly called John, is a password-security auditing tool. It can test password hashes against candidate passwords and is commonly used by security professionals to evaluate password strength in authorized environments.

A password is normally not stored directly by a secure system. Instead, a password hash may be stored. Password-auditing tools can test candidate passwords against that hash.

Why is John the Ripper Important?

Password Auditing

Organizations can test whether their own password policies allow weak passwords.

Hash Analysis

Security professionals can work with password hashes during authorized security assessments.

Security Awareness

It demonstrates why strong passwords and appropriate password storage mechanisms are important.

Defensive Testing

Administrators can identify weak credentials before attackers can exploit them.

How John the Ripper Works

At a high level, John follows a candidate-generation and verification process.

  1. A password hash is provided from an authorized test environment.
  2. John generates or receives candidate passwords.
  3. The candidate password is processed using the appropriate hashing algorithm.
  4. The resulting value is compared with the target hash.
  5. A matching value indicates that the candidate password corresponds to the tested hash.

Basic Command Structure

john [options] [password-file]

The exact options depend on the auditing task and the hash format being tested.

Useful John Commands

# Show John version
john --version

# Display supported formats
john --list=formats

# Show previously recovered passwords
john --show hashes.txt

These commands are useful for understanding the installed version, available formats and existing results in an authorized laboratory.

Password Security Concepts

Strong Password

Long, unique passwords reduce the effectiveness of password guessing attacks.

Password Hash

A hash is a one-way representation commonly used for password storage.

Salt

A unique salt helps prevent identical passwords from producing identical stored hashes.

Password Policy

Organizations can enforce length, uniqueness and other credential-security requirements.

Security Reminder

John the Ripper should only be used against password hashes that you own or have explicit authorization to audit. Do not use it against accounts, systems or credentials without permission.
