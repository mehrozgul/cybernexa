Burp Suite

Learn how Burp Suite is used to inspect, intercept and analyze HTTP/HTTPS traffic during authorized web security testing.

What is Burp Suite?

Burp Suite is a web application security testing platform developed by PortSwigger. It provides tools for examining HTTP requests and responses between a browser and a web application.

Security professionals commonly use it in an authorized testing environment to understand how an application communicates and to identify potential security issues.

Why is Burp Suite Important?

Modern web applications communicate heavily through HTTP and HTTPS. Burp Suite allows a security tester to see and analyze this communication instead of treating the browser as a black box.

Important Burp Suite Components

Proxy

Intercepts and displays browser HTTP/HTTPS traffic.

Repeater

Sends a selected HTTP request repeatedly so you can study different responses.

Intruder

Automates controlled variations of request parameters for authorized security testing.

Target

Helps organize and understand the web application's tested attack surface.

HTTP History

Shows requests and responses observed through the proxy.

Decoder

Helps encode, decode and transform common data representations.

Understanding an HTTP Request

A browser may send a request such as: 

GET /login HTTP/1.1
Host: lab.local
User-Agent: Browser
Accept: text/html

Burp Suite can display the request so a tester can inspect elements such as the HTTP method, URL path, headers and parameters.

Repeater Concept

Repeater is useful when you want to study one request in detail. A request can be sent to Repeater and then examined repeatedly while changing a permitted test value. 

GET /search?q=cybersecurity HTTP/1.1
Host: lab.local

Response:
HTTP/1.1 200 OK
Content-Type: text/html

In a local training application, you can change the q parameter and observe how the response changes.
