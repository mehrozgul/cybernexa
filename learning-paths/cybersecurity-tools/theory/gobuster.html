CYBERNEXA SECURITY TOOL

Gobuster

Learn how Gobuster can be used to discover directories, files and other resources on web applications during authorized security assessments.

$ gobuster

What is Gobuster?

Gobuster is a command-line security tool commonly used for directory and file enumeration on web servers. It can also support other enumeration modes such as DNS and virtual-host discovery.

Instead of manually guessing possible resource names, Gobuster can test entries from a wordlist and report resources that respond.

Why is Gobuster Used?

Web Enumeration

Helps identify directories and files that may not be directly linked from a website.

Security Testing

Can help security professionals identify exposed web resources during authorized testing.

Content Discovery

Uses a wordlist to test possible resource names efficiently.

Command-Line Workflow

Works well in Linux terminals and automated security-testing environments.

Basic Usage

A basic directory enumeration command follows this general structure: 

gobuster dir -u http://127.0.0.1:8000 -w wordlist.txt

Here, dir selects directory enumeration, -u specifies the target URL, and -w specifies the wordlist.

Important Options

-u

Specifies the target URL.

-w

Specifies the wordlist used for enumeration.

-x

Can be used to specify file extensions for content discovery.

-o

Can be used to save enumeration results to an output file.

Example

Suppose an authorized local web application contains directories such as: 

admin/
images/
login/
uploads/

A suitable wordlist can contain these possible names. Gobuster tests them against the local application and reports resources that respond.

Safe Learning Environment

Important:

Use Gobuster only against systems you own or have explicit permission to test. For this CyberNexa lab, use a local training server such as 127.0.0.1.
