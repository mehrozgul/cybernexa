What is Wireshark?

Wireshark is an open-source network protocol analyzer used to capture and inspect network traffic. It allows security professionals to examine individual packets and understand how devices communicate across a network.

Instead of looking at network communication as one large stream of data, Wireshark breaks the communication into packets and provides detailed information about protocols, addresses, ports and packet contents.

Why is Wireshark Important?

Network traffic contains valuable information about what systems are communicating, which protocols are being used and whether unusual traffic is present.

Network Troubleshooting Identify communication and protocol problems.
Security Monitoring Investigate suspicious network activity.
Protocol Analysis Understand TCP, UDP, DNS, HTTP and other protocols.
Incident Investigation Examine captured traffic during security investigations.
Learning Visualize how real network protocols work.
Traffic Analysis Find patterns inside network communications.

How Wireshark Works

Wireshark works by receiving captured network traffic from a supported network interface or capture file. It then decodes the packets and presents protocol information to the analyst.

STEP 01

Capture

Network packets are captured from an interface or opened from a capture file.

STEP 02

Decode

Wireshark identifies protocols and packet fields.

STEP 03

Filter

Display filters help isolate relevant traffic.

STEP 04

Analyze

The analyst investigates communication patterns and security indicators.

Important Wireshark Concepts

Packet A unit of network communication.
Protocol Rules used for communication between systems.
Source IP Address of the system sending traffic.
Destination IP Address of the receiving system.
Source Port Port associated with the sender's application.
Destination Port Port associated with the receiving service.

Basic Wireshark Display Filters

Display filters allow an analyst to focus on specific traffic instead of manually examining every packet.

ip.addr == 192.168.1.10

Display traffic involving a specific IP address.

dns

Display DNS traffic.

tcp

Display TCP packets.

udp

Display UDP packets.

tcp.port == 443

Display TCP traffic associated with port 443.

http

Display traffic identified as HTTP.

Wireshark in Cybersecurity

Security analysts can use Wireshark to investigate suspicious network behavior. For example, during an authorized investigation, an analyst may examine DNS requests, unusual connections, unexpected protocols or repeated communication patterns.

Example investigation: 1. Identify suspicious traffic 2. Find source and destination IPs 3. Identify the protocol 4. Examine source and destination ports 5. Apply display filters 6. Follow the relevant communication 7. Document the finding

Key Takeaways

  • Wireshark is a network protocol analyzer.
  • It allows analysts to inspect captured packets.
  • IP addresses, ports and protocols are important parts of packet analysis.
  • Display filters make traffic analysis faster.
  • Wireshark is useful for troubleshooting, monitoring and authorized security investigations.
