What is Netcat?

Netcat, commonly written as nc, is a command-line networking utility that can establish connections between systems using TCP or UDP.

It is often described as a networking utility rather than a single-purpose security tool because it can be useful for communication, troubleshooting, service testing and controlled security labs.

Why is Netcat Important?

Network Testing

Test whether a particular TCP service is reachable from a controlled machine.

TCP Communication

Create a simple TCP connection between two authorized systems.

Listening Services

Start a temporary local listener for testing network connectivity.

Troubleshooting

Quickly investigate whether a network service accepts connections.

Basic Netcat Usage

The general structure of a TCP connection is: 

nc [options] host port

For example, when testing a service running on your own machine: 

nc 127.0.0.1 8080

Here, 127.0.0.1 represents the local machine and 8080 represents the test port.

Creating a Local Listener

Netcat can listen for an incoming TCP connection. In a safe lab, use localhost or another machine that you own and control. 

nc -l 127.0.0.1 9000

The command creates a listener on the local machine using TCP port 9000.

Important:

Only use listeners and network connections on systems and ports that you are authorized to test.

Useful Netcat Options

Command Purpose
nc host port Connect to a TCP service.
nc -l port Listen for a connection.
nc -z host port Check whether a TCP port accepts a connection.
nc -v host port Show more connection information.
nc -u host port Use UDP instead of the default TCP mode.
