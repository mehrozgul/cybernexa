NMAP PRACTICAL LAB

Network Discovery Lab

Practice basic Nmap commands in a controlled localhost environment.

Before You Start

  1. Make sure Nmap is installed on your system.
  2. Use 127.0.0.1 for this beginner lab.
  3. Open a terminal such as Command Prompt, PowerShell or Linux Terminal.
  4. Run the commands only against systems you own or are authorized to test.

Interactive Command Practice

The browser cannot execute Nmap directly. This interface demonstrates the expected output for the selected safe practice command.

cybernexa@nmap-lab LAB MODE
$ Enter Nmap command

Type a supported localhost command and click "Run Command".

Host

127.0.0.1 represents the local machine.

Ports

Results depend on services currently running on the local system.

Services

Service detection can provide additional information when supported.

Lab Tasks

  1. Run a basic scan against localhost.
  2. Scan port 80.
  3. Scan ports 22, 80 and 443.
  4. Try service detection against localhost.
  5. Compare the results of the different commands.

Challenge

Use your own authorized virtual machine as a second lab target and compare its exposed services with localhost.

  • Record the open ports.
  • Identify which services are running.
  • Determine whether every exposed service is actually required.
