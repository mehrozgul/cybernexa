METASPLOIT PRACTICAL LAB

Metasploit Framework Lab

Learn the Metasploit console, module discovery and basic authorized penetration-testing workflow through a safe simulated environment.

Lab Progress 0%

Lab Objectives

  1. Understand the Metasploit console workflow.
  2. Learn how Metasploit modules are discovered.
  3. Practice basic module-information commands.
  4. Understand the difference between exploit and auxiliary modules.
  5. Work only inside an authorized training environment.

Metasploit Console Simulation

msfconsole — CyberNexa Training Environment
msf6 > _

Step-by-Step Commands

Step 01

msfconsole

Starts the Metasploit interactive console.

Step 02

help

Displays available console commands.

Step 03

search type:auxiliary

Searches the module database for auxiliary modules.

Step 04

show options

Displays configuration options for a selected module.

Step 05

info <module>

Displays information about a selected module.

Step 06

back

Returns to the previous console context.

Authorized Training Environment

Metasploit is a legitimate security-testing framework, but its exploitation capabilities can affect real systems. Use this lab only with localhost, intentionally vulnerable virtual machines, CTF targets, or systems for which you have explicit authorization.
