LINUX SECURITY LAB

Linux Tools Practical Lab

Practice essential Linux commands used for system inspection, file analysis, process monitoring and network visibility.

Lab Objectives

  1. Identify the current Linux user.
  2. Check the current working directory.
  3. List files and directories.
  4. Create and inspect a local security log.
  5. Search the log for failed events.
  6. Inspect running processes.
  7. Inspect network interfaces and listening sockets.

Command Reference

help Show available lab commands.
whoami Display the current user.
pwd Display current directory.
ls List files and directories.
cat security.log Display the sample security log.
grep failed security.log Search failed events.
ps Display sample running processes.
ip addr Display sample network interface information.
ss -tuln Display sample listening sockets.

Security Challenge

Use the available commands to investigate the simulated Linux environment.

  • Identify the current user.
  • Inspect the security log.
  • Search for failed login events.
  • Inspect running processes.
  • Inspect listening network services.
