NETCAT PRACTICAL LAB

TCP Client / Server Lab

Practice Netcat networking concepts using a controlled localhost environment. Learn how a listener and client communicate through a TCP port.

Lab Objectives

  1. Understand the difference between a listener and a client.
  2. Create a local TCP listener.
  3. Connect to the listener from another terminal.
  4. Send a simple test message.
  5. Verify the communication.

Step 1 — Start the Listener

Open a Linux terminal and run the following command. This example uses localhost and port 9000.

Terminal 1 — Listener
student@linux:~$ nc -l 127.0.0.1 9000 Waiting for a connection...

Step 2 — Connect as Client

Open a second terminal on the same Linux machine and connect to the local listener.

Terminal 2 — Client
student@linux:~$ nc 127.0.0.1 9000

Command Reference

nc -l 127.0.0.1 9000

Starts a TCP listener on localhost port 9000.

nc 127.0.0.1 9000

Connects to the local TCP listener.

nc -v 127.0.0.1 9000

Displays additional connection information.

nc -z 127.0.0.1 9000

Checks whether the TCP port is accepting connections.

Challenge

Extend the local lab by changing the test port from 9000 to 9001.

  • Start the listener on port 9001.
  • Connect the client to port 9001.
  • Send a custom message.
  • Verify that the listener receives it.
Security & Authorization

Use Netcat only on systems, hosts and network services that you own or are explicitly authorized to test. This lab intentionally uses localhost so the exercise remains controlled.
