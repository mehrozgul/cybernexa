PASSWORD SECURITY LAB

John the Ripper Lab

Practice the basic workflow of password-hash auditing using a deliberately created local laboratory example.

Lab Objective

  1. Understand what a password hash represents.
  2. Work with a deliberately created test hash.
  3. Understand how John processes candidate passwords.
  4. Observe the type of result produced by a password audit.
  5. Understand why strong passwords are important.

Authorized Laboratory Hash

TEST HASH
5f4dcc3b5aa765d61d8327deb882cf99

This is a deliberately provided educational test hash. Use only authorized laboratory data when performing password auditing.

John the Ripper Workflow

john@cybernexa:~$
john hashes.txt john --show hashes.txt

In a real authorized Linux laboratory, the hash would be stored in a test file and John would be used from the terminal. This browser lab demonstrates the workflow without executing John against external systems.

Click "Run Lab" to start the demonstration.

Challenge

After understanding the basic workflow, investigate these defensive questions in your own authorized environment:

  • Why should passwords not be stored as plain text?
  • Why are salts important for password storage?
  • How does password length affect resistance to guessing?
  • Why should password-auditing tools only be used with permission?
