GOBUSTER PRACTICAL LAB

Web Content Discovery Lab

Practice directory and file enumeration against a local training web server using Gobuster.

Lab Objective

  1. Start a local web server.
  2. Create a small training directory structure.
  3. Create a wordlist containing possible paths.
  4. Run Gobuster against the local server.
  5. Analyze the discovered resources.

Step 1 — Create Training Environment

Create a temporary directory for the lab:

mkdir -p ~/cybernexa-gobuster-lab/site

Move into the training website:

cd ~/cybernexa-gobuster-lab/site

Step 2 — Create Test Resources

Create directories that Gobuster can discover:

mkdir admin mkdir uploads mkdir login

Create a simple page:

echo "CyberNexa Local Training Server" > index.html

Create another test file:

echo "Training login page" > login/index.html

Step 3 — Create a Wordlist

Create a small wordlist containing possible resources:

printf "admin\nlogin\nuploads\nimages\nbackup\nconfig\n" > wordlist.txt

View the wordlist:

cat wordlist.txt

Step 4 — Start Local Web Server

From inside the site directory, start Python's local HTTP server:

python3 -m http.server 8000
LOCAL SERVER
Serving HTTP on 0.0.0.0 port 8000 ...

Keep this terminal running and use another terminal for Gobuster.

Step 5 — Run Gobuster

Run directory enumeration against your local server:

gobuster dir -u http://127.0.0.1:8000 -w wordlist.txt
GOBUSTER
$ gobuster dir -u http://127.0.0.1:8000 -w wordlist.txt =============================================================== Gobuster =============================================================== /admin (Status: 301) /login (Status: 301) /uploads (Status: 301) =============================================================== Finished ===============================================================

Step 6 — Understand the Results

/admin

Gobuster discovered the directory because "admin" existed in the wordlist.

/login

The login directory responded to the request.

/uploads

The uploads directory was also discovered.

301 Status

HTTP 301 indicates that the requested resource redirects to another location.

Step 7 — File Extension Enumeration

You can test selected extensions in an authorized local environment:

gobuster dir -u http://127.0.0.1:8000 -w wordlist.txt -x txt,html

Challenge

Expand the local training website and try to discover additional resources.

  • Create an images directory.
  • Create a backup directory.
  • Add their names to the wordlist.
  • Run Gobuster again.
  • Compare the new results with the previous scan.

Security Rule

Use Gobuster only against systems you own or have explicit authorization to test. This lab intentionally uses 127.0.0.1 so the enumeration stays inside your local training environment.
