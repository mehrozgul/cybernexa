CRYPTOGRAPHY PRACTICAL LAB

OpenSSL Lab

Practice OpenSSL commands for key generation, certificates, certificate inspection and hashing in a controlled local environment.

Lab Objectives

  1. Check whether OpenSSL is installed.
  2. Generate a local RSA private key.
  3. Create a self-signed test certificate.
  4. Inspect the certificate information.
  5. Generate a SHA-256 digest for a test file.

Step 01 — Check OpenSSL

TERMINAL COMMAND 
openssl version
EXPECTED OUTPUT
OpenSSL 3.x.x ...

Step 02 — Generate RSA Private Key

TERMINAL COMMAND 
openssl genrsa -out private.key 2048
RESULT
A private key file named: private.key will be created in the current directory.

Step 03 — Create Test Certificate

TERMINAL COMMAND 
openssl req -new -x509 \
-key private.key \
-out certificate.crt \
-days 365
RESULT
A self-signed certificate named: certificate.crt will be generated for the local learning environment.

Step 04 — Inspect Certificate

TERMINAL COMMAND 
openssl x509 -in certificate.crt -text -noout
INFORMATION TO OBSERVE
Subject Issuer Validity Public Key Signature Algorithm Certificate Extensions

Step 05 — Create Test File

LINUX COMMAND 
echo "CyberNexa OpenSSL Lab" > test.txt

Step 06 — Generate SHA-256 Digest

TERMINAL COMMAND 
openssl dgst -sha256 test.txt
EXPECTED FORMAT
SHA2-256(test.txt)= [64 hexadecimal characters]

Practice Task

  1. Generate a new RSA private key named cybernexa.key.
  2. Create a certificate named cybernexa.crt.
  3. Inspect the certificate.
  4. Create a text file called message.txt.
  5. Generate its SHA-256 digest.

Advanced Challenge

  1. Generate another SHA-256 digest after changing the contents of the test file.
  2. Compare the two digests.
  3. Explain why the digest changes when the file contents change.
  4. Inspect the certificate and identify its subject, issuer and validity period.
