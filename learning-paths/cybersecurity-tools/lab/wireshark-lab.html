WIRESHARK PRACTICAL LAB

Network Packet Analysis

Practice identifying protocols, IP addresses, ports and suspicious-looking traffic using a simulated packet-analysis environment.

Lab Objectives

  1. Understand the basic structure of a captured packet.
  2. Identify source and destination IP addresses.
  3. Identify protocols and ports.
  4. Apply Wireshark-style display filters.
  5. Investigate suspicious traffic patterns.

Packet Analysis Environment

Try filters such as: dns , tcp , http , udp or tcp.port == 443 .

Analyst Observations

DNS Look for unexpected domains or unusual DNS activity.
HTTPS Identify encrypted connections and their endpoints.
SSH Investigate unexpected SSH connections on port 22.

Advanced Challenge

Investigate the sample traffic and answer:

  • Which packet uses DNS?
  • Which packet uses HTTPS?
  • Which packet communicates using SSH?
  • Which source IP appears to initiate the SSH connection?
  • Which display filter would isolate TCP traffic?
