Python Functions

Learn how Python functions organize reusable code and help build clean, modular cybersecurity scripts.

What is a Function?

A function is a reusable block of code that performs a specific task. Instead of writing the same code repeatedly, we define it once and call it whenever needed. 

def greet():
    print("Welcome to CyberNexa")

greet()

Here, def is used to define a function. The function is executed when we call greet().

Why are Functions Important in Cybersecurity?

Cybersecurity scripts often perform repeated tasks such as checking ports, validating input, processing logs or testing multiple systems. Functions make these tasks reusable and easier to maintain.

Code Reusability

Write a task once and use it multiple times.

Modular Code

Divide a large security script into smaller tasks.

Easy Maintenance

Changes can be made inside one function.

Better Organization

Functions keep cybersecurity scripts structured.

Function Syntax

A basic Python function follows this structure: 

def function_name():
    # code
    pass
  • def starts the function definition.
  • function_name is the name of the function.
  • Parentheses () contain parameters if needed.
  • Indented code forms the function body.

Functions with Parameters

Parameters allow us to pass data into a function. 

def check_port(port):
    print("Checking port:", port)

check_port(22)
check_port(443)

In this example, port is a parameter. The values 22 and 443 are passed to the function.

Returning a Value

A function can return a result using the return statement. 

def is_secure(port):
    if port == 443:
        return True
    return False

result = is_secure(443)

print(result)
Output: True

Cybersecurity Example

Functions can be used to identify commonly used secure and insecure network ports. 

def check_port(port):

    if port == 443:
        return "HTTPS - Secure Web Traffic"

    elif port == 22:
        return "SSH - Secure Remote Access"

    elif port == 80:
        return "HTTP - Unencrypted Web Traffic"

    else:
        return "Unknown Port"


print(check_port(443))
print(check_port(80))
HTTPS - Secure Web Traffic
HTTP - Unencrypted Web Traffic

Functions with Multiple Parameters

A function can accept more than one parameter. 

def scan_target(ip, port):

    print("Target IP:", ip)
    print("Target Port:", port)


scan_target("192.168.1.10", 443)

Default Parameters

A parameter can have a default value. If no value is provided, Python uses the default value. 

def scan_port(port=443):

    print("Scanning port:", port)


scan_port()
scan_port(22)

Common Function Types

No Parameters

def start():
    print("Start")

With Parameters

def scan(ip):
    print(ip)

With Return

def add(a, b):
    return a + b

Default Parameter

def scan(port=443):
    print(port)

Summary

  • A function is a reusable block of code.
  • Functions are created using the def keyword.
  • Parameters allow functions to receive data.
  • The return statement sends a result back.
  • Functions make cybersecurity scripts reusable, organized and easier to maintain.
