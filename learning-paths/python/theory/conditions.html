Python Conditions

Learn how Python conditions make decisions and control the behavior of cybersecurity programs.

What are Conditions?

Conditions allow a Python program to make decisions. The program checks whether a condition is True or False and then executes the appropriate block of code. 

port = 443

if port == 443:
    print("HTTPS is being used")

Here, Python checks whether the value of port is equal to 443. If the condition is True, the message is displayed.

Why are Conditions Important in Cybersecurity?

Cybersecurity scripts frequently need to make decisions. For example, a script may check whether a port is open, whether a login is successful, or whether a security risk is high.

Port Checking

Check whether a particular port is open.

Login Status

Check whether authentication succeeded.

Risk Detection

Identify whether a security score is high.

Access Control

Decide whether a user should receive access.

if Statement

The if statement executes code only when its condition is True. 

port = 443

if port == 443:
    print("Secure HTTPS port")
Output: Secure HTTPS port

else Statement

The else block executes when the if condition is False. 

port = 80

if port == 443:
    print("HTTPS")
else:
    print("Not HTTPS")
Output: Not HTTPS

elif Statement

The elif statement is used when there are multiple conditions to check. 

port = 22

if port == 80:
    print("HTTP")
elif port == 443:
    print("HTTPS")
elif port == 22:
    print("SSH")
else:
    print("Unknown port")
Output: SSH

Logical Operators

Logical operators combine multiple conditions.

and

True when both conditions are True. 

port == 443 and secure == True

or

True when at least one condition is True. 

port == 80 or port == 443

not

Reverses the Boolean result. 

not blocked

Nested Conditions

A condition inside another condition is called a nested condition. 

logged_in = True
admin = True

if logged_in:

    if admin:
        print("Admin access granted")
    else:
        print("User access granted")

else:
    print("Login required")

Cybersecurity Example

Conditions can be used to classify a security risk based on a risk score. 

risk_score = 85

if risk_score >= 80:
    print("High Risk")
elif risk_score >= 50:
    print("Medium Risk")
else:
    print("Low Risk")
Output: High Risk

Practical Port Example

A simple security script can classify commonly used network ports. 

port = 22

if port == 22:
    print("SSH service")
elif port == 80:
    print("HTTP service")
elif port == 443:
    print("HTTPS service")
else:
    print("Unknown service")
Output: SSH service

Summary

  • if checks a condition.
  • else executes when the condition is False.
  • elif allows multiple conditions.
  • Comparison operators produce True or False.
  • Logical operators combine conditions.
  • Conditions are important for cybersecurity decision-making.
