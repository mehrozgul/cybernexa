Python Sockets

Learn how Python sockets allow programs to communicate with systems over a network using IP addresses and ports.

What is a Socket?

A socket is a communication endpoint that allows two programs to communicate over a network.

In cybersecurity, sockets are useful for understanding network communication, testing services and building network security tools. 

import socket

s = socket.socket()

print("Socket created")

Why are Sockets Important in Cybersecurity?

Security tools frequently communicate with network services. Python sockets provide a low-level way to understand and work with this communication.

Port Checking

Test whether a service is accepting connections on a specific TCP port.

Network Communication

Allow programs to exchange data through a network.

Service Testing

Help security professionals test network services in authorized environments.

Security Tools

Sockets are a building block for many network security scripts.

IP Address and Port

Network communication commonly uses an IP address together with a port number. 

target = "127.0.0.1"
port = 80

print("Target:", target)
print("Port:", port)

Here, 127.0.0.1 represents the local computer and 80 represents the HTTP port.

TCP Socket

TCP is connection-oriented. A TCP socket can be created using SOCK_STREAM. 

import socket

s = socket.socket(
    socket.AF_INET,
    socket.SOCK_STREAM
)

print("TCP socket created")

UDP Socket

UDP is connectionless and generally has less overhead than TCP. Python creates a UDP socket using SOCK_DGRAM. 

import socket

s = socket.socket(
    socket.AF_INET,
    socket.SOCK_DGRAM
)

print("UDP socket created")

Connecting to a Service

The connect() method attempts to establish a connection to a specified IP address and port. 

import socket

target = "127.0.0.1"
port = 80

s = socket.socket(
    socket.AF_INET,
    socket.SOCK_STREAM
)

s.settimeout(2)

try:
    s.connect((target, port))
    print("Port is open")
except:
    print("Connection failed")
finally:
    s.close()

Cybersecurity Example

A basic authorized security check can test whether a specific TCP service is reachable. 

import socket

target = "127.0.0.1"
port = 22

s = socket.socket(
    socket.AF_INET,
    socket.SOCK_STREAM
)

s.settimeout(2)

result = s.connect_ex((target, port))

if result == 0:
    print("SSH service is reachable")
else:
    print("SSH service is not reachable")

s.close()

Important Socket Methods

socket()

Creates a socket object.

connect()

Attempts to connect to a remote endpoint.

connect_ex()

Returns an error code instead of directly raising a connection exception.

close()

Closes the socket connection.

Summary

  • A socket is a network communication endpoint.
  • Python provides the built-in socket module.
  • TCP uses SOCK_STREAM.
  • UDP uses SOCK_DGRAM.
  • IP addresses identify hosts and ports identify services.
  • Sockets are useful for authorized network security testing.
