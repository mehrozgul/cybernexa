Python File Handling

Learn how Python reads, creates, writes and manages files and how file handling can be used in cybersecurity tasks.

What is File Handling?

File handling means working with files through a program. Python provides built-in functions that allow us to create, open, read, write and update files.

file = open("security.txt", "r")

content = file.read()

file.close()

print(content)

In this example, Python opens a file, reads its contents, closes the file and displays the stored information.

Why is File Handling Important in Cybersecurity?

Cybersecurity tools frequently work with files. Security analysts may need to read logs, save scan results, process suspicious files or create reports.

Log Files

Read system or security logs for investigation.

Scan Results

Save network or security scan results.

Security Reports

Generate reports containing security findings.

Configuration

Read configuration information stored in files.

Opening a File

Python uses the open() function to open a file.

file = open("security.txt", "r")

The first argument is the file name and the second argument specifies how the file should be opened.

Common File Modes

r — Read

Opens an existing file for reading.

open("log.txt", "r")

w — Write

Writes data to a file. Existing content can be replaced. 

open("report.txt", "w")

a — Append

Adds new data to the end of a file. 

open("log.txt", "a")

x — Create

Creates a new file. 

open("newfile.txt", "x")

Reading a File

The read() method reads the contents of a file. 

file = open("security.txt", "r")

data = file.read()

file.close()

print(data)

Reading Lines

Python also provides methods for reading individual lines or all lines from a file. 

file = open("security.txt", "r")

lines = file.readlines()

file.close()

for line in lines:
    print(line)

Writing to a File

The w mode allows us to write information into a file. 

file = open("security_report.txt", "w")

file.write("Security scan completed.")

file.close()

Appending Data

The a mode adds new information without removing existing content. 

file = open("security.log", "a")

file.write("Login attempt detected.\n")

file.close()

Using the with Statement

The with statement is the recommended way to work with files because Python automatically closes the file after the block finishes. 

with open("security.txt", "r") as file:

    data = file.read()

    print(data)

Cybersecurity Example

A security script can read a log file and search for suspicious login activity. 

with open("login.log", "r") as file:

    logs = file.read()

if "failed" in logs.lower():

    print("Possible failed login activity detected.")

else:

    print("No failed login activity found.")

Saving Security Results

Security scripts can also save their results into a report file. 

ip = "192.168.1.10"
port = 443
status = "OPEN"

with open("scan_report.txt", "w") as file:

    file.write("Security Scan Report\n")
    file.write("IP: " + ip + "\n")
    file.write("Port: " + str(port) + "\n")
    file.write("Status: " + status + "\n")

Important: File Errors

A program may produce an error if the requested file does not exist or cannot be accessed. These errors can later be handled using Python exception handling. 

try:

    with open("security.log", "r") as file:
        data = file.read()

except FileNotFoundError:

    print("File was not found.")

Summary

  • File handling allows Python to work with files.
  • r is used for reading.
  • w is used for writing.
  • a is used for appending.
  • x is used for creating a new file.
  • read() reads file contents.
  • write() writes data into a file.
  • The with statement automatically closes files.
  • File handling is useful for logs, reports and security data.
