Python Lists & Dictionaries

Learn how Python lists and dictionaries store multiple values and how they can be used in cybersecurity scripts.

What is a List?

A list is a Python data structure used to store multiple values in a single variable. Lists are ordered, changeable, and can contain different types of data. 

ports = [22, 53, 80, 443]

print(ports)

In this example, the variable ports contains four network port numbers.

Accessing List Items

Python lists use indexing. The first item has index 0. 

ports = [22, 53, 80, 443]

print(ports[0])
print(ports[2])
Output: 22
Output: 80

Adding and Changing List Items

Lists are mutable, which means their values can be changed after the list is created. 

ports = [22, 80, 443]

ports.append(8080)

ports[1] = 8081

print(ports)
Output: [22, 8081, 443, 8080]

Useful List Methods

append()

Adds an item to the end of a list.

remove()

Removes a specific item from a list.

sort()

Sorts the items in a list.

len()

Returns the number of items.

Cybersecurity Example Using a List

A list can store multiple IP addresses, ports, usernames, URLs, or security findings. 

target_ips = [
    "192.168.1.10",
    "192.168.1.20",
    "192.168.1.30"
]

for ip in target_ips:
    print("Scanning:", ip)

What is a Dictionary?

A dictionary stores data in key-value pairs. Each key is used to access its corresponding value. 

target = {
    "ip": "192.168.1.10",
    "port": 443,
    "protocol": "HTTPS"
}

print(target["ip"])
Output: 192.168.1.10

Dictionary Structure

Key

A unique name used to identify a value.

Value

The actual information stored against a key.

IP

Can store a target IP address.

Port

Can store a target network port.

Adding and Changing Dictionary Values

target = {
    "ip": "192.168.1.10",
    "port": 80
}

target["port"] = 443

target["protocol"] = "HTTPS"

print(target)
Output: {'ip': '192.168.1.10', 'port': 443, 'protocol': 'HTTPS'}

Useful Dictionary Methods

keys()

Returns all dictionary keys.

values()

Returns all dictionary values.

items()

Returns key-value pairs.

get()

Safely retrieves a value using a key.

List vs Dictionary

List

Stores multiple values in an ordered sequence and uses indexes to access items. 

ports = [22, 80, 443]

Dictionary

Stores information using meaningful key-value pairs. 

target = {
    "port": 443
}

Practical Cybersecurity Example

Lists and dictionaries can work together to represent information about multiple systems. 

targets = [
    {
        "ip": "192.168.1.10",
        "port": 443,
        "service": "HTTPS"
    },
    {
        "ip": "192.168.1.20",
        "port": 22,
        "service": "SSH"
    }
]

for target in targets:
    print("IP:", target["ip"])
    print("Port:", target["port"])
    print("Service:", target["service"])
    print()

Summary

  • A list stores multiple values in an ordered collection.
  • List items are accessed using indexes.
  • Lists can be modified using methods such as append().
  • A dictionary stores data using key-value pairs.
  • Dictionary values are accessed using their keys.
  • Cybersecurity scripts commonly use lists for multiple targets and dictionaries for structured information.
