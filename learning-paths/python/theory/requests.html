Python Requests

Learn how Python can communicate with web servers, send HTTP requests and inspect web responses using the Requests library.

What is Requests?

Requests is a popular Python library used to send HTTP requests to web servers. It makes it easier to communicate with websites and web APIs. 

import requests

response = requests.get("https://example.com")

print(response.status_code)

In this example, Python sends a GET request to the server and stores the server response inside the response variable.

Why is Requests Important in Cybersecurity?

Security professionals often need to communicate with websites and APIs. The Requests library can be used for safe HTTP testing, security automation, API interaction and collecting information from authorized systems.

HTTP Testing

Send requests to an authorized web application and inspect its response.

Status Codes

Check HTTP status codes such as 200, 404 and 500.

Headers

Read HTTP response headers during security analysis.

Automation

Automate repetitive HTTP-based security tasks.

Installing Requests

Requests is an external Python library. It can be installed using pip. 

pip install requests

After installation, import the library using: 

import requests

GET Request

A GET request is commonly used to retrieve information from a web server. 

import requests

url = "https://example.com"

response = requests.get(url)

print(response.status_code)
Example Output: 200

A status code of 200 generally means that the HTTP request was successful.

HTTP Status Code

The response object contains the HTTP status code returned by the server. 

import requests

response = requests.get("https://example.com")

print(response.status_code)

200

Request successful.

404

Requested resource was not found.

403

Server understood the request but access is forbidden.

500

Internal server error.

Reading Response Headers

HTTP headers contain additional information about the server response. 

import requests

response = requests.get("https://example.com")

print(response.headers)

Headers can provide information such as content type, server behavior and other HTTP metadata.

Reading Response Content

The response body can be accessed through response.text. 

import requests

response = requests.get("https://example.com")

print(response.text)

Using a Timeout

A timeout prevents a program from waiting indefinitely for a server response. 

import requests

response = requests.get(
    "https://example.com",
    timeout=5
)

print(response.status_code)

In this example, the request will wait up to 5 seconds for a response.

Cybersecurity Example

During authorized security analysis, Requests can be used to check whether a web service is reachable and inspect its HTTP response. 

import requests

target = "https://example.com"

response = requests.get(
    target,
    timeout=5
)

print("Target:", target)
print("Status:", response.status_code)

if response.status_code == 200:
    print("Web service is responding.")
else:
    print("Web service returned another status.")

Security Note

  • Only send requests to systems you own or are authorized to test.
  • Use reasonable request rates during security testing.
  • Avoid testing third-party systems without permission.
  • Use timeouts to make security scripts more reliable.

Summary

  • Requests is a Python library for HTTP communication.
  • It can send GET and other HTTP requests.
  • Response status codes help understand server responses.
  • Response headers provide additional HTTP information.
  • Requests can be useful for cybersecurity automation.
  • Security testing should only be performed on authorized systems.
