Python Variables

Learn how variables store and manage data in Python and how they are used in cybersecurity scripts.

What is a Variable?

A variable is a name that refers to a value stored in a Python program. Variables allow us to store information and use that information later. 

username = "admin"
port = 22
is_active = True

Here, username, port and is_active are variables.

Why are Variables Important in Cybersecurity?

Cybersecurity scripts work with changing information. Variables allow us to store IP addresses, ports, usernames, URLs, file names and security results.

IP Address

Store a target or source IP address.

Port

Store a network port number.

Username

Store a username used by a security script.

URL

Store a website address for HTTP requests.

Creating Variables

Python does not require a separate variable declaration. We simply assign a value to a name. 

name = "Gul"
age = 20
port = 443
secure = True

Common Variable Data Types

String

Used to store text. 

ip = "192.168.1.10"

Integer

Used for whole numbers. 

port = 443

Float

Used for decimal numbers. 

risk_score = 8.5

Boolean

Represents True or False. 

online = True

Changing a Variable

A variable can be assigned a new value at any time. 

port = 80

port = 443

print(port)
Output: 443

Multiple Variables

Python also allows multiple variables to be assigned in a single statement. 

ip, port, protocol = "192.168.1.10", 443, "HTTPS"

print(ip)
print(port)
print(protocol)

Cybersecurity Example

Variables can store information about a target system during a security task. 

target_ip = "192.168.1.10"
target_port = 443
protocol = "HTTPS"

print("Target:", target_ip)
print("Port:", target_port)
print("Protocol:", protocol)
Target: 192.168.1.10
Port: 443
Protocol: HTTPS

Variable Naming Rules

  • Variable names can contain letters, numbers and underscores.
  • A variable name cannot start with a number.
  • Variable names are case-sensitive.
  • Python keywords should not be used as variable names.
  • Use meaningful names to make the code easier to understand. 
target_ip = "192.168.1.10"
port_443 = 443

# Invalid
# 443port = 443

Variables in a Security Script

A simple security script can use variables to describe a target and the security information being processed. 

target = "192.168.1.10"
port = 22
service = "SSH"
status = "OPEN"

print("Target:", target)
print("Port:", port)
print("Service:", service)
print("Status:", status)

Summary

  • A variable stores or refers to a value.
  • Python variables do not need explicit declaration.
  • Variables can store strings, integers, floats and Booleans.
  • Variables can be changed during program execution.
  • Cybersecurity scripts use variables for IPs, ports, URLs, usernames and security results.
