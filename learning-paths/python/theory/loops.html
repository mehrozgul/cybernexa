Python Loops

Learn how Python loops repeat tasks and how loops are used in cybersecurity automation and security scripts.

What is a Loop?

A loop is a programming structure used to repeat a block of code multiple times.

Instead of writing the same code again and again, we can use a loop to perform the same task automatically. 

for number in range(5):
    print(number)
Output:
0
1
2
3
4

Why are Loops Important in Cybersecurity?

Cybersecurity tasks often require the same operation to be performed on many items.

Port Scanning

Check multiple ports on a target system.

IP Addresses

Process multiple IP addresses automatically.

Log Analysis

Process many log entries one by one.

Automation

Repeat security tasks without manually executing every step.

Types of Loops in Python

Loop Purpose
for loop Used when we want to iterate through a sequence or repeat a task a known number of times.
while loop Used when a task should continue while a condition remains True.

1. for Loop

A for loop is commonly used when we want to process each item in a sequence. 

for i in range(5):
    print(i)

The range(5) generates numbers from 0 up to, but not including, 5.

Using range()

The range() function is frequently used with for loops. 

for port in range(20, 26):
    print(port)
Output:
20
21
22
23
24
25

This type of loop can be useful when working with a defined range of ports in a security lab.

2. while Loop

A while loop repeats code as long as its condition remains True. 

count = 1

while count <= 5:
    print(count)
    count += 1
Output:
1
2
3
4
5

break Statement

The break statement immediately stops the loop. 

for port in range(1, 10):

    if port == 5:
        break

    print(port)
Output:
1
2
3
4

continue Statement

The continue statement skips the current iteration and moves to the next iteration. 

for port in range(1, 6):

    if port == 3:
        continue

    print(port)
Output:
1
2
4
5

Loop Through a List

A loop can process each item in a Python list. 

ports = [22, 80, 443]

for port in ports:
    print("Checking port:", port)
Output:
Checking port: 22
Checking port: 80
Checking port: 443

Cybersecurity Example

A simple security script can use a loop to check a list of commonly used ports. 

ports = [21, 22, 80, 443, 3389]

for port in ports:

    print("Checking port:", port)

This is a basic example of automation. Real port scanning requires networking libraries and appropriate authorization.

Nested Loops

A nested loop is a loop placed inside another loop. 

for ip in ["192.168.1.10", "192.168.1.20"]:

    for port in [22, 80, 443]:

        print(ip, port)

Nested loops can be useful for processing multiple hosts and multiple ports in a controlled lab.

Common Mistakes

  • Forgetting the colon : after the loop condition.
  • Incorrect indentation inside the loop.
  • Creating an infinite while loop.
  • Using the wrong range value.
  • Forgetting to update the variable in a while loop.

Summary

  • A loop repeats a block of code.
  • Python mainly provides for and while loops.
  • for loops are useful for iterating through sequences and ranges.
  • while loops continue while a condition is True.
  • break stops a loop.
  • continue skips the current iteration.
  • Loops are extremely useful for cybersecurity automation.
