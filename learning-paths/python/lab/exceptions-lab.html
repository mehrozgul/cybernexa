Exceptions Lab

Practice handling errors safely in a cybersecurity script using Python exception handling.

Lab Task

  1. Create a variable containing a port number.
  2. Convert the value into an integer.
  3. Use try and except to handle invalid input.

  5. Display an appropriate security message.
