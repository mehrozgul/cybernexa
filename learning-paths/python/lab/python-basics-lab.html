PRACTICAL LAB 01

Python Basics Lab

Practice the basic Python syntax used to create simple cybersecurity scripts.

Lab Objective

In this lab, you will create a simple Python script that stores cybersecurity information and displays it on the screen.

Lab Task

Complete the following steps:

  1. Open your Python environment such as VS Code, IDLE or PyCharm.
  2. Create a file named python_basics.py.
  3. Create variables for an IP address, port and protocol.
  4. Display the values using print().
  5. Run the Python program.

Starter Code

PYTHON 
target_ip = "192.168.1.10"
target_port = 443
protocol = "HTTPS"

print("Target IP:", target_ip)
print("Target Port:", target_port)
print("Protocol:", protocol)
EXPECTED OUTPUT Target IP: 192.168.1.10 Target Port: 443 Protocol: HTTPS

Mini Challenge

Modify the program and create your own cybersecurity-related variables.

Your Task

  1. Create a variable named username.
  2. Create a variable named service.
  3. Create a variable named status.
  4. Print all three values.
