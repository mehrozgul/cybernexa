Security Scripts Lab

Build a simple Python security script that analyzes failed login attempts and generates a security report.

Lab Task

  1. Create a security log containing login events.
  2. Read and analyze the log.
  3. Count failed login attempts.
  4. Generate a security warning when attempts reach the defined threshold.
  5. Save the result into security_report.txt.

Python Environment

OUTPUT
Click "Run Code" to execute the lab.

Challenge

Improve the security script so that it also displays the usernames associated with failed login attempts.

  • Store usernames in the log.
  • Identify failed login entries.
  • Count the failed attempts.
  • Display the affected usernames.
  • Save the final result in the report file.
