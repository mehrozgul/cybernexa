Python Loops Lab

Practice for loops, while loops, range(), break and continue using simple cybersecurity examples.

Lab 01 — for Loop

Use a for loop to print numbers from 1 to 5. 

for number in range(1, 6):
    print(number)
Output: 1 2 3 4 5
Task: Change the range so that the program prints numbers from 1 to 10.

Lab 02 — Security Ports

Use a loop to display common cybersecurity ports. 

ports = [22, 80, 443, 3389]

for port in ports:
    print("Checking port:", port)
Output: Checking port: 22 Checking port: 80 Checking port: 443 Checking port: 3389
Task: Add port 53 to the list and run the program in Python.

Lab 03 — while Loop

Use a while loop to count from 1 to 5. 

count = 1

while count <= 5:
    print(count)
    count += 1
Output: 1 2 3 4 5
Task: Modify the program so that it counts from 1 to 10.

Lab 04 — break

Stop the loop when the port reaches 443. 

ports = [22, 80, 443, 8080]

for port in ports:

    if port == 443:
        break

    print("Checking:", port)
Output: Checking: 22 Checking: 80
Task: Understand why port 443 is not printed.

Lab 05 — continue

Skip port 80 and continue with the remaining ports. 

ports = [22, 80, 443]

for port in ports:

    if port == 80:
        continue

    print("Checking:", port)
Output: Checking: 22 Checking: 443
Task: Change the program to skip port 22 instead.

Final Challenge — Port Checking

Create your own Python program that loops through the following ports: 

ports = [21, 22, 53, 80, 443, 3389]
Your Task:

1. Use a for loop.
2. Print every port.
3. If the port is 443, print "HTTPS detected".
4. If the port is 22, print "SSH detected". 
ports = [21, 22, 53, 80, 443, 3389]

for port in ports:

    print("Checking port:", port)

    if port == 22:
        print("SSH detected")

    if port == 443:
        print("HTTPS detected")
Expected Output: Checking port: 21 Checking port: 22 SSH detected Checking port: 53 Checking port: 80 Checking port: 443 HTTPS detected Checking port: 3389
