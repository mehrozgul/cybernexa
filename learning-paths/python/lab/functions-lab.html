LEVEL Beginner

Lab Task

Write a Python function that receives a network port and returns information about the port.

Task 1: Create a function named check_port(port).
Task 2: If the port is 443, return HTTPS - Secure Web Traffic.
Task 3: If the port is 22, return SSH - Secure Remote Access.
Task 4: For any other port, return Unknown Port.
