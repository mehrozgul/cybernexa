Python Variables Lab

Practice creating variables and storing cybersecurity information such as IP addresses, ports, protocols and security status.

Lab Objective

Create Python variables for a fictional cybersecurity target and display their values.

  • Create a variable named target_ip.
  • Store 192.168.1.10 in it.
  • Create a variable named target_port.
  • Store 443 in it.
  • Create a variable named protocol and store HTTPS.
  • Create a Boolean variable named secure and set it to True.
  • Print all four values.
