Requests Lab

Practice sending an HTTP GET request and inspecting the response returned by a web server.

Lab Task

  1. Import the requests library.
  2. Store an authorized website URL in a variable.
  3. Send a GET request using requests.get().
  4. Display the HTTP status code.
  5. Display whether the web service responded successfully.

Challenge

Modify the Python program so that it also displays useful information about the HTTP response.

  • Display the status code.
  • Display the response content type.
  • Use a timeout of 5 seconds.
