What is MAC Address?

A MAC address is a unique hardware identifier associated with a network interface. It is used for communication between devices on a local network.

#

Quick Definition

What is a MAC Address? MAC stands for Media Access Control. A MAC address is a hardware-level identifier assigned to a network interface and is commonly used to identify devices on a local network.
@

MAC Address Format

A MAC address is normally represented as six groups of two hexadecimal digits. The groups are separated using colons, hyphens, or sometimes no separators.

Common Example
00:1A:2B:3C:4D:5E

Hexadecimal

MAC addresses use hexadecimal digits from 0–9 and A–F.

6 Groups

A traditional MAC address contains six groups of two hexadecimal digits.

48 Bits

A standard MAC address is 48 bits long.

PC

MAC Address Example

Every network interface can have its own MAC address. For example, a laptop's Ethernet adapter and Wi-Fi adapter can have different MAC addresses.

Wi-Fi Adapter

The wireless network interface can have its own MAC address.

Example
3C:52:82:1A:7B:90

Ethernet Adapter

A wired Ethernet interface can have a different MAC address.

Example
00:25:96:FF:12:34
⇄

MAC Address vs IP Address

MAC addresses and IP addresses are both used in networking, but they serve different purposes.

Feature MAC Address IP Address
Meaning Media Access Control Internet Protocol
Purpose Identifies a network interface Identifies a device/interface logically on a network
Layer Data Link Layer Network Layer
Example 00:1A:2B:3C:4D:5E 192.168.1.10
Format Hexadecimal Decimal or hexadecimal depending on IP version
◎

Why MAC Address Matters

MAC addresses play an important role in local network communication and network administration.

Local Communication

MAC addresses are used when devices communicate within a local network.

Switch Forwarding

Network switches use MAC address information to forward Ethernet frames.

Network Management

Administrators can use MAC addresses to identify network interfaces and connected devices.

Access Control

MAC addresses can be used in certain network access-control and filtering configurations.
