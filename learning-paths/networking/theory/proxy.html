What is Proxy?

A proxy server acts as an intermediary between a client and a destination service. It can forward requests, control traffic and provide additional privacy and security functions.

◇

Quick Definition

What is a Proxy? A proxy server is an intermediary that receives requests from a client and forwards them to another server or service on behalf of the client.
→

How a Proxy Works

When a client wants to access a resource, the request can first be sent to a proxy server instead of directly to the destination server.

The proxy receives the request, processes it according to its configuration and then forwards the request to the destination service.

The response from the destination can then travel back through the proxy before reaching the client.

Why Proxies Are Used

Proxies can provide several useful functions in networks and organizations.

Traffic Control

Organizations can control and monitor requests passing through a proxy server.

Privacy

A proxy can act as an intermediary so the destination does not directly communicate with the original client.

Access Control

Proxy servers can be configured to allow or restrict access to particular resources.

Caching

Some proxies can cache frequently requested content to improve access efficiency.

▣

Common Types of Proxy

Proxy servers can be deployed in different ways depending on their purpose and network architecture.

⇄

Forward Proxy

Acts on behalf of clients when they access external services.

◉

Reverse Proxy

Acts on behalf of servers and receives client requests before forwarding them to backend systems.

⚡

Web Proxy

Handles web requests and can apply filtering, monitoring and caching rules.

⇄

Forward Proxy vs Reverse Proxy

Forward Proxy

A forward proxy is positioned between clients and external services. It forwards requests from clients toward destination servers.

Reverse Proxy

A reverse proxy is positioned in front of servers or backend systems. It receives client requests and forwards them to the appropriate backend server.

⚡

Proxy and Network Security

Proxies can be part of a network security architecture. They may help organizations inspect, filter and control network requests according to defined policies.

For example, an organization can use a web proxy to restrict access to certain websites or monitor web traffic according to its security requirements.

A proxy is not automatically a complete security solution. Its protection depends on how it is configured and how it is integrated with other security controls.

Quick Summary

  • A proxy acts as an intermediary between a client and a destination service.
  • A proxy can forward requests on behalf of clients or servers.
  • Proxies can provide traffic control, access control, privacy and caching functions.
  • Forward proxies primarily operate on behalf of clients.
  • Reverse proxies operate in front of servers or backend systems.
  • Proxy security depends on correct configuration and integration with other security controls.
