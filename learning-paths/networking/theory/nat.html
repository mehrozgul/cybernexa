What is NAT?

Network Address Translation (NAT) allows devices using private IP addresses to communicate with public networks such as the Internet.

◇

Quick Definition

What is NAT? NAT stands for Network Address Translation. It translates private IP addresses into public IP addresses so devices on a private network can communicate with external networks.
◎

Why NAT is Used

NAT is commonly used in home, business and enterprise networks. It allows multiple devices using private IP addresses to access the Internet through a public IP address.

Private IP Addresses

NAT allows devices with private IP addresses to communicate with public networks.

Internet Access

Multiple devices inside a private network can access the Internet using NAT.

Address Conservation

NAT reduces the need for a separate public IPv4 address for every internal device.

Network Separation

Private internal addresses can remain separate from public Internet addressing.

→

How NAT Works

When a device inside a private network sends traffic to the Internet, the router performing NAT changes the source private IP address into a public IP address.

When the response returns, the NAT device uses its translation information to forward the response back to the correct internal device.

Private IP vs Public IP

Private IP Address

Used inside private networks such as home and organizational LANs. Private addresses are not directly routable across the public Internet.

Public IP Address

Used for communication across public networks such as the Internet. It can identify a network or device externally.

▣

Types of NAT

NAT can operate in different ways depending on how private addresses are translated to public addresses.

Static NAT

Creates a fixed one-to-one mapping between a private IP address and a public IP address.

Dynamic NAT

Maps private IP addresses to available public IP addresses from a configured pool.

PAT

Port Address Translation allows many private devices to share one public IP address by using different port numbers.

NAT and Ports

NAT can work together with port numbers to keep track of multiple connections from different internal devices.

PAT, also called NAT overload, allows many private devices to share a single public IP address by using different source port numbers.

Quick Summary

  • NAT stands for Network Address Translation.
  • NAT translates private IP addresses when communicating with public networks.
  • NAT allows multiple private devices to access the Internet.
  • Static NAT provides a fixed one-to-one mapping.
  • Dynamic NAT uses a pool of public IP addresses.
  • PAT allows multiple devices to share one public IP address using port numbers.
