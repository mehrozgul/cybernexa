Ports & Protocols

Learn how network ports identify specific services and how protocols define the rules used for communication between devices.

#

Quick Definition

What is a Port? A port is a logical communication endpoint used to identify a specific service or application running on a device.
⇄

What is a Protocol?

A network protocol is a set of rules that defines how devices communicate and exchange data over a network.

Communication Rules

Protocols define how data should be formatted, transmitted and received.

Data Delivery

Protocols help devices understand how information should travel between them.

Security

Some protocols provide encryption and authentication to protect communication.

Standardization

Protocols provide common standards so different systems can communicate.

→

How Ports & Protocols Work Together

Protocols define how communication happens, while ports identify the particular service or application receiving the communication.

For example, HTTPS normally uses TCP port 443. When a browser connects to a secure website, port 443 identifies the HTTPS service.

Port Number Ranges

Well-Known Ports

Ports 0–1023 are commonly assigned to standard services and protocols.

Registered Ports

Ports 1024–49151 are commonly used by applications and registered services.

Dynamic / Private Ports

Ports 49152–65535 are commonly used for temporary or dynamic connections.

Total Ports

TCP and UDP each provide port numbers from 0 through 65535.

⇄

TCP & UDP Ports

TCP and UDP use port numbers to identify applications and services. However, TCP and UDP provide different transport mechanisms.

TCP

TCP provides connection-oriented and reliable communication.

UDP

UDP provides connectionless communication with lower overhead.

Quick Summary

  • A port is a logical endpoint used to identify a network service or application.
  • Protocols define the rules used for network communication.
  • TCP and UDP use port numbers to identify applications and services.
  • Common ports include 22 for SSH, 53 for DNS, 80 for HTTP and 443 for HTTPS.
  • Ports are important in cybersecurity because exposed services can increase a system's attack surface.
