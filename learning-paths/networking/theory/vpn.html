What is VPN?

A Virtual Private Network (VPN) creates a protected connection between a device and a network over the Internet. It can help protect data in transit and provide secure access to network resources.

🔒

Quick Definition

What is a VPN? A VPN, or Virtual Private Network, is a technology that creates an encrypted connection between a device and a VPN server over a network such as the Internet.
◎

Why VPN is Used

VPNs are commonly used when users need a more protected connection or secure access to resources across an untrusted network.

Data Protection

Encryption can help protect data while it travels between the user and the VPN endpoint.

Secure Remote Access

Organizations can use VPNs to allow authorized users to securely access internal network resources.

Public Wi-Fi Security

A VPN can provide an encrypted tunnel when using networks such as public Wi-Fi.

Privacy

A VPN can hide the user's original IP address from websites by routing traffic through the VPN server.

→

How a VPN Works

When a VPN is enabled, the VPN client establishes a connection with a VPN server. Network traffic is then routed through the VPN connection.

The connection between the device and VPN server can use encryption to protect data while it travels across the network.

Basic VPN Components

A VPN system typically contains several components that work together to establish and protect the connection.

VPN Client

Software on the user's device that establishes and manages the VPN connection.

VPN Server

A server that accepts VPN connections and acts as an endpoint for the VPN tunnel.

Encryption

Helps protect network traffic so unauthorized parties cannot easily read the transmitted data.

VPN Protocol

Defines how the VPN connection is established, authenticated and secured.

#

Common VPN Protocols

VPN protocols define the methods used to establish and secure VPN connections.

OpenVPN

A widely used VPN protocol known for flexibility and strong security when properly configured.

WireGuard

A modern VPN protocol designed with a relatively simple architecture and modern cryptography.

IPsec

A collection of protocols used to secure IP communications at the network layer.

IKEv2

A protocol commonly used with IPsec to establish and manage secure VPN connections.

⚡

VPN and Security

VPN technology can improve the security of network communication, especially when traffic crosses an untrusted network.

Important Security Point A VPN protects the connection between the device and the VPN endpoint, but it does not automatically make every website, application or device completely secure.
