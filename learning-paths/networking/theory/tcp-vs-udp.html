TCP vs UDP

TCP and UDP are transport-layer protocols used to deliver data between applications over a network. They provide different approaches to communication, reliability and speed.

⇄

Quick Definition

What are TCP and UDP? TCP (Transmission Control Protocol) provides reliable, connection-oriented communication, while UDP (User Datagram Protocol) provides faster, connectionless communication with less overhead.
T

TCP — Transmission Control Protocol

TCP is a connection-oriented transport-layer protocol designed to provide reliable and ordered delivery of data between applications.

Connection-Oriented

TCP establishes a connection before transferring data.

Reliable Delivery

TCP uses acknowledgments and retransmission to help ensure data reaches the destination.

Ordered Data

TCP maintains the correct order of data during transmission.

Error Control

TCP detects transmission problems and manages lost or corrupted data.

U

UDP — User Datagram Protocol

UDP is a connectionless transport-layer protocol that sends data without establishing a connection first.

Connectionless

UDP sends data without establishing a connection beforehand.

Low Overhead

UDP has fewer control mechanisms, making communication lightweight.

Faster Communication

UDP can provide lower delay because it does not perform TCP-style reliability mechanisms.

No Delivery Guarantee

UDP does not guarantee delivery, ordering or retransmission of packets.

Common Uses

TCP and UDP are selected according to the requirements of the application.

TCP

Web Browsing

HTTP and HTTPS traditionally use TCP because reliable data delivery is important.

TCP

File Transfer

File transfer applications commonly require reliable and complete data delivery.

UDP

DNS Queries

DNS commonly uses UDP for lightweight, low-overhead queries.

UDP

Streaming & Real-Time Traffic

UDP can be useful for applications where low delay is important.
