What are VLANs?

VLANs allow a physical network to be divided into separate logical networks. They improve organization, security and traffic management inside a network.

◇

Quick Definition

What is a VLAN? VLAN stands for Virtual Local Area Network. It is a logical network created inside a physical network to separate devices into different broadcast domains.
◎

Why VLANs Are Used

VLANs allow network administrators to logically separate devices even when those devices are connected to the same physical switch infrastructure.

Network Segmentation

VLANs divide a larger network into smaller logical network segments.

Security

Devices belonging to different VLANs can be isolated from each other and controlled through network policies.

Traffic Management

VLANs help reduce unnecessary broadcast traffic within a network.

Organization

Users can be grouped logically according to departments, roles or network requirements.

Common VLAN Types

VLANs can be used for different purposes depending on the design and requirements of a network.

D

Data VLAN

Carries normal user data traffic.

V

Voice VLAN

Used for voice and IP phone traffic.

M

Management VLAN

Used for managing network devices.

N

Native VLAN

Used for untagged traffic on an 802.1Q trunk.

G

Guest VLAN

Can be used to isolate guest devices from internal resources.

S

Security VLAN

Can be designed to separate devices according to security requirements.

⇄

Access Port vs Trunk Port

Switch ports can operate in different modes depending on how VLAN traffic needs to be carried.

Feature Access Port Trunk Port
VLANs Normally carries traffic for one VLAN. Can carry traffic for multiple VLANs.
Common Use End devices such as PCs and printers. Connections between switches or network devices.
VLAN Tagging End-device traffic is normally untagged. VLAN information can be carried using 802.1Q tagging.

Inter-VLAN Communication

Devices in different VLANs are separated into different broadcast domains. If devices from different VLANs need to communicate, a Layer 3 device such as a router or Layer 3 switch is required.

Benefits of VLANs

  • VLANs logically divide a physical network.
  • They help create separate broadcast domains.
  • VLANs can improve network organization and security.
  • They can reduce unnecessary broadcast traffic.
  • Different departments can be placed into separate logical networks.
  • Communication between VLANs can be controlled using Layer 3 devices and security policies.

Quick Summary

  • VLAN stands for Virtual Local Area Network.
  • VLANs logically separate devices inside a physical network.
  • Each VLAN creates a separate broadcast domain.
  • Access ports normally connect end devices to a VLAN.
  • Trunk ports can carry traffic for multiple VLANs.
  • 802.1Q is commonly used to identify VLAN traffic across trunk links.
  • Communication between different VLANs requires Layer 3 routing.
