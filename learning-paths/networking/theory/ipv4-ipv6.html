IPv4 & IPv6

IPv4 and IPv6 are Internet Protocol versions used to identify devices and deliver data across networks. Understanding both is essential for networking and cybersecurity.

#

Quick Definition

What are IPv4 and IPv6? IPv4 and IPv6 are versions of the Internet Protocol. They provide addressing systems that allow devices to be identified and communicate across networks.
4

IPv4

IPv4 is the fourth version of the Internet Protocol. It uses a 32-bit address system and represents addresses using four decimal numbers separated by periods.

IPv4 Example
192.168.1.10
32-bit Address
Decimal Format
Four Octets
Dotted Format

IPv6

IPv6 is the newer version of the Internet Protocol. It uses a 128-bit address system and provides a much larger address space than IPv4.

IPv6 Example
2001:0db8:85a3:0000:0000:8a2e:0370:7334
128-bit Address
Hexadecimal Format
Eight Groups

IPv4 vs IPv6

IPv4 and IPv6 perform the same fundamental addressing function, but they differ significantly in address size, notation and available address space.

Feature IPv4 IPv6
Address Size 32-bit 128-bit
Format Decimal Hexadecimal
Separator Dot (.) Colon (:)
Example 192.168.1.10 2001:db8::1
Address Space Smaller Much larger
Address Groups 4 octets 8 groups
→

Why IPv6 Was Introduced

The number of Internet-connected devices has grown significantly over time. IPv4 provides a limited 32-bit address space, creating pressure on available public addresses.

IPv6 uses 128-bit addresses and therefore provides a vastly larger address space for connected devices.

More Addresses

IPv6 provides a much larger address space than IPv4.

Modern Networks

IPv6 was designed to support the continued growth of Internet-connected systems.

Quick Summary

  • IPv4 is the fourth version of the Internet Protocol.
  • IPv4 uses 32-bit addresses.
  • IPv6 uses 128-bit addresses.
  • IPv4 addresses use decimal notation.
  • IPv6 addresses use hexadecimal notation.
  • IPv6 provides a much larger address space than IPv4.
  • Both IPv4 and IPv6 are used for identifying and communicating with devices across networks.
