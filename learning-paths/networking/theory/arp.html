What is ARP?

ARP (Address Resolution Protocol) is used in IPv4 networks to find the MAC address associated with a known IP address on the local network.

◇

Quick Definition

What is ARP? ARP stands for Address Resolution Protocol. It is used to map an IPv4 address to the corresponding MAC address of a device on the local network.
◎

Why ARP is Needed

Devices communicate on a local Ethernet network using MAC addresses. However, applications and network communication commonly work with IP addresses.

ARP helps a device discover the MAC address associated with a known IPv4 address so that an Ethernet frame can be delivered to the correct device.

IP Address

Identifies a device at the network layer and is used to locate the destination.

MAC Address

Identifies a network interface on the local Ethernet network.

ARP Request

Asks which device owns a specific IPv4 address.

ARP Reply

Provides the MAC address associated with the requested IPv4 address.

→

How ARP Works

Suppose a computer knows the IP address of another device on the same local network but does not know its MAC address.

The computer sends an ARP Request asking which device owns that IP address. The device with the matching IP address sends an ARP Reply containing its MAC address.

ARP Request vs ARP Reply

ARP Request ARP Reply
Asks for the MAC address associated with an IPv4 address. Provides the MAC address associated with that IPv4 address.
Usually sent as a broadcast on the local network. Normally sent back to the requesting device.
"Who has this IP address?" "That IP address belongs to this MAC address."
▣

ARP Cache

After learning the MAC address of another device, a computer can store the IP-to-MAC mapping in its ARP cache.

The ARP cache helps reduce the need to send repeated ARP Requests for the same device.

Example 192.168.1.20 → AA:BB:CC:DD:EE:FF

This entry means that the IPv4 address 192.168.1.20 is associated with the specified MAC address.

ARP and Network Security

ARP does not provide authentication for ARP messages. Because of this, attackers on a local network may attempt to manipulate ARP mappings.

ARP Spoofing

An attacker sends forged ARP messages to associate their MAC address with another device's IP address.

ARP Poisoning

False ARP information can cause devices to send traffic to an unintended system.

Quick Summary

  • ARP stands for Address Resolution Protocol.
  • ARP maps an IPv4 address to a MAC address on a local network.
  • An ARP Request asks for the MAC address associated with an IP address.
  • An ARP Reply provides the requested MAC address.
  • Devices can store learned mappings in an ARP cache.
  • ARP is important for communication on IPv4 Ethernet networks.
  • ARP spoofing can be used to manipulate local network traffic.
