What is an IP Address?

An IP address is a unique logical address used to identify a device on a network and help deliver data to the correct destination.

#

Quick Definition

What is an IP Address? An Internet Protocol (IP) address is a logical address assigned to a device on a network. It helps identify the device and allows data to be delivered to the correct destination.
◎

Why IP Addresses Matter

IP addresses are essential for communication between devices. Without addressing, network devices would not know where data should be delivered.

Device Identification

An IP address identifies a device or network interface within a network.

Data Delivery

IP addressing helps routers determine where network packets should be sent.

Network Communication

Devices use IP addresses to communicate with other devices across networks.

Network Routing

Routers use destination IP addresses to forward packets toward their destination.

IPv4 Address

IPv4 is the most widely recognized IP addressing format. It uses a 32-bit address represented as four decimal numbers separated by dots.

Example IPv4 Address 192.168.1.20

IPv6 Address

IPv6 is the newer version of the Internet Protocol. It uses 128-bit addresses and provides a much larger address space than IPv4.

Example IPv6 Address 2001:db8:85a3::8a2e:370:7334

Public vs Private IP

Public

Public IP Address

A public IP address is used to identify a network or device when communicating across the Internet. It can be assigned by an Internet Service Provider.

Private

Private IP Address

A private IP address is used inside a local network such as a home, school or office network.

↻

Static vs Dynamic IP

Static

Static IP Address

A static IP address remains the same unless it is manually changed. It is commonly useful for servers and systems that need a consistent address.

Dynamic

Dynamic IP Address

A dynamic IP address is normally assigned automatically by a DHCP server and may change over time.

▣

Common Private IPv4 Ranges

The following IPv4 ranges are reserved for private networks and are commonly used inside homes, organizations and laboratories.

Class A 10.0.0.0 – 10.255.255.255
Class B 172.16.0.0 – 172.31.255.255
Class C 192.168.0.0 – 192.168.255.255
/

Subnet Mask

A subnet mask is used with an IPv4 address to determine which portion represents the network and which portion represents the host.

Example IP Address: 192.168.1.20   |   Subnet Mask: 255.255.255.0
→

Default Gateway

A default gateway is usually the router's IP address on a local network. Devices use it when they need to communicate with destinations outside their local network.

Example A common home-network gateway can be 192.168.1.1.

Quick Summary

  • An IP address identifies a device or network interface for network communication.
  • IPv4 uses 32-bit addresses.
  • IPv6 uses 128-bit addresses.
  • Public IP addresses are used for communication across the Internet.
  • Private IP addresses are used inside local networks.
  • Static IP addresses normally remain unchanged, while dynamic IP addresses can change.
  • A subnet mask separates the network and host portions of an IPv4 address.
  • A default gateway is normally the router used to reach other networks.
