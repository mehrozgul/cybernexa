What is DHCP?

DHCP automatically provides devices with IP addresses and other network configuration information, making it easier for devices to connect and communicate on a network.

◇

Quick Definition

What is DHCP? DHCP stands for Dynamic Host Configuration Protocol. It automatically assigns IP addresses and other network configuration information to devices on a network.
◎

Why DHCP is Used

Without DHCP, network administrators would need to manually configure IP addresses and other network settings on every device.

Automatic IP Assignment

DHCP automatically provides devices with available IP addresses.

Less Manual Configuration

Administrators do not need to manually configure every device on the network.

Network Configuration

DHCP can provide information such as the default gateway and DNS server.

Efficient Management

DHCP helps manage IP addresses efficiently across a network.

⇄

DHCP Client and DHCP Server

DHCP communication normally involves a DHCP client and a DHCP server.

DHCP Client

A device such as a laptop, smartphone or computer that requests network configuration from the DHCP server.

DHCP Server

A server or network device that provides IP addresses and other network configuration information to clients.

→

DHCP DORA Process

DHCP commonly uses a four-step process called DORA to assign an IP address to a client.

01 — D

Discover

The client broadcasts a DHCP Discover message to find an available DHCP server.

02 — O

Offer

The DHCP server responds with an IP address offer and other network configuration details.

03 — R

Request

The client sends a DHCP Request message to request the offered IP address.

04 — A

Acknowledge

The server sends a DHCP Acknowledgment confirming the IP address assignment.

Information Provided by DHCP

DHCP can provide several important network configuration values to a client device.

IP Address

Identifies the device on the IP network.

Subnet Mask

Defines the network and host portions of an IP address.

Default Gateway

Provides the address used to communicate with other networks.

DNS Server

Provides the DNS server address used to resolve domain names.

#

DHCP Ports

DHCP uses UDP for communication and uses two standard port numbers.

UDP Port 67

Used by the DHCP server.

UDP Port 68

Used by the DHCP client.

Quick Summary

  • DHCP stands for Dynamic Host Configuration Protocol.
  • DHCP automatically assigns IP addresses to devices.
  • DHCP can provide subnet mask, default gateway and DNS server information.
  • DHCP communication commonly follows the DORA process.
  • DORA stands for Discover, Offer, Request and Acknowledge.
  • DHCP uses UDP port 67 for the server and UDP port 68 for the client.
  • DHCP reduces the need for manual network configuration.
