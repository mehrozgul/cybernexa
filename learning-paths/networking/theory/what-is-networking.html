NETWORKING

What is Networking?

Networking is the foundation of modern communication. It allows computers, devices and systems to communicate, exchange data and share resources with each other.

◇

Quick Definition

What is Computer Networking? Computer networking is the process of connecting two or more computing devices so they can communicate, exchange information and share resources.
◎

Why Networking Matters

Networking is an essential part of modern computing. Almost every organization, website, application and connected device depends on networks to communicate and transfer information.

Communication

Networks allow devices and users to communicate and exchange information.

Resource Sharing

Devices can share resources such as files, printers, applications and internet access.

Internet Access

Networks make it possible for devices to connect to services and resources across the Internet.

Security

Network security helps protect communication, systems and data from unauthorized access.

→

How Networking Works

When devices communicate over a network, data is transferred from one device to another using defined rules called protocols.

A typical communication process involves a source device, a network connection, networking equipment and a destination device.

Network devices and protocols work together to make sure that information can travel between the correct systems.

▣

Basic Networking Components

Different devices perform different roles inside a network. Some of the most common networking components are listed below.

PC

Computer

A device that sends and receives data over a network.

⇄

Router

Connects different networks and forwards data between them.

⬡

Switch

Connects devices within a local network and forwards data between them.

◉

Server

Provides services, applications or resources to other devices.

⚡

Firewall

Helps control and filter network traffic according to security rules.

Wi

Access Point

Allows wireless devices to connect to a network.

Quick Summary

  • Networking connects two or more computing devices.
  • Networks allow devices to communicate and exchange information.

  • Routers, switches, servers and firewalls can perform different roles in a network.
  • Protocols define rules for communication between networked devices.
