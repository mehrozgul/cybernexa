What is Subnetting?

Subnetting is the process of dividing a larger IP network into smaller logical networks called subnets. It helps organize networks, manage IP addresses and control network traffic efficiently.

◇

Quick Definition

What is Subnetting? Subnetting is the technique of dividing one IP network into multiple smaller networks. Each smaller network is called a subnet.
◎

Why Subnetting Matters

Subnetting allows network administrators to divide a large network into smaller and more manageable sections.

Better Organization

Devices can be grouped into separate networks based on departments, locations or functions.

Efficient IP Usage

Subnetting helps allocate IP addresses according to the actual requirements of each network.

Improved Security

Different groups of devices can be placed into separate network segments to help control communication.

Reduced Network Traffic

Smaller networks can reduce unnecessary broadcast traffic and make networks easier to manage.

Important Subnetting Concepts

Several concepts are important when working with IP subnetting.

IP

IP Address

Identifies a device or network interface using an IP address.

/

CIDR

Represents the network prefix using notation such as /24 or /26.

#

Subnet Mask

Determines which portion of an IP address represents the network.

N

Network Address

Identifies the subnet itself and is not normally assigned to a host.

B

Broadcast Address

Used to communicate with all hosts within an IPv4 subnet.

H

Host Addresses

IP addresses available for devices inside an IPv4 subnet.

#

Simple Subnetting Example

Suppose we have the network 192.168.1.0/24 . A /24 network can be divided into smaller subnets by borrowing bits from the host portion.

Example: Dividing a /24 Network into /26 Subnets
Network: 192.168.1.0/24
New Prefix: /26

Subnet 1: 192.168.1.0/26
Subnet 2: 192.168.1.64/26
Subnet 3: 192.168.1.128/26
Subnet 4: 192.168.1.192/26

By changing the prefix from /24 to /26, the original network is divided into four smaller IPv4 subnets.

Basic Subnetting Process

A basic subnetting process can be understood through the following steps.

01

Identify Network

Determine the original IP network and its prefix.

02

Determine Requirement

Decide how many subnets or hosts are required.

03

Borrow Bits

Borrow host bits to create additional network bits.

04

Find Subnets

Calculate the network ranges created by the new prefix.

05

Find Hosts

Determine the usable host address range for each subnet.

06

Verify

Check network, host and broadcast addresses for accuracy.

Quick Summary

  • Subnetting divides a larger IP network into smaller logical networks.
  • Smaller networks are called subnets.
  • Subnetting helps organize networks and manage IP addresses efficiently.
  • A subnet mask determines the network and host portions of an IPv4 address.
  • CIDR notation represents the network prefix, such as /24 or /26.
  • Each IPv4 subnet has a network address, usable host addresses and a broadcast address.
