What is DNS?

DNS is the system that translates human-readable domain names into IP addresses, allowing users to access websites and network services easily.

◇

Quick Definition

What is DNS? DNS stands for Domain Name System. It translates domain names such as example.com into IP addresses that computers use to locate network resources.
◎

Why DNS is Needed

Computers communicate using IP addresses, but remembering IP addresses for every website would be difficult for users.

Human-Friendly Names

DNS allows users to access websites using easy-to-remember domain names instead of numerical IP addresses.

IP Address Resolution

DNS finds the IP address associated with a requested domain name.

Easier Internet Access

Users can type a domain name into a browser instead of manually entering an IP address.

Scalable System

DNS helps organize and manage the large number of domains and network resources available on the Internet.

#

Domain Name vs IP Address

A domain name is designed for people to remember, while an IP address is used by computers and networking systems to identify a destination.

Domain Name

Example: example.com

Easy for humans to read and remember.

IP Address

Example: 93.184.216.34

Used by computers to locate the destination.

How DNS Works

When a user enters a domain name into a browser, the system needs to find the IP address associated with that domain.

DNS performs this name-resolution process so the browser can communicate with the correct server.

Common DNS Records

DNS uses different types of records to store information about domains and network resources.

A Record

Maps a domain name to an IPv4 address.

AAAA Record

Maps a domain name to an IPv6 address.

CNAME

Creates an alias that points one domain name to another domain name.

MX Record

Specifies the mail server responsible for receiving email for a domain.

#

DNS Port

DNS commonly uses port 53 for communication. DNS queries normally use UDP, while TCP can also be used in situations such as larger responses and certain DNS operations.

53

DNS Port

DNS commonly uses UDP port 53 and can also use TCP port 53.

Real-World Example

Suppose you open a browser and type example.com. Your computer needs the IP address of that domain before it can communicate with the web server.

DNS helps resolve the domain name into its corresponding IP address, after which the browser can connect to the destination server.
