What is Firewall?

A firewall is a security system that monitors and controls network traffic based on predefined security rules. It helps protect systems and networks from unauthorized access and unwanted traffic.

🔥

Quick Definition

What is a Firewall? A firewall is a network security mechanism that examines incoming and outgoing network traffic and allows or blocks traffic according to defined security rules.
🛡

Why Firewalls Matter

Firewalls provide an important layer of protection between trusted and untrusted networks. They help organizations control network communication and reduce unauthorized access.

Traffic Filtering

Firewalls inspect network traffic and decide whether it should be allowed or blocked.

Access Control

Security rules can control which systems, services and connections are permitted.

Network Protection

Firewalls help protect internal networks from unwanted or unauthorized external traffic.

Monitoring

Firewall logs can provide information about network connections and blocked traffic.

→

How a Firewall Works

When network traffic reaches a firewall, the firewall examines the traffic according to its configured security rules.

The rules may consider information such as source IP address, destination IP address, protocol, port and direction of traffic.

Based on these rules, the firewall can allow the traffic, block it or log the connection for monitoring.

Common Types of Firewalls

Firewalls can operate at different levels and use different techniques to inspect and control network traffic.

01

Packet Filtering

Filters packets using information such as IP addresses, protocols and port numbers.

02

Stateful Firewall

Tracks active connections and makes decisions based on the state of network sessions.

03

Proxy Firewall

Acts as an intermediary between a client and the destination service.

04

Next-Generation Firewall

Provides advanced inspection and security capabilities beyond basic packet filtering.

05

Host-Based Firewall

Runs directly on an individual computer or server to control its network traffic.

06

Network Firewall

Protects multiple devices and systems at the network boundary.

Real-World Example

Consider a company network connected to the Internet. The firewall is placed between the internal network and the external network.

When an external device tries to access an internal service, the firewall checks the connection against its configured rules before allowing or blocking it.

Quick Summary

  • A firewall monitors and controls network traffic.
  • Firewalls can allow or block traffic according to security rules.
  • Firewall rules can use IP addresses, ports and protocols.
  • Firewalls help protect systems and networks from unauthorized access.
  • Common firewall types include packet-filtering, stateful, proxy and next-generation firewalls.
  • Firewalls can be deployed on individual hosts or at network boundaries.
