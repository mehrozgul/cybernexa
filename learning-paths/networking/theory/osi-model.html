OSI Model

The OSI Model is a seven-layer framework that helps explain how data is communicated between devices across a network.

#

Quick Definition

What is the OSI Model? OSI stands for Open Systems Interconnection. It is a conceptual model that divides network communication into seven different layers. Each layer has a specific responsibility.
◎

Why the OSI Model Matters

The OSI Model provides a structured way to understand how network communication works from one device to another.

Understand Networking

It breaks complex network communication into seven easier-to-understand layers.

Troubleshooting

Network problems can be analyzed by checking the different layers.

Standardization

It provides a common framework for understanding communication between different systems.

Cybersecurity

Security controls and attacks can be understood in relation to different network layers.

7

Seven Layers of the OSI Model

The OSI Model contains seven layers. The layers are usually remembered from Layer 7 at the top to Layer 1 at the bottom.

7

Application Layer

Provides network services directly to applications used by the user.

HTTP / DNS / FTP
6

Presentation Layer

Handles data formatting, translation, encryption and compression.

Format
5

Session Layer

Establishes, manages and terminates communication sessions between systems.

Session
4

Transport Layer

Provides end-to-end communication, reliability and flow control.

TCP / UDP
3

Network Layer

Handles logical addressing and determines paths for data between networks.

IP / Router
2

Data Link Layer

Provides node-to-node delivery and uses MAC addresses for local communication.

MAC / Switch
1

Physical Layer

Transmits raw bits through physical media such as cables and radio signals.

Bits / Cable

Data Units in the OSI Model

As data moves through the OSI layers, it is handled in different forms called Protocol Data Units (PDUs).

Layers 7–5

Data is commonly referred to as data or a message at the upper layers.

Layer 4

Data is commonly called a segment when TCP is used, or a datagram when UDP is used.

Layer 3

The data unit is called a packet.

Layer 2

The data unit is called a frame.

Layer 1

Data is transmitted as bits over the physical medium.

Quick Summary

  • OSI stands for Open Systems Interconnection.
  • The OSI Model has seven layers.
  • Layer 7 is the Application Layer.
  • Layer 4 is the Transport Layer and uses protocols such as TCP and UDP.
  • Layer 3 is the Network Layer and works with logical addressing such as IP.
  • Layer 2 is the Data Link Layer and uses MAC addresses for local communication.
  • Layer 1 is the Physical Layer and transmits bits.
  • The OSI Model helps understand, design and troubleshoot network communication.
