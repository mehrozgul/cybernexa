What is ICMP?

ICMP is a network-layer protocol used to send control, error and diagnostic messages between network devices.

◇

Quick Definition

What is ICMP? ICMP stands for Internet Control Message Protocol. It is used by network devices to communicate control and error information and to help diagnose network connectivity.
◎

Why ICMP Matters

ICMP helps network devices report problems and test whether another device or network destination is reachable.

Connectivity Testing

ICMP can be used to check whether a destination device is reachable.

Error Reporting

Network devices can use ICMP messages to report certain communication errors.

Network Diagnosis

ICMP is commonly used by network tools to troubleshoot connectivity problems.

Control Messages

ICMP carries control and informational messages related to IP communication.

#

ICMP and the Network Layer

ICMP works with the Internet Protocol at the Network Layer of the OSI model.

It is associated with IP communication and is used to exchange control and diagnostic information between network devices.

ICMP and Ping

The ping command is one of the most common tools that uses ICMP.

A ping test sends an ICMP Echo Request to a destination. If the destination responds, it sends an ICMP Echo Reply.

Example: Ping Command

On a computer, you can use the ping command to test connectivity to an IP address.

ping 8.8.8.8

If the destination responds, the result can help confirm that communication to that destination is possible.

!

Does ICMP Use Ports?

Important ICMP does not use TCP or UDP port numbers. It is a separate network-layer protocol associated with IP communication.

Common ICMP Messages

Echo Request

Sent to test whether a destination can respond.

Echo Reply

Response to an ICMP Echo Request, commonly used by ping.

Destination Unreachable

Indicates that a destination or required network path cannot be reached.

Time Exceeded

Indicates that a packet's allowed lifetime has been exceeded.
