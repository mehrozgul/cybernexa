🎯 Lab Objective

In this practical lab, you will connect two different IP networks using two Cisco routers.

You will configure router interfaces, assign IP addresses, create static routes and verify communication between networks.

💡 What You Will Learn

You will practice routing concepts, router interfaces, static routes, next-hop addresses, routing tables, default gateways and connectivity testing.

01 Configure Router R1 Interfaces

Configure the LAN interface and the router-to-router interface on R1.

Cisco IOS — R1
enable configure terminal interface g0/0 ip address 192.168.10.1 255.255.255.0 no shutdown exit interface g0/1 ip address 10.0.0.1 255.255.255.252 no shutdown end
Verification 
show ip interface brief

GigabitEthernet0/0   192.168.10.1   up   up
GigabitEthernet0/1   10.0.0.1       up   up
🧠 Understand the Result

R1 now has one interface connected to LAN 1 and another interface connected to R2.

02 Configure Router R2 Interfaces

Configure the LAN interface and the router-to-router interface on R2.

Cisco IOS — R2
enable configure terminal interface g0/0 ip address 10.0.0.2 255.255.255.252 no shutdown exit interface g0/1 ip address 192.168.20.1 255.255.255.0 no shutdown end
Verification 
show ip interface brief

GigabitEthernet0/0   10.0.0.2       up   up
GigabitEthernet0/1   192.168.20.1   up   up
🔎 Important

R2 must have an interface in the router-to-router network and another interface in LAN 2.

03 Configure Static Route on R1

R1 knows its directly connected networks, but it does not automatically know the remote LAN behind R2. Add a static route to LAN 2 using R2 as the next hop.

Cisco IOS — R1
enable configure terminal ip route 192.168.20.0 255.255.255.0 10.0.0.2 end
Verification 
show ip route

S    192.168.20.0/24 [1/0] via 10.0.0.2
🧠 Understand the Result

The S in the routing table represents a static route. R1 will forward traffic for 192.168.20.0/24 to R2 at 10.0.0.2.

04 Configure Static Route on R2

R2 also needs a route back to LAN 1. Configure the remote network using R1 as the next-hop router.

Cisco IOS — R2
enable configure terminal ip route 192.168.10.0 255.255.255.0 10.0.0.1 end
Verification 
show ip route

S    192.168.10.0/24 [1/0] via 10.0.0.1
🔁 Why Is the Return Route Needed?

Communication requires a path in both directions. R2 needs to know how to send response traffic back to the 192.168.10.0/24 network.

05 Configure PC IP Addresses

Configure each PC with an IP address from the correct LAN and use the router interface as its default gateway.

PC Network IP Address Subnet Mask Gateway
PC1 LAN 1 192.168.10.10 255.255.255.0 192.168.10.1
PC2 LAN 1 192.168.10.11 255.255.255.0 192.168.10.1
PC3 LAN 2 192.168.20.10 255.255.255.0 192.168.20.1
PC4 LAN 2 192.168.20.11 255.255.255.0 192.168.20.1
💡 Packet Tracer

On each PC, open Desktop → IP Configuration and enter the corresponding IP address, subnet mask and default gateway.

06 Verify Routing Tables

Use the show ip route command on both routers to verify directly connected networks and static routes.

Cisco IOS — R1 / R2
show ip route show ip interface brief
What to Check 
R1:
Connected → 192.168.10.0/24
Connected → 10.0.0.0/30
Static    → 192.168.20.0/24 via 10.0.0.2

R2:
Connected → 192.168.20.0/24
Connected → 10.0.0.0/30
Static    → 192.168.10.0/24 via 10.0.0.1
07 Test Connectivity

First test communication inside each LAN. Then test communication between the two different networks.

PC Command Prompt
ping 192.168.10.11 ping 192.168.20.10
Expected Result 
Reply from 192.168.10.11: bytes=32 time<1ms TTL=128

Reply from 192.168.20.10: bytes=32 time<1ms TTL=127
🧠 Understand the Result

A successful cross-network ping shows that the PCs, router interfaces, static routes and return path are working together.

🧭 Routing Concepts
Routing The process of selecting a path for packets to travel between different networks.
Static Route A route manually configured by a network administrator.
Next Hop The next router address to which traffic should be forwarded.
Routing Table A table used by a router to determine where packets should be forwarded.
Default Gateway The router interface used by a host to reach another network.
Connected Route A route automatically created when a router interface is configured and active.
🛠️ Common Troubleshooting
Interface Down Check the interface status with show ip interface brief and use no shutdown if required.
Wrong IP Verify that router and PC addresses belong to the correct subnet.
Wrong Gateway Check that every PC uses the router interface in its own LAN as the default gateway.
Missing Route Use show ip route and verify that the remote network has a valid route.
Wrong Next Hop Check that the static route points to the correct neighboring router address.
Return Path Make sure the destination router also has a route back to the source network.
🛡️ Why Routing Matters in Cybersecurity

Routing is an important networking concept for cybersecurity because security devices and systems must understand how traffic moves between different networks.

Network Segmentation Routing allows communication between separated network segments under defined conditions.
Access Control Routing combined with ACLs can help control which traffic is allowed between networks.
Traffic Flow Understanding routes helps security analysts understand how packets move through a network.
Firewall Placement Routers and firewalls can be positioned between networks to enforce security policies.
Network Monitoring Routing information can help identify expected network paths during security monitoring.
Incident Response Understanding routes helps determine how systems can communicate during network investigations.
