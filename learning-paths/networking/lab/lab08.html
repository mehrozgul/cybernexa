Subnetting Concepts

Review these important concepts before performing the practical subnetting exercises.

01

Subnet

A smaller logical network created by dividing a larger IP network.

NETWORK
02

Subnet Mask

Determines which portion of an IPv4 address represents the network and host.

MASK
03

CIDR

Slash notation such as /24, /26 or /27 represents the number of network bits.

CIDR
04

Network Address

The first address of a subnet and identifies the subnet itself.

NETWORK ID
05

Broadcast Address

The last address of a subnet and is used to communicate with all hosts in that subnet.

BROADCAST
06

Usable Host Range

Addresses between the network and broadcast addresses that can normally be assigned to hosts.

HOSTS

Subnetting Formulas

These formulas can be used to calculate the number of subnets and usable hosts.

Number of Subnets

If S bits are borrowed from the host portion:

Number of Subnets = 2^S

Number of Usable Hosts

If H bits remain for hosts:

Usable Hosts = 2^H - 2

Block Size

For the interesting subnet-mask octet:

Block Size = 256 - Subnet Mask Value

Identify Your Current Network

1

Use ipconfig

Open Windows Command Prompt and run the following command to identify your current IP configuration.

Example Output 
IPv4 Address. . . . . . : 192.168.1.20
Subnet Mask . . . . . . : 255.255.255.0
Default Gateway . . . . : 192.168.1.1

Identify your IPv4 address and subnet mask. The actual values on your computer may be different.

02

Calculate a /26 Subnet

2

Divide 192.168.1.0/24

Divide the network 192.168.1.0/24 into /26 subnets.

Calculation 
Original Network: 192.168.1.0/24
New Prefix:       /26
Subnet Mask:      255.255.255.192
Block Size:       64

Number of Subnets = 2^(26-24)
                  = 2^2
                  = 4

Usable Hosts = 2^(32-26) - 2
             = 64 - 2
             = 62

Therefore, a /24 network can be divided into four /26 subnets, with 62 usable host addresses in each subnet.

04

Determine the Subnet of an IP Address

4

Analyze 192.168.1.70/26

Determine the network address, broadcast address and usable host range for 192.168.1.70/26.

Step-by-Step Result 
IP Address:        192.168.1.70
CIDR:              /26
Subnet Mask:       255.255.255.192
Block Size:        64

Subnet boundaries:
0, 64, 128, 192

70 belongs to the 64 subnet.

Network Address:   192.168.1.64
First Host:        192.168.1.65
Last Host:         192.168.1.126
Broadcast Address: 192.168.1.127

Therefore, 192.168.1.70 belongs to the 192.168.1.64/26 subnet.

Complete Subnetting Example

8

Divide 192.168.10.0/24 into 8 Subnets

We need 8 subnets from the original /24 network.

Calculation 
Required Subnets = 8

2^S = 8
S = 3

Original Prefix = /24

New Prefix = 24 + 3
           = /27

Subnet Mask = 255.255.255.224

Block Size = 256 - 224
           = 32

Usable Hosts = 2^(32-27) - 2
             = 32 - 2
             = 30

Therefore, 192.168.10.0/24 can be divided into 8 /27 subnets, with 30 usable hosts in each subnet.

Practical Observations

CIDR

CIDR notation such as /26 identifies the number of network bits in an IPv4 address.

Subnet Mask

The subnet mask separates the network portion from the host portion of an IPv4 address.

Network Address

The first address identifies the subnet and is not normally assigned to a host.

Broadcast Address

The final address is reserved for broadcast communication in an IPv4 subnet.

Block Size

Block size determines the interval between consecutive subnet network addresses.

Usable Hosts

In a typical IPv4 subnet, network and broadcast addresses are excluded from normal host assignment.
