Lab Objective

What will you learn? In this lab, you will understand the seven OSI layers and connect common networking activities and commands with the appropriate layers.
7

Seven OSI Layers

Review the seven layers before performing the practical exercises.

7

Application Layer

Provides network services directly to applications.

HTTP / DNS
6

Presentation Layer

Handles data formatting, encoding and encryption.

Format / Encrypt
5

Session Layer

Establishes, manages and terminates communication sessions.

Sessions
4

Transport Layer

Provides end-to-end communication using TCP or UDP.

TCP / UDP
3

Network Layer

Handles logical addressing and packet delivery.

IP / Router
2

Data Link Layer

Handles frames and local network communication.

MAC / Switch
1

Physical Layer

Transmits raw bits through physical media.

Bits / Cable
01

Identify Your Network Configuration

1

Open Command Prompt

Open Windows Command Prompt and run the following command.

ipconfig

Observe your IPv4 address, subnet mask and default gateway. This information is mainly related to Layer 3 because IP addressing operates at the Network Layer.

02

Test Network Connectivity

2

Use Ping

Use the ping command to test connectivity with a destination.

ping 8.8.8.8
Expected Output 
Reply from 8.8.8.8: bytes=32 time<20ms TTL=...

Ping uses ICMP and demonstrates network-layer communication. It can help verify whether a destination is reachable.

03

Observe the Network Route

3

Use Tracert

Run tracert to observe the path packets take toward a destination.

tracert example.com
Example Output 
Tracing route to example.com
1    <1 ms    192.168.1.1
2    10 ms    ...
3    20 ms    ...
Trace complete.

Tracert helps visualize Layer 3 routing between network devices.

04

Identify Application Layer Activity

4

Use Nslookup

Use DNS lookup to observe application-level network activity.

nslookup example.com
Expected Output 
Server:  ...
Address: ...

Name:    example.com
Addresses: ...

DNS is commonly associated with the Application Layer of the OSI Model.

⇄

Practical Observations

Layer 7 — Application

DNS tools such as nslookup demonstrate application-layer network services.

Layer 4 — Transport

TCP and UDP provide transport services between applications.

Layer 3 — Network

IP addressing, routing, ping and tracert demonstrate network-layer concepts.

Layer 2 — Data Link

MAC addresses and Ethernet frames operate at the Data Link Layer.
