🎯 Lab Objective

In this lab, you will learn how ICMP is used by network devices to exchange control and diagnostic messages.

You will use Windows commands such as ping and tracert to test connectivity, observe responses and understand basic network troubleshooting.

📡 How ICMP Works

ICMP is a network-layer protocol used to send control, error-reporting and diagnostic messages between network devices. The ping utility commonly uses ICMP Echo Request and Echo Reply messages.

💡 Basic Idea

A host can send an ICMP Echo Request to another host. If the destination is reachable and allows the request, it can respond with an ICMP Echo Reply.

01 Check Your Network Configuration

First, use ipconfig to view your computer's IPv4 address, subnet mask and default gateway.

Command Prompt
ipconfig
Example Output 
Ethernet adapter Ethernet:

   IPv4 Address. . . . . . . : 192.168.1.20
   Subnet Mask . . . . . . . : 255.255.255.0
   Default Gateway . . . . . : 192.168.1.1
🔎 What to Observe

Identify your IPv4 address and default gateway. These values help you understand which network your computer is connected to.

02 Test Local Connectivity

Use the ping command to test connectivity with your local default gateway.

Command Prompt
ping 192.168.1.1
Example Output 
Pinging 192.168.1.1 with 32 bytes of data:

Reply from 192.168.1.1: bytes=32 time<1ms TTL=64
Reply from 192.168.1.1: bytes=32 time<1ms TTL=64
Reply from 192.168.1.1: bytes=32 time<1ms TTL=64
Reply from 192.168.1.1: bytes=32 time<1ms TTL=64

Ping statistics for 192.168.1.1:
    Packets: Sent = 4, Received = 4, Lost = 0 (0% loss)
🔎 Why Do This?

The ping command helps determine whether the destination responds to ICMP Echo Requests and provides basic information about packet loss and response time.

03 Test Internet Connectivity

You can use ping with a reachable public host to test network connectivity beyond your local gateway.

Command Prompt
ping 8.8.8.8
Example Output 
Pinging 8.8.8.8 with 32 bytes of data:

Reply from 8.8.8.8: bytes=32 time=25ms TTL=117
Reply from 8.8.8.8: bytes=32 time=24ms TTL=117
Reply from 8.8.8.8: bytes=32 time=26ms TTL=117
Reply from 8.8.8.8: bytes=32 time=25ms TTL=117
💡 Concept

A successful response indicates that ICMP Echo communication with the destination is possible. A failed ping does not always mean the destination is offline because ICMP may be filtered.

04 Trace the Network Path

The tracert command can be used to observe the network path between your computer and a destination.

Command Prompt
tracert 8.8.8.8
Example Output 
Tracing route to 8.8.8.8

  1    <1 ms    <1 ms    <1 ms    192.168.1.1
  2     5 ms     6 ms     5 ms    10.20.0.1
  3    12 ms    13 ms    12 ms    203.0.113.1
  4    25 ms    24 ms    25 ms    8.8.8.8
🔎 What to Observe

Observe the hops between your computer and the destination. Each hop represents a router or network device encountered along the path.

05 Test Name Resolution with Ping

Ping can also accept a hostname instead of an IP address. This allows you to observe how a hostname is resolved before connectivity is tested.

Command Prompt
ping google.com
Example Output 
Pinging google.com [142.250.72.14] with 32 bytes of data:

Reply from 142.250.72.14: bytes=32 time=24ms TTL=117
Reply from 142.250.72.14: bytes=32 time=25ms TTL=117
💡 Concept

When a hostname is used, the system normally resolves the hostname to an IP address before sending the ICMP Echo Requests.

06 Test for Packet Loss

Use ping with a larger number of requests to observe packet loss and response times.

Command Prompt
ping 8.8.8.8 -n 10
Example Result 
Ping statistics for 8.8.8.8:

    Packets: Sent = 10,
    Received = 10,
    Lost = 0 (0% loss)

Approximate round trip times:
    Minimum = 23ms
    Maximum = 28ms
    Average = 25ms
🧠 What to Understand

Packet loss represents packets that did not receive a response. Response time represents the approximate round-trip time for an ICMP message.

📡 ICMP Echo Request and Reply

If the destination receives the Echo Request and is configured to respond, it sends an ICMP Echo Reply back to the requesting host.

🧠 Key ICMP Concepts
ICMP Internet Control Message Protocol is used for network control, diagnostics and error reporting.
Echo Request An ICMP message commonly sent by ping to test whether a destination responds.
Echo Reply A response to an ICMP Echo Request when the destination responds.
Ping A diagnostic utility commonly used to test reachability and measure response time.
Tracert A Windows diagnostic command used to display the network path toward a destination.
Packet Loss The percentage of sent packets that do not receive a corresponding response.
