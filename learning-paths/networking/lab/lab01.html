🎯 Lab Objective

In this lab, you will examine the network configuration of your Windows computer and understand how a device communicates with other devices through a network.

You will identify your IP address, default gateway, DNS server and test basic network connectivity.

🔗 Basic Network Communication

A simple network allows devices to communicate with each other and access other networks through networking devices.

01 Find Your IP Address

Open Windows Command Prompt and run the following command:

Command Prompt
ipconfig
Example Output 
Windows IP Configuration

Ethernet adapter Ethernet:

   IPv4 Address. . . . . . : 192.168.1.20
   Subnet Mask . . . . . . : 255.255.255.0
   Default Gateway . . . . : 192.168.1.1
🔎 What to Observe

Find the IPv4 Address, Subnet Mask and Default Gateway displayed for your active network adapter.

02 View Complete Network Configuration

Run the following command to view detailed network configuration.

Command Prompt
ipconfig /all
🔎 Find These Values

Locate the Physical Address (MAC address), IPv4 address, Default Gateway and DNS Servers.

03 Test Network Connectivity

Use the ping command to test whether your computer can communicate with another network host.

Command Prompt
ping 8.8.8.8
Example Output 
Pinging 8.8.8.8 with 32 bytes of data:

Reply from 8.8.8.8: bytes=32 time=25ms TTL=117
Reply from 8.8.8.8: bytes=32 time=24ms TTL=117
Reply from 8.8.8.8: bytes=32 time=26ms TTL=117

Ping statistics:
    Packets: Sent = 3, Received = 3, Lost = 0
💡 Concept

Ping uses ICMP to test basic network reachability between your computer and the destination host.

04 Find Your Default Gateway

Run the following command:

Command Prompt
ipconfig

Look for the line named: 

Default Gateway . . . . . : 192.168.1.1
🌐 Why is it important?

The default gateway is normally the router that provides a path from your local network to other networks.

05 Test DNS Resolution

Use nslookup to check how a domain name is resolved to an IP address.

Command Prompt
nslookup example.com
Example Output 
Server:  dns.example
Address: 192.168.1.1

Name:    example.com
Address: 93.184.216.34
🔎 Concept

DNS translates human-readable domain names into IP addresses that computers can use for communication.

06 Trace the Network Path

Use tracert to observe the network path between your computer and a destination.

Command Prompt
tracert example.com
🛰️ What does it show?

The command displays intermediate network hops encountered while attempting to reach the destination.

🧠 Key Networking Concepts
IP Address Identifies a device/interface on an IP network.
MAC Address Hardware-level address associated with a network interface.
Gateway Provides a path from the local network to other networks.
DNS Resolves domain names into IP addresses.
Ping Tests network reachability using ICMP.
Router Forwards packets between different networks.
