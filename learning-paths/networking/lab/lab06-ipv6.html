Lab Objective

What will you learn? In this lab, you will identify IPv6 addresses on a Windows computer, understand link-local addressing, observe IPv6 configuration, identify an IPv6 default gateway and test IPv6 connectivity using ping and tracert.
IP

IPv6 Concepts

Review the important IPv6 concepts before performing the practical exercises.

01

IPv6 Address

IPv6 uses a 128-bit address written using hexadecimal groups separated by colons.

128-BIT
02

Link-Local Address

Link-local IPv6 addresses are commonly automatically assigned and begin with fe80.

FE80::/10
03

Global Unicast Address

Global unicast addresses can be used for communication across IPv6 networks.

GLOBAL
04

IPv6 Default Gateway

An IPv6 default route provides a path toward networks outside the local IPv6 network.

ROUTER
05

IPv6 Loopback

The loopback address ::1 refers to the local IPv6 host itself.

::1

Important IPv6 Address Types

Use the following table to recognize common IPv6 address types during the practical exercises.

Address Type Range / Address Example Purpose
Link-Local fe80::/10 fe80::1 Local Link
Loopback ::1 ::1 Local Host
Unique Local fc00::/7 fd00::1 Private IPv6
Global Unicast Commonly 2000::/3 2001:db8::1 Global Network
01

Identify Your IPv6 Address

1

Use ipconfig

Open Windows Command Prompt and run the command below to view IPv6 configuration.

ipconfig
Example Output 
IPv6 Address. . . . . . . : 2001:db8:1234:1::20
Link-local IPv6 Address . . : fe80::abcd:1234:5678:90ab
Default Gateway . . . . . : fe80::1

Your actual IPv6 values may be different. Identify the IPv6 address and link-local address assigned to your adapter.

02

View Detailed IPv6 Configuration

2

Use ipconfig /all

Run the following command to inspect detailed IPv6 configuration.

ipconfig /all
Information to Observe 
IPv6 Address
Temporary IPv6 Address
Link-local IPv6 Address
IPv6 Default Gateway
DNS Servers
DHCPv6 Information

Observe the different IPv6 addresses associated with your network adapter.

03

View the IPv6 Routing Table

3

Use route print -6

Run the following command to display the IPv6 routing table.

route print -6
Example 
IPv6 Route Table

::/0
Gateway: fe80::1

::1/128
Interface: Local Host

Look for the default IPv6 route represented by ::/0. It identifies the route used for destinations outside the local IPv6 network.

04

Test IPv6 Connectivity

4

Use ping -6

Test IPv6 connectivity to the IPv6 loopback address.

ping -6 ::1
Expected Output 
Pinging ::1 with 32 bytes of data:
Reply from ::1: time<1ms
Reply from ::1: time<1ms

Ping statistics for ::1:
Packets: Sent = 2, Received = 2, Lost = 0

A successful reply from ::1 confirms that IPv6 is functioning on the local computer.

05

Test an IPv6 Link-Local Address

5

Ping Your IPv6 Gateway

Replace the example address with your actual IPv6 gateway. On Windows, a link-local gateway may require a zone identifier such as %12.

ping -6 fe80::1%12
Example 
Reply from fe80::1%12: time<1ms
Reply from fe80::1%12: time<1ms

Packets: Sent = 2, Received = 2, Lost = 0

The interface identifier such as %12 is only an example. Your Windows system may use a different interface index.

06

Trace an IPv6 Route

6

Use tracert -6

Use tracert with the -6 option to perform an IPv6 route trace to an IPv6 destination.

tracert -6 2001:4860:4860::8888
Example 
Tracing route to IPv6 destination

1    <1 ms    fe80::1
2     8 ms    2001:db8::2
3    20 ms    ...

Trace complete.

The output can show intermediate IPv6 network hops between your computer and the destination.

IPv6 Practical Observations

128-Bit Address

IPv6 uses 128-bit addresses, providing a much larger address space than IPv4.

Link-Local

Link-local IPv6 addresses commonly begin with fe80 and operate on the local link.

Loopback

The IPv6 loopback address ::1 identifies the local computer.

Default Route

The IPv6 default route is represented by ::/0.

Ping -6

The ping -6 command can be used to test IPv6 connectivity.

Tracert -6

Tracert -6 can display IPv6 network hops toward a destination.
