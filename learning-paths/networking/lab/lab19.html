🎯 Lab Objective

In this practical lab, you will inspect Windows proxy configuration, identify whether a proxy is configured, test web connectivity and understand how proxy settings can affect network communication.

The commands are designed for your own computer and should be used only on systems and networks that you own or are authorized to inspect.

💡 What You Will Practice

Check proxy settings → inspect Windows proxy configuration → test web connectivity → test TCP connectivity → compare proxy behavior → understand proxy security.

01 Check WinHTTP Proxy Configuration

Windows provides the netsh command to display the proxy configuration used by WinHTTP applications.

Command Prompt
netsh winhttp show proxy
Example Output 
Current WinHTTP proxy settings:

    Direct access (no proxy server).
🔎 What to Observe

Check whether Windows reports direct access or a configured proxy server. Your actual result depends on the configuration of your computer and network.

02 Inspect Windows Internet Proxy Settings

Windows Internet settings can contain a proxy configuration used by applications that rely on WinINet settings.

PowerShell
Get-ItemProperty "HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings" | Select-Object ProxyEnable, ProxyServer, ProxyOverride
Example Output 
ProxyEnable ProxyServer ProxyOverride
----------- ----------- -------------
0
🧠 Understand the Result

ProxyEnable indicates whether the Windows Internet proxy setting is enabled. ProxyServer shows a configured proxy address when one is present.

03 Test Web Connectivity

Use curl to send a web request and observe whether the destination responds.

Command Prompt
curl.exe -I https://example.com
Example Output 
HTTP/1.1 200 OK
Content-Type: text/html
Content-Length: 1256
🧠 Understand the Result

A successful HTTP response shows that the web request reached the destination and a response was received. The exact headers can vary depending on the destination.

04 Test TCP Connectivity

PowerShell provides Test-NetConnection for testing TCP connectivity to a destination and port.

PowerShell
Test-NetConnection example.com -Port 443
Example Output 
ComputerName     : example.com
RemotePort       : 443
InterfaceAlias   : Wi-Fi
TcpTestSucceeded : True
🔎 Interpretation

TcpTestSucceeded : True means the TCP connection test succeeded. InterfaceAlias shows the network interface Windows used for that connection.

05 Trace the Network Path

Use tracert to observe the network path toward a destination. This helps you understand the route used by the network.

Command Prompt
tracert example.com
Example Output 
Tracing route to example.com

  1    192.168.1.1
  2    10.0.0.1
  3    203.0.113.1
  4    example.com

Trace complete.
🔎 What to Observe

Observe the responding hops. The actual path depends on your local network, ISP, routing configuration and destination. A proxy can change the application-level destination path, so tracert should not be interpreted as a complete description of HTTP proxy behavior.

06 Check DNS Configuration

DNS is used to resolve domain names into IP addresses. Inspect the DNS configuration of your Windows system.

Command Prompt
ipconfig /all | findstr /i "DNS Servers"
Example Output 
DNS Servers . . . . . . . . . . :
192.168.1.1
🛡️ Security Use

DNS configuration is important when troubleshooting web connectivity and investigating network behavior. Proxy software can also have application-specific DNS behavior depending on how it is configured.

07 Test a Web Request

Use PowerShell's Invoke-WebRequest to test whether a web resource can be requested successfully.

PowerShell
Invoke-WebRequest -Uri https://example.com -Method Head
Example Output 
StatusCode        : 200
StatusDescription : OK
Content           :
RawContent        : HTTP/1.1 200 OK
🧠 Understand the Result

A status code such as 200 indicates that the web server returned a successful response. The exact result depends on the destination and your network configuration.

08 Mini Proxy Investigation

Complete this short investigation on your own Windows system. Inspect your proxy settings and compare the results with your normal web connectivity.

🧪 Task

1. Run netsh winhttp show proxy.
2. Inspect Windows Internet proxy settings.

4. Run Test-NetConnection example.com -Port 443.

🌐 Proxy Concepts — Practical Understanding
Proxy Client A client application or system configuration that sends requests through a proxy server.
Proxy Server A server that receives requests from clients and can make network requests on their behalf.
Forward Proxy A proxy used by clients to access external resources through an intermediary server.
Proxy Address The hostname or IP address used to identify the proxy server.
Proxy Port The network port through which a proxy service accepts client connections.
Proxy Override Rules that specify destinations that should bypass the configured proxy.
⚖️ Proxy Types and Behavior
Forward Proxy Acts on behalf of clients when accessing external network resources.
Reverse Proxy Sits in front of servers and receives requests from clients before forwarding them to backend servers.
HTTP Proxy A proxy designed primarily for HTTP-based web communication.
HTTPS Proxy Can support HTTPS traffic through proxy mechanisms such as HTTP CONNECT.
Proxy Bypass Some destinations can be configured to connect directly instead of using the proxy.
Proxy Authentication A proxy can require clients to authenticate before allowing requests.
🛡️ Cybersecurity Application

Proxy knowledge is important for cybersecurity professionals because proxies can affect traffic visibility, access control, web filtering and network monitoring.

Web Filtering Organizations can use proxies to control access to selected websites and web resources.
Traffic Monitoring Security teams can use authorized proxy infrastructure to monitor web traffic according to organizational policy.
Access Control Proxy systems can enforce policies that determine which resources users can access.
Logging Proxy servers can generate logs containing information about requests and connections.
Reverse Proxy Security Reverse proxies can sit in front of web applications and support security and traffic-management controls.
Security Limitation A proxy is not automatically a security solution. Its protection depends on configuration, policies and the surrounding security controls.
🛠️ Troubleshooting

If web access is not working as expected, check the proxy configuration logically instead of changing multiple settings at the same time.
