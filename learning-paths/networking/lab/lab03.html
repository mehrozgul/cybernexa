Lab Objective

What will you learn? In this lab, you will understand the four layers of the TCP/IP Model and connect common networking commands and protocols with their corresponding layers.
4

Four TCP/IP Layers

Review the four TCP/IP layers before performing the practical exercises.

4

Application Layer

Provides network services directly to applications.

HTTP / DNS
3

Transport Layer

Provides end-to-end communication using TCP or UDP.

TCP / UDP
2

Internet Layer

Handles logical addressing and packet routing between networks.

IP / ICMP
1

Network Access Layer

Handles communication over the local physical network.

Ethernet / MAC
01

Identify Your TCP/IP Network Configuration

1

Check IP Configuration

Open Windows Command Prompt and run the following command.

ipconfig

Observe your IPv4 address, subnet mask and default gateway. These values demonstrate addressing and routing concepts associated with the Internet Layer.

02

Test Internet Layer Connectivity

2

Use Ping

Use the ping command to test connectivity with a destination.

ping 8.8.8.8
Expected Output 
Reply from 8.8.8.8: bytes=32 time<20ms TTL=...

Ping uses ICMP and demonstrates communication at the Internet Layer of the TCP/IP Model.

03

Observe TCP/IP Routing

3

Use Tracert

Run tracert to observe the route toward a destination.

tracert example.com
Example Output 
Tracing route to example.com
1    <1 ms    192.168.1.1
2    10 ms    ...
3    20 ms    ...
Trace complete.

Tracert helps demonstrate IP routing and the movement of packets between different networks.

04

Identify TCP/IP Application Activity

4

Use Nslookup

Use DNS lookup to observe an Application Layer network service.

nslookup example.com
Expected Output 
Server:  ...
Address: ...

Name:    example.com
Addresses: ...

DNS is an Application Layer service in the TCP/IP Model. The nslookup command allows you to observe DNS resolution.

⇄

Practical Observations

Application Layer

DNS and HTTP are examples of services used by applications over a network.

Transport Layer

TCP and UDP provide communication services between applications and the network.

Internet Layer

IP, ICMP, ping and tracert demonstrate Internet-layer communication and routing.

Network Access Layer

Ethernet frames and MAC addresses are used for communication on the local network.
