Explore how Network Address Translation (NAT) allows devices using private IP addresses to communicate with external networks through a router.

🎯 Lab Objective

In this lab, you will examine how NAT works between a private local network and an external network.

You will identify your private IP address, default gateway and public IP address, and observe how a router provides access to external networks.

🔗 Basic NAT Communication

NAT allows multiple devices on a private network to communicate with the Internet using a public IP address.

01 Find Your Private IP Address

Open Windows Command Prompt and run the following command:

Command Prompt
ipconfig
Example Output 
Windows IP Configuration

Wireless LAN adapter Wi-Fi:

   IPv4 Address. . . . . . : 192.168.1.20
   Subnet Mask . . . . . . : 255.255.255.0
   Default Gateway . . . . : 192.168.1.1
🔎 What to Observe

Identify the IPv4 address assigned to your computer. Addresses such as 192.168.x.x, 10.x.x.x and 172.16.x.x–172.31.x.x are commonly used private IPv4 address ranges.

02 Find Your Default Gateway

Use the following command to identify the router that normally acts as the gateway for your local network.

Command Prompt
ipconfig
Example Output 
Default Gateway . . . . . : 192.168.1.1
🌐 NAT Concept

In a typical home network, the router performs NAT between devices using private IP addresses and the public IP address used toward the Internet.

03 View the NAT Router Path

Use tracert to observe the path from your computer toward an external destination.

Command Prompt
tracert example.com
Example Output 
Tracing route to example.com

  1    2 ms    1 ms    1 ms   192.168.1.1
  2   12 ms   11 ms   13 ms   10.20.0.1
  3   24 ms   23 ms   25 ms   ...
💡 Concept

The first hop is often the local router/default gateway. NAT itself is an address-and-port translation function; tracert does not directly display the NAT translation table.

04 Identify Your Public IP

A private IP address identifies your device inside the local network. The public IP address is used by the network toward the Internet.

Example 
Private IP:
192.168.1.20

Default Gateway:
192.168.1.1

Public IP:
203.0.113.25
🔎 Important

The public IP shown by an Internet service may belong to your router or another upstream NAT device rather than directly to your computer.

05 Observe NAT Through an External Connection

Open a browser and visit a public IP-checking service. Compare the public IP shown there with your computer's private IPv4 address from ipconfig.

Example Observation 
Computer Private IP:
192.168.1.20

Router / Gateway:
192.168.1.1

Public Internet IP:
203.0.113.25
🔄 NAT Translation

When your computer sends traffic to the Internet, the NAT device can translate the private source address into a public source address.

06 Understand Port Address Translation

Modern home routers commonly use Port Address Translation (PAT), also called NAT overload, allowing multiple private devices to share one public IPv4 address by using different source port numbers.

Example 
Device A
Private: 192.168.1.20:5000
        |
        | NAT
        v
Public: 203.0.113.25:40001


Device B
Private: 192.168.1.21:5001
        |
        | NAT
        v
Public: 203.0.113.25:40002
🧠 Concept

Both devices can use the same public IP because the NAT device keeps track of different translated port mappings.

🧠 Key NAT Concepts
NAT Translates IP addresses between different address spaces, commonly private and public IPv4 addresses.
Private IP An IP address used inside a private network and normally not routed directly across the public Internet.
Public IP An address used for communication across public networks.
PAT Uses port numbers to allow multiple private devices to share a public IPv4 address.
Gateway The local router/interface used to reach other networks.
NAT Router A router that performs address translation between private and external networks.

📘 Lab Summary

In this practical lab, you examined the relationship between private IP addresses, the default gateway and the public Internet.

You learned that NAT can translate private IPv4 addresses into public addresses, while PAT can use port numbers to allow multiple private devices to share a public IPv4 address.

Lab Safety

Perform these exercises only on systems and networks that you own or are explicitly authorized to test. The commands in this lab are intended for basic network observation and learning about NAT behavior.
