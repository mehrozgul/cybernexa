🎯 Lab Objective

In this practical lab, you will create a simple LAN using PCs, a Cisco switch and a Cisco router.

You will configure the switch hostname, basic security, management IP and ports. You will then configure the router interface, assign IP addresses and verify communication.

💡 What You Will Learn

Switches connect devices inside the same local network, while routers connect different IP networks and act as the gateway for hosts.

02 Configure PC Addresses

Open each PC in Packet Tracer and go to Desktop → IP Configuration.

💻 PC1

IP Address: 192.168.10.10
Subnet Mask: 255.255.255.0
Default Gateway: 192.168.10.1

💻 PC2

IP Address: 192.168.10.20
Subnet Mask: 255.255.255.0

03 Configure the Switch

Open SW1 → CLI and enter the following commands.

Cisco IOS — SW1
enable configure terminal hostname SW1 no ip domain-lookup enable secret class service password-encryption line console 0 password cisco login exit
🔎 Why These Commands?

The hostname identifies the switch. The enable secret protects privileged mode. Password encryption protects configured plain-text passwords, while the console password controls local console access.

04 Configure Switch Management IP

Configure VLAN 1 with the switch management address and configure the default gateway.

Cisco IOS — SW1
enable configure terminal interface vlan 1 ip address 192.168.10.2 255.255.255.0 no shutdown exit ip default-gateway 192.168.10.1 end write memory
Verify 
show ip interface brief
05 Configure Switch Ports

Configure the ports connected to the PCs as access ports. This lab keeps the configuration simple by using one LAN.

Cisco IOS — SW1
enable configure terminal interface range fa0/1 - 2 switchport mode access spanning-tree portfast no shutdown exit end write memory
🧠 What is an Access Port?

An access port normally carries traffic for a single VLAN and is commonly used for end devices such as PCs.

06 Configure the Router

Open R1 → CLI and configure the router hostname and basic access protection.

Cisco IOS — R1
enable configure terminal hostname R1 no ip domain-lookup enable secret class service password-encryption line console 0 password cisco login exit
07 Configure Router Interface

Configure G0/0 as the default gateway for the 192.168.10.0/24 LAN.

Cisco IOS — R1
enable configure terminal interface gigabitEthernet 0/0 description LAN-Gateway ip address 192.168.10.1 255.255.255.0 no shutdown exit end write memory
Verify Router Interface 
show ip interface brief
📌 Expected State

G0/0 should have IP address 192.168.10.1 and should become up/up when the physical connection and configuration are correct.

08 Configure the Switch-to-Router Link

Connect SW1 Fa0/24 to R1 G0/0. Configure Fa0/24 as an access port in VLAN 1 for this simple single-LAN lab.

Cisco IOS — SW1
enable configure terminal interface fa0/24 switchport mode access no shutdown exit end write memory

11 Test Connectivity

Use the PC Command Prompt in Packet Tracer to test the devices one by one.

PC1 — Command Prompt
ping 192.168.10.1 ping 192.168.10.2 ping 192.168.10.20
Successful Test 
Reply from 192.168.10.1:
Reply from 192.168.10.2:
Reply from 192.168.10.20:

A successful reply indicates that the destination
responded to the ICMP echo request.
🔎 Test Order

First test the default gateway, then the switch management IP, and finally the other PC. This helps isolate configuration or connectivity problems.

12 View the Switch MAC Address Table

A switch learns source MAC addresses and stores them in its MAC address table to make Layer 2 forwarding decisions.

Cisco IOS — SW1
show mac address-table
🧠 What to Observe

Look for learned MAC addresses and the switch ports where those addresses were learned.

13 View the ARP Table

ARP maps IPv4 addresses to MAC addresses on a local network.

Cisco IOS — R1
show arp
⚖️ Router vs Switch
Switch Primarily operates at Layer 2 and forwards Ethernet frames using MAC addresses.
Router Primarily operates at Layer 3 and forwards packets between IP networks.
Switch Gateway A Layer 2 switch does not normally provide the default gateway for hosts; the router does.
MAC Address Switches use MAC addresses to make local Layer 2 forwarding decisions.
IP Address Routers use IP addressing and routing information to move traffic between networks.
Default Gateway Hosts use the default gateway when traffic is destined for another IP network.
🛠️ Troubleshooting

If the ping test fails, check the configuration in a logical order instead of changing multiple settings at once.

🛡️ Why Router & Switch Knowledge Matters in Cybersecurity

Cybersecurity professionals need to understand normal network behavior before they can investigate suspicious traffic or network attacks.

Network Segmentation Switches and routers can help separate systems into different network segments.
Traffic Analysis Understanding Layer 2 and Layer 3 traffic makes network monitoring easier to interpret.
Access Control Network devices can apply controls that restrict or permit specific traffic.
Incident Response Network topology and device configuration help investigators understand where traffic travels.
Routing Routing knowledge helps explain how packets move between different IP networks.
Layer 2 Security Switch configuration is relevant to practical defenses involving local network access.
✓ Lab Completion Checklist
🧠 Key Concepts
Switch Connects devices within a local network and forwards frames using MAC addresses.
Router Connects IP networks and forwards packets based on Layer 3 addressing.
Gateway The router address used by a host to reach destinations outside its local subnet.
VLAN A logical Layer 2 network used to separate broadcast domains.
MAC Table A switch table that records learned MAC addresses and their associated interfaces.
ARP A mechanism used by IPv4 devices to discover the MAC address associated with an IP address.
