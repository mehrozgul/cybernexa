🎯 Lab Objective

In this lab, you will learn how ARP helps a device determine the MAC address associated with an IPv4 address on the local network.

You will inspect the ARP cache, generate ARP activity, identify IP-to-MAC mappings and clear the ARP cache.

🔗 How ARP Works

When a computer needs to communicate with another device on the same local network, it may need the destination device's MAC address. ARP helps discover that mapping.

💡 Basic Idea

ARP resolves a known IPv4 address into the corresponding MAC address needed for local Ethernet communication.

01 View the ARP Cache

Open Windows Command Prompt and run the following command to display the current ARP cache.

Command Prompt
arp -a
Example Output 
Interface: 192.168.1.20 --- 0x8
  Internet Address      Physical Address      Type
  192.168.1.1           aa-bb-cc-dd-ee-ff     dynamic
  192.168.1.10          11-22-33-44-55-66     dynamic
🔎 What to Observe

Look for the Internet Address, Physical Address and Type columns. The Internet Address represents the IPv4 address, while the Physical Address represents the MAC address.

02 Generate ARP Activity

First identify your default gateway using ipconfig.

Command Prompt
ipconfig

Then send a ping to your local gateway. Replace the example address with the gateway shown on your computer.

Command Prompt
ping 192.168.1.1
🔎 Why Do This?

Communicating with a local host can cause your computer to learn or refresh the IP-to-MAC mapping required for local network communication.

03 Check the ARP Entry

After communicating with the gateway, display the ARP cache again.

Command Prompt
arp -a
Example Entry 
Internet Address      Physical Address      Type
192.168.1.1           aa-bb-cc-dd-ee-ff     dynamic
💡 Concept

The ARP table stores mappings between IPv4 addresses and MAC addresses so that local communication can take place at the link layer.

04 View a Specific ARP Entry

You can display the ARP information associated with a specific IP address.

Command Prompt
arp -a 192.168.1.1
🔎 What to Observe

Replace 192.168.1.1 with an IP address from your local network. The command can be used to inspect the ARP information for that interface/address.

05 Clear the ARP Cache

Windows provides a command for deleting ARP cache entries. Run Command Prompt as Administrator before using it.

Administrator Command Prompt
arp -d *
⚠️ Important

This removes dynamic ARP entries from the ARP cache. The cache may be populated again when your computer communicates with devices on the local network.

06 Observe ARP Cache Again

After clearing the cache, display the ARP table again.

Command Prompt
arp -a
🧠 What to Understand

Some entries may disappear after the cache is cleared. New mappings can appear again when your computer needs to communicate with local devices.

📡 ARP Request and Reply

ARP normally uses a request-and-reply process when a host needs to discover the MAC address associated with a local IPv4 address.

📩 ARP Reply

The device that owns the requested IPv4 address can respond with its MAC address. The requesting host can then use that information for local communication.

🧠 Key ARP Concepts
ARP Address Resolution Protocol maps an IPv4 address to a MAC address on a local network.
IPv4 Address A logical network-layer address used to identify an interface on an IP network.
MAC Address A link-layer address associated with a network interface.
ARP Cache A local table containing learned IP-to-MAC address mappings.
ARP Request A request used to discover the MAC address associated with a local IPv4 address.
ARP Reply A response that provides the requested MAC address information.
