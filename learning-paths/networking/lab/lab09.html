DNS Practical Lab

Practice DNS name resolution using Windows networking commands. Learn how to query DNS, inspect records, clear the DNS cache and troubleshoot basic DNS resolution problems.

Lab Objective

What will you learn? In this lab you will perform practical DNS queries, identify DNS records, inspect your DNS configuration, clear the local DNS cache and verify DNS name resolution using Windows command-line tools.
Requirement: Windows PC or laptop
Tool: Command Prompt
Internet: Recommended
Knowledge: Basic Networking
STEP 01
Check Your DNS Configuration

First, check which DNS server your computer is currently using.

Command Prompt 
ipconfig /all
Look for: 
DNS Servers . . . . . . . . . . : 192.168.1.1
What does this show?

The DNS Servers field shows the DNS server configured for your network connection. Your actual DNS server address may be different.

STEP 02
Perform a Basic DNS Lookup

Use nslookup to find the IP address associated with a domain name.

Command Prompt 
nslookup example.com
Example Output 
Server:  your-dns-server
Address:  192.168.1.1

Non-authoritative answer:
Name:    example.com
Address: 93.184.216.34
What happened?

The DNS server received the query for example.com and returned the IP address associated with the domain.

STEP 03
Query an A Record

An A record maps a domain name to an IPv4 address. Use nslookup to specifically request an A record.

Command Prompt 
nslookup -type=A example.com
Key Concept

The A record is used for IPv4 address resolution. The returned address can be used by applications to reach the destination server.

STEP 04
Query an MX Record

MX records identify mail servers responsible for receiving email for a domain.

Command Prompt 
nslookup -type=MX example.com
Why is this useful?

DNS record queries help administrators and security learners understand which services are associated with a domain.

STEP 05
View and Clear DNS Cache

Windows temporarily stores DNS responses in a local DNS cache. You can inspect and clear this cache using Command Prompt.

View DNS Cache 
ipconfig /displaydns
Clear DNS Cache 
ipconfig /flushdns
Typical Flush Result 
Windows IP Configuration

Successfully flushed the DNS Resolver Cache.
Troubleshooting Use

Clearing the DNS cache can help when an old or incorrect cached DNS response is causing name-resolution problems.

STEP 06
Test DNS Resolution

Finally, verify that your system can resolve a domain name correctly.

Command Prompt 
nslookup google.com
Expected Result 
Server:  your-dns-server
Address:  your-dns-server-address

Name:    google.com
Address: returned-ip-address
Result

If nslookup returns an IP address for the domain, DNS name resolution is working. If the lookup fails, the DNS configuration or network connection should be investigated.

▣

Common DNS Records

Use these record types as a quick reference while performing DNS queries.

Record Purpose Example Query
A Domain → IPv4 nslookup -type=A example.com
AAAA Domain → IPv6 nslookup -type=AAAA example.com
MX Mail server nslookup -type=MX example.com
CNAME Domain alias nslookup -type=CNAME example.com
⚙

DNS Troubleshooting Practice

If a website name is not resolving, follow these basic troubleshooting steps.

  • Check the computer's DNS server using ipconfig /all.
  • Test the domain using nslookup.
  • Check whether the DNS server responds.
  • Clear the local DNS cache using ipconfig /flushdns.
  • Perform the DNS lookup again.
  • Compare the result with another working DNS configuration if necessary.
