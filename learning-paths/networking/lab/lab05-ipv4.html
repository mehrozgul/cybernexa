IPv4 Address

IPv4 uses a 32-bit address represented by four decimal octets separated by dots.

32-BIT
02

NETWORK

Default Gateway

Private IPv4 Address Ranges

The following IPv4 ranges are reserved for private networks such as homes, offices and laboratories.

Range CIDR Example Common Use
10.0.0.0 – 10.255.255.255 10.0.0.0/8 10.0.0.10 Private Network
172.16.0.0 – 172.31.255.255 172.16.0.0/12 172.16.5.20 Private Network
192.168.0.0 – 192.168.255.255 192.168.0.0/16 192.168.1.20 Home / LAN
01

Identify Your IPv4 Address

1

Use ipconfig

Open Windows Command Prompt and execute the following command.

ipconfig
Example Output 
IPv4 Address. . . . . . . : 192.168.1.20
Subnet Mask . . . . . . . : 255.255.255.0
Default Gateway . . . . . : 192.168.1.1

Find and record your actual IPv4 address, subnet mask and default gateway.

02

View Detailed IPv4 Configuration

2

Use ipconfig /all

Run the following command to view detailed network configuration.

ipconfig /all
Information to Observe 
IPv4 Address
Subnet Mask
Default Gateway
DHCP Enabled
DNS Servers
Physical Address

Observe how Windows receives and stores the IPv4 configuration of your network adapter.

03

Identify the IPv4 Default Gateway

3

View the Routing Table

Use the following command to display the IPv4 routing table.

route print -4
Example 
Network Destination    Netmask
0.0.0.0                0.0.0.0
Gateway                192.168.1.1

Look for the default route beginning with 0.0.0.0. The gateway shown there is normally the router used to reach other networks.

04

Test IPv4 Connectivity

4

Ping the Default Gateway

Replace the example address with your actual IPv4 default gateway.

ping 192.168.1.1
Expected Output 
Reply from 192.168.1.1: bytes=32 time<1ms TTL=64
Reply from 192.168.1.1: bytes=32 time<1ms TTL=64

A successful reply indicates that your computer can communicate with the IPv4 gateway.

05

Trace an IPv4 Route

5

Use tracert

Use tracert to observe the IPv4 path toward a destination such as a public website.

tracert 8.8.8.8
Example 
Tracing route to 8.8.8.8
over a maximum of 30 hops

1    <1 ms    192.168.1.1
2     5 ms    10.0.0.1
3    20 ms    ...
Trace complete.

The output shows intermediate network hops between your computer and the destination.

IPv4 Practical Observations

32-Bit Address

IPv4 addresses contain 32 bits and are commonly represented using four octets.

Subnet Mask

The subnet mask separates the network portion from the host portion.

Private Address

Private IPv4 addresses are commonly used inside local networks.

Default Gateway

The default gateway provides a path from the local network to other networks.

Ping

Ping can be used to test basic IPv4 reachability to another host.

Tracert

Tracert can display the network hops toward an IPv4 destination.
