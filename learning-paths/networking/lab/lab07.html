MAC Address Concepts

Review the important MAC address concepts before performing the practical exercises.

01

MAC Address

A MAC address is a hardware-level identifier associated with a network interface.

LAYER 2
02

48-Bit Address

A standard MAC address is 48 bits and is normally represented using six hexadecimal pairs.

48-BIT
03

Physical Address

Windows commonly displays the MAC address under the name Physical Address.

WINDOWS
04

Network Adapter

A computer can have different MAC addresses for Ethernet, Wi-Fi, virtual and other network interfaces.

Locally Administered Address

Some operating systems and devices can use a locally administered MAC address instead of the adapter's factory-assigned address.

MAC Address Format

A typical MAC address contains six hexadecimal pairs. Different systems may display the same address using different separators.

Format Example Description
Hyphen 00-1A-2B-3C-4D-5E Common Windows display format
Colon 00:1A:2B:3C:4D:5E Common networking notation
Cisco Style 001A.2B3C.4D5E Often used in Cisco networking
01

Identify Your MAC Address

1

Use getmac

Open Windows Command Prompt and run the following command to display the MAC addresses of available network adapters.

getmac
Example Output 
Physical Address    Transport Name
=================== =================================
A4-B1-C2-D3-E4-F5   \Device\Tcpip_{...}

Identify the physical address associated with your active network adapter. The value shown on your computer will normally be different from the example.

02

View MAC Address with ipconfig

2

Use ipconfig /all

Run the following command to display detailed information about your network adapters.

ipconfig /all
Information to Observe 
Description
Physical Address
DHCP Enabled
IPv4 Address
Subnet Mask
Default Gateway
DNS Servers

Find the Physical Address field under your active Ethernet or Wi-Fi adapter. This is the MAC address associated with that network interface.

03

View MAC Addresses Using PowerShell

3

Use Get-NetAdapter

Open Windows PowerShell and run the following command to display network adapter information.

Get-NetAdapter
Example Output 
Name       InterfaceDescription       MacAddress
----       --------------------       ----------
Wi-Fi      Wireless Adapter          A4-B1-C2-D3-E4-F5
Ethernet   Ethernet Adapter          00-1A-2B-3C-4D-5E

Observe the adapter name, interface description, MAC address and connection state. Your system may display different adapter names and addresses.

04

Compare Ethernet and Wi-Fi MAC Addresses

4

Identify Network Interfaces

Run the following command and identify the different network adapters installed on your computer.

Get-NetAdapter | Select-Object Name, MacAddress, Status
Example 
Name       MacAddress           Status
----       ----------           ------
Wi-Fi      A4-B1-C2-D3-E4-F5    Up
Ethernet   00-1A-2B-3C-4D-5E    Disconnected

A computer may have separate MAC addresses for different network interfaces. For example, the Wi-Fi adapter and Ethernet adapter normally have different physical addresses.

05

Check the MAC Address in Windows Settings

5

Open Network Adapter Properties

You can also find the MAC address through Windows graphical settings.

Windows Steps 
Settings
→ Network & Internet
→ Wi-Fi or Ethernet
→ Hardware Properties
→ Physical Address (MAC)

Compare the physical address shown in Windows Settings with the address displayed by ipconfig /all or Get-NetAdapter.

Practical Observations

MAC Address

A MAC address identifies a network interface at the data-link layer of networking.

Physical Address

Windows commonly displays the MAC address using the label Physical Address.

48-Bit Identifier

A standard MAC address contains 48 bits and is normally displayed as six hexadecimal pairs.

Wi-Fi Adapter

The Wi-Fi interface normally has its own MAC address separate from other network adapters.

Ethernet Adapter

A wired Ethernet interface normally has its own MAC address.

Local Network

MAC addresses are important for communication within a local Ethernet or Wi-Fi network.
