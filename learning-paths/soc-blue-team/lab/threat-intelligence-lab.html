Threat Intelligence Investigation

Practice the basic Threat Intelligence workflow by examining security indicators, identifying their type, adding context and deciding how the information can support SOC investigation.

Lab Objective

Learn how a SOC analyst can use threat intelligence information during an investigation.

Scenario: Your SOC has detected several suspicious events. You have received a small set of indicators and must analyze them before deciding what action should be taken.

The exercise uses fictional training indicators. They are provided only for learning and investigation practice.

Analyst Analysis

Use context instead of treating every indicator as automatically malicious.

STEP 01

Identify

Determine whether the artifact is an IP address, domain, URL, hash or another indicator.

STEP 02

Correlate

Compare the indicator with available logs, alerts, security reports and other relevant information.

STEP 03

Prioritize

Use the available context to determine whether the indicator requires further investigation or response.

Investigation Result

The indicators should not be treated as malicious solely because they appear in a dataset. A SOC analyst should correlate indicators with additional evidence such as logs, endpoint activity, network connections and threat reports. The purpose of Threat Intelligence is to add context that helps analysts make better security decisions.

Analyst Checklist

Use this checklist during a basic intelligence investigation.

✓ Identify Indicator
Determine the indicator type.
✓ Collect Context
Find where and when it appeared.
✓ Correlate Events
Compare it with security logs and alerts.
✓ Assess Risk
Consider the available evidence.
✓ Document Findings
Record observations and evidence.
✓ Escalate When Required
Send significant findings for further investigation.
