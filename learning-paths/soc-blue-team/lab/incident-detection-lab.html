Incident Detection Lab

Analyze simulated SOC security events, identify suspicious activity, validate detection alerts and determine which events should be escalated as potential incidents.

Lab Objective

Learn how a SOC analyst identifies potential incidents from security events.

What You Need To Do

  1. Review the security events shown below.
  2. Select a severity filter if required.
  3. Run the detection engine.
  4. Identify events marked as suspicious.
  5. Inspect the detected events.
  6. Determine which activity should be escalated.

Security Event Analysis

The following events represent simulated SOC telemetry.

ID Time Source Event Severity Status

EVT-003 09:16:43 Server-02 Successful login after repeated failures HIGH Suspicious
EVT-004 09:19:11 Workstation-03 Normal DNS request LOW Normal
EVT-005 09:21:55 Endpoint-12 Connection to known malicious IP CRITICAL Suspicious
EVT-006 09:24:30 Firewall-01 Blocked outbound connection MEDIUM Blocked

Detection Result

Detection Finding

The detection engine identifies events that match suspicious conditions such as repeated authentication failures followed by successful access or communication with a known malicious IP.

SOC Analyst Action

A suspicious event should be investigated using additional logs, endpoint information, network activity and threat intelligence. Confirmed or high-risk activity should be escalated.
