SOC Network Monitoring Lab

Analyze Network Traffic

Practice identifying source and destination IP addresses, ports, protocols and unusual network behavior using a simulated SOC monitoring environment.

Lab Objective

What you will practice in this exercise.

In this lab, you will analyze simulated network traffic and determine which activity appears normal and which activity requires further investigation. You will inspect IP addresses, ports, protocols and connection behavior.

⚠ Monitoring Finding

The traffic from 192.168.1.40 to 185.22.91.17 over TCP/4444 appears unusual compared with the other observed traffic. The repeated connection should be investigated further to determine whether it represents legitimate activity or a security event.
