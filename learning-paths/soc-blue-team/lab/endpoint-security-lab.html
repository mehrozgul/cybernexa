Lab Scenario

You are working as a junior SOC analyst. A workstation has been selected for a basic endpoint security assessment.

Target: WORKSTATION-07

The endpoint belongs to an employee workstation. Your task is to check important security controls, identify suspicious conditions and decide which security improvements should be applied. Do not assume that every abnormal condition is automatically a confirmed compromise. Investigate the available evidence before making a conclusion.

Recommended Defensive Actions

  • Enable and properly configure the host firewall.
  • Keep endpoint protection software active and updated.
  • Apply missing operating-system security updates.
  • Investigate suspicious processes before terminating them.
  • Remove or review unauthorized software according to policy.
  • Investigate unusual authentication activity and review account security when necessary.
