Basic Threat Hunting

Basic Threat Hunting is the proactive process of searching security data, logs, endpoints and network activity for suspicious behavior that automated security tools may not have detected.

Definition

Understand the basic meaning of Threat Hunting before performing an investigation.

Core Definition

Threat Hunting is a proactive cybersecurity activity in which security analysts actively search systems, networks, endpoints and security data for signs of malicious or suspicious activity that may not have been detected by existing security controls.

How Threat Hunting Works

Threat hunting is based on investigation rather than waiting for an alert to appear.

A SOC normally receives alerts from security tools such as SIEM platforms, endpoint security systems and network monitoring solutions.

Threat hunting goes one step further. Instead of waiting for an alert, an analyst develops a reasonable hypothesis about possible malicious activity and searches available security data for supporting evidence.

The analyst may examine authentication logs, process activity, network connections, DNS requests, endpoint events and other security telemetry.

If suspicious behavior is discovered, the analyst investigates the activity further and determines whether it represents a potential security incident.

Why Threat Hunting Matters

Threat hunting helps security teams discover suspicious activity that may bypass automated detection.

REASON 01

Find Hidden Threats

Attackers may remain inside an environment without generating an obvious security alert. Hunting helps search for such activity.

REASON 02

Improve Detection

Hunting findings can help analysts improve detection rules, alerts and security monitoring.

REASON 03

Understand Attacker Behavior

Analysts can investigate patterns and behaviors that may indicate reconnaissance, persistence or other malicious activity.

Threat Hunting Process

A simplified hunting workflow used by security analysts.

Threat Hunting Hypothesis

A hypothesis gives the analyst a specific question to investigate.

Example Hunting Hypothesis

"An attacker may be attempting to access user accounts through repeated failed authentication attempts followed by a successful login from an unusual source."

FailedLogins > 5 + SuccessfulLogin + UnusualSource = Investigate Activity

Simple Example

Consider a basic authentication investigation.

⚠ Suspicious Pattern

An analyst notices that an account has several failed login attempts followed by a successful login from an unfamiliar IP address.

✓ Hunting Investigation

The analyst searches authentication logs, checks the source IP, reviews login times and looks for additional suspicious activity involving the same account.

Key Concepts

Important terms to remember from Basic Threat Hunting.

Threat Hunting: Proactively searching for hidden or suspicious activity.
Hypothesis: A security assumption or question that guides the investigation.
Telemetry: Security data collected from systems, endpoints and networks.
Hunt Query: A search used to identify potentially suspicious activity.
Evidence: Information that supports or disproves a security hypothesis.
Threat Indicator: A data point that may indicate malicious activity.

Summary

Basic Threat Hunting is a proactive SOC activity used to search for suspicious behavior that may not have triggered an automated security alert. Analysts create a hypothesis, collect relevant security data, perform searches, investigate suspicious results, validate their findings and use the results to improve security monitoring and detection. Threat hunting therefore complements automated detection and helps security teams discover potentially hidden threats.
