SOC MONITORING

What is Log Monitoring?

Log Monitoring is the continuous observation and analysis of system, network, application and security logs to identify suspicious activity, security events and potential threats.

Definition

Understand the basic meaning of Log Monitoring in a SOC.

Core Definition

Log Monitoring is the process of continuously collecting, reviewing and analyzing logs generated by systems, applications, network devices and security tools to identify unusual, suspicious or potentially malicious activity.

How Log Monitoring Works

A SOC uses logs as an important source of security visibility.

Every operating system, server, application and network device can generate logs that record activities and events.

Security analysts monitor these records to understand what is happening inside an environment and to identify activity that may indicate a security problem.

For example, repeated failed login attempts, unusual authentication activity, unexpected administrative actions or connections to suspicious destinations may require further investigation.

In a professional SOC, logs may be collected centrally so analysts can search, correlate and investigate events more efficiently.

Common Log Sources

Different security-relevant systems generate different types of logs.

SOURCE 01

Windows Logs

Authentication events, process activity, system events, account changes and security-related activities.

SOURCE 02

Linux Logs

Authentication, system services, SSH activity, errors and other operating-system events.

SOURCE 03

Firewall Logs

Network connections, blocked traffic, allowed traffic, source addresses and destination information.

SOURCE 04

Web Server Logs

HTTP requests, client addresses, requested resources, response codes and web activity.

SOURCE 05

Authentication Logs

Successful and failed login attempts, account activity and authentication events.

SOURCE 06

Security Tools

EDR, IDS, IPS and other security technologies can generate events useful for investigation.

Simple SOC Example

See how log monitoring can reveal suspicious activity.

⚠ Suspicious Activity

A server records many failed login attempts for the same account within a short period, followed by a successful login from an unusual source address.

✓ Analyst Monitoring

The analyst reviews the related logs, checks the source address, examines authentication history and determines whether the activity requires further investigation.

Key Concepts

Important terms to remember when working with security logs.

Log: A record of an event or activity generated by a system, application or security device.
Log Source: The system, application or device that generates logs.
Event: A recorded activity such as login, network connection or system change.
Monitoring: Continuously observing logs for relevant or suspicious activity.
Correlation: Connecting related events from one or more sources to understand a larger activity pattern.
Investigation: Examining relevant log evidence to determine what happened.

Summary

Log Monitoring is a fundamental SOC activity that provides visibility into system, network and security events. Analysts collect and monitor logs, identify unusual activity, investigate important events and use the available evidence to determine whether further security action is required.
