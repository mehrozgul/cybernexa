Network Monitoring

What is Network Monitoring?

Network Monitoring is the process of observing network traffic, connections, devices and communication patterns to identify performance problems, unusual activity and potential security threats.

Definition

Understand the core concept of Network Monitoring.

Core Definition

Network Monitoring is the continuous observation and analysis of network devices, traffic, connections and communication patterns to maintain visibility into network activity and identify abnormal or potentially malicious behavior.

How Network Monitoring Works

Security and network teams collect information about network activity and analyze it for meaningful patterns.

Network monitoring begins by collecting information from devices and communication systems such as routers, switches, firewalls, servers and endpoints.

The collected information can include source and destination IP addresses, ports, protocols, connection attempts, traffic volume and timestamps.

Monitoring tools then help security teams identify normal traffic patterns and detect activity that may require investigation.

In a SOC environment, network monitoring provides visibility that can help analysts identify suspicious connections, unusual traffic and possible security incidents.

What Security Teams Monitor

Important network indicators provide visibility into network behavior.

IP

IP Addresses

Source and destination addresses help analysts understand where network communication originates and where it is going.

PORT

Ports

Ports indicate which network services are being accessed or communicating across the network.

NET

Protocols

Protocols such as TCP, UDP, HTTP and DNS provide information about how systems communicate.

LOG

Connections

Repeated, failed or unusual connection attempts can provide useful security indicators.

TRAFFIC

Traffic Volume

Unusual increases or decreases in traffic can indicate operational or security problems.

TIME

Activity Timing

The time and frequency of network activity can help identify behavior outside normal patterns.

Normal vs Suspicious Network Activity

Analysts compare observed activity with expected network behavior.

✓ Normal Activity

  • Expected internal communication
  • Known services and ports
  • Regular traffic patterns
  • Authorized connections
  • Expected DNS and web activity

⚠ Suspicious Activity

  • Repeated connection attempts
  • Unexpected external communication
  • Unusual ports or protocols
  • Unexpected traffic spikes
  • Communication with suspicious destinations

Simple SOC Example

Consider an endpoint communicating with an unusual external destination.

⚠ Possible Suspicious Activity

A workstation normally communicates with approved services but suddenly begins making repeated connections to an unfamiliar external IP address over an unusual port.

✓ Analyst Response

The analyst reviews the source IP, destination IP, port, protocol and connection frequency, then correlates the activity with other available logs before deciding whether further investigation is required.

Key Concepts

Important terms to remember.

Network Traffic: Data moving between systems across a network.
Source IP: The IP address initiating a network communication.
Destination IP: The IP address receiving the communication.
Port: A logical endpoint used by network services.
Protocol: Rules used by systems to communicate over a network.
Baseline: A representation of normal network behavior used for comparison.

Summary

Network Monitoring provides visibility into network communication and behavior. Security teams monitor IP addresses, ports, protocols, connections, traffic volume and activity patterns. By comparing observed activity with expected behavior, analysts can identify events that may require further investigation.
