CYBERSECURITY FUNDAMENTALS

CIA Triad

Learn the three fundamental security principles used to protect information and systems: Confidentiality, Integrity and Availability.

What is the CIA Triad?

The CIA Triad is a fundamental model in cybersecurity used to understand the three main objectives of information security.

CIA stands for Confidentiality, Integrity and Availability. These principles help organizations protect data, maintain its accuracy and make sure authorized users can access it when needed.

Three Principles of the CIA Triad

🔒

Confidentiality

Confidentiality means protecting information from unauthorized access or disclosure.

🛡️

Integrity

Integrity means keeping information accurate, complete and protected from unauthorized modification.

⚡

Availability

Availability means ensuring that authorized users can access systems and information when required.

01. Confidentiality

Confidentiality focuses on preventing unauthorized people from viewing or accessing sensitive information.

Only users or systems with the appropriate authorization should be able to access protected information.

  • Strong passwords
  • Multi-factor authentication
  • Access control
  • Encryption
  • Proper permissions
Example

A student's academic record should only be accessible to the student and authorized university staff. Unauthorized users should not be able to view it.

02. Integrity

Integrity ensures that information remains accurate, complete and trustworthy.

Data should not be changed, deleted or manipulated by unauthorized users.

  • Hashing
  • Digital signatures
  • File permissions
  • Access controls
  • Audit logs
Example

If a student's grade is stored as 85, an attacker should not be able to change it to 95 without authorization. Security controls should detect or prevent the unauthorized modification.

03. Availability

Availability means that authorized users should be able to access systems, services and information when they need them.

Security is not only about protecting data. Systems must also remain operational and accessible.

  • Backups
  • Redundant systems
  • Disaster recovery
  • System monitoring
  • Protection against denial-of-service attacks
Example

An online banking service should remain available to authorized customers. If the service becomes unavailable because of a system failure or attack, availability has been affected.

CIA Triad Comparison

Principle Main Goal Example Security Control
Confidentiality Prevent unauthorized access Encryption
Integrity Prevent unauthorized modification Hashing
Availability Keep systems accessible Backups / Redundancy

Real-World Example

Consider an online banking system. The CIA Triad can be applied as follows:

  • Confidentiality: Only the customer and authorized banking systems should access account information.
  • Integrity: Account balances and transaction records must not be modified without authorization.
  • Availability: Authorized customers should be able to use banking services when required.

Why is the CIA Triad Important?

The CIA Triad provides a simple framework for thinking about information security.

When designing or evaluating a security system, security professionals can consider whether information is protected from unauthorized access, protected from unauthorized changes and available to authorized users.

Summary

  • Confidentiality protects information from unauthorized access.
  • Integrity protects information from unauthorized modification.
  • Availability ensures authorized access when information or systems are needed.
  • Together, these three principles form the CIA Triad.
