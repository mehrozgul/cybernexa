Digital Signatures Lab

Generate a temporary cryptographic key pair, sign a message and verify the digital signature directly in your browser.

Difficulty Beginner
Type Cryptography
Objective Sign & Verify Data

Lab Objective

In this lab, you will understand the basic workflow of a digital signature by performing the process directly inside your browser.

  • Generate a public/private key pair.
  • Create a digital signature for a message.
  • Verify the signature using the public key.
  • Understand how modification affects verification.

Scenario

Secure Document Exchange

Alice wants to send a digitally signed message to Bob. Alice uses her private key to sign the message. Bob uses Alice's public key to verify that the signature corresponds to the message.

Lab Workflow

  • Click Generate Keys to create a temporary public/private key pair.
  • Enter or keep the sample message.
  • Click Sign Message to generate a digital signature.
  • Click Verify Signature to verify the original message.
  • Click Modify Message and verify again to observe how changing the message can cause verification to fail.

Knowledge Check

1. Which key is normally used to create a digital signature?
2. Which key is normally used to verify a digital signature?
3. What security property can digital signatures help provide?
4. What happens if signed data is changed?
5. What is the main purpose of signature verification?

Lab Result

Complete the Digital Signatures Lab

You have practiced the basic digital-signature workflow: key generation, signing and verification. Remember that a digital signature is primarily used to support authenticity and integrity rather than confidentiality.
