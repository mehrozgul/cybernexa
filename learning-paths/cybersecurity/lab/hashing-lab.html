PRACTICAL LAB

Hashing Lab

Practice the core concepts of cryptographic hashing, password hashing, integrity verification and the difference between hashing and encryption.

Difficulty Beginner
Type Security Analysis
Objective Understand Hashing

🎯 Lab Objective

In this lab, you will review how hashing works and identify appropriate uses of cryptographic hashes.

  • Understand the purpose of a hash function.
  • Identify important hashing properties.
  • Understand hashing for integrity verification.
  • Understand the role of salt in password hashing.
  • Distinguish hashing from encryption.

🧩 Scenario

SecureFile System

SecureFile publishes software downloads together with SHA-256 hashes. The security team also stores user passwords using a password-specific hashing system with unique salts. Your task is to identify the correct security concepts used in this scenario.

🧪 Knowledge Check

1. What is the primary output of a cryptographic hash function?
2. Which property means the same input produces the same hash?
3. What happens when a small change is made to the input of a secure cryptographic hash function?
4. Why is a unique salt used with password hashing?
5. Which algorithm is widely used today for producing a 256-bit cryptographic digest?
6. Which statement correctly describes hashing compared with encryption?
7. Which is an appropriate use of SHA-256?

Lab Result

✅ Complete the Hashing Lab

After completing the knowledge check, review the difference between hashing and encryption and remember that password storage requires password-specific hashing techniques rather than simple fast hashes.
