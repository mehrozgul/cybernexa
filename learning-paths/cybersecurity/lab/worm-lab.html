PRACTICAL LAB

Worm Lab

Identify the characteristics of computer worms, understand how they spread between systems and recognize basic defensive measures.

Difficulty Beginner
Type Malware Analysis
Objective Understand Worm Behavior

Lab Objective

In this lab, you will analyze a simple worm scenario and identify the characteristics that make worms different from other types of malware.

  • Understand what a computer worm is.
  • Identify how worms can spread between systems.
  • Understand the difference between a worm and a virus.
  • Recognize common defensive measures against worms.

Scenario

SecureNet Organization

SecureNet has several computers connected to the same network. One computer becomes infected with a malicious program that can independently search for vulnerable systems and attempt to spread to other computers without requiring the user to manually execute it on every target.

Knowledge Check

1. What is a computer worm?
2. What is a major characteristic of a worm?
3. How is a worm different from a traditional virus?
4. Which factor can help prevent worm propagation?
5. Which network control can help limit worm propagation?

Lab Result

Complete the Worm Lab

After completing the knowledge check, review how worms can propagate between vulnerable systems and remember that patching, network segmentation, access control and security monitoring can help limit their spread.
