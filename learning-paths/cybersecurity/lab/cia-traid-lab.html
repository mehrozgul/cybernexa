CIA Triad Lab

Identify confidentiality, integrity and availability problems in realistic cybersecurity scenarios.

Difficulty Beginner
Topic CIA Triad
Objective Identify Security Principles

Lab Objective

In this lab, you will analyze different cybersecurity situations and determine whether the situation mainly affects Confidentiality, Integrity or Availability.

Remember:

Confidentiality = unauthorized access or disclosure. Integrity = unauthorized modification or loss of accuracy. Availability = loss of access to a required system or resource.

CIA Triad Challenge

Q1. An attacker obtains a user's password and reads private emails without permission. Which CIA principle is affected?
Q2. An attacker changes a company's database records without authorization. Which principle is mainly affected?
Q3. A website becomes unavailable because of a denial-of-service attack. Which principle is affected?
Q4. A confidential company document is leaked to an unauthorized person. Which principle is affected?
Q5. A backup server is used so that services can continue operating if the main server fails. Which principle does this support?
Q6. A file's contents are modified by an unauthorized attacker. Which principle has been violated?
Q7. A hospital system is protected so that only authorized doctors and staff can view patient records. Which principle is being protected?
Q8. A system uses hashing to detect whether a file has been changed. Which CIA principle does this mainly support?

Lab Result

How to Complete This Lab

  1. Read each cybersecurity scenario carefully.
  2. Identify whether the problem involves unauthorized access, unauthorized modification or loss of access.
  3. Select Confidentiality, Integrity or Availability.
  4. Click Check Answers.
  5. Review your score and understand the incorrect answers.

CIA Triad Lab Complete

Once you understand these three principles, you have the foundation required for the upcoming cybersecurity topics.
