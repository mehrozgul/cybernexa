Log Investigation Lab

Analyze authentication logs, identify suspicious login activity and use timestamps, usernames and IP addresses to investigate a potential security event.

LOG ANALYSIS LAB ● ACTIVE
Lab Type Log Investigation
Data Authentication Logs
Difficulty Beginner
Objective Find Suspicious Activity

Lab Objective

Understand how analysts investigate authentication logs.

Mission

You are investigating a possible account compromise. Review the authentication logs below and identify suspicious activity by examining failed attempts, successful logins, usernames, timestamps and source IP addresses.

Investigation Steps

Follow these steps to investigate the sample log data.

STEP 01

Review the Logs

Read the recorded authentication events and identify the users, timestamps and source IPs.

STEP 02

Look for Anomalies

Look for repeated failed login attempts, unusual IP addresses and unexpected successful logins.

STEP 03

Build the Timeline

Compare the timestamps to understand the order of suspicious events.

Investigation Result

Use the evidence in the logs to determine what happened.

Analyst Observation

The logs show three consecutive failed login attempts against the admin account from the same external IP address.

A successful login occurs shortly after the failed attempts from the same source address.

A privilege change is then recorded for the same administrator account.

This sequence should be treated as suspicious and requires further investigation.

Investigation Questions

Answer these questions after reviewing the logs.

Question 01 Which username shows the suspicious login activity?
Question 02 Which source IP address appears repeatedly?
Question 03 How many failed login attempts occurred before the successful login?
Question 04 What event occurred after the successful login?

Lab Completion

You have completed the Log Investigation exercise when you can identify suspicious authentication activity, correlate related log events and explain why the event requires further investigation.
