Incident Triage Lab

Analyze a simulated security alert, review the available evidence, evaluate the potential impact and assign an appropriate incident priority.

Lab Objective

Your task is to perform basic incident triage using the information provided by the security monitoring system.

Incoming Security Alert

The SOC monitoring system has generated an alert for a user account named admin01.

The account experienced several failed login attempts within a short period followed by a successful login.

The successful login originated from an unusual external IP address that has not previously been associated with the account.

Available Evidence

Review the information before assigning a priority.

Account admin01
Failed Attempts 17 attempts
Successful Login 1 successful login
Source Unusual external IP
Device Previously unknown
System Administrative account

Assign Incident Priority

Based on the evidence, select the priority level that best represents the urgency of this incident.

What priority should this incident receive?
High Priority Potential compromise of an administrative account. Requires rapid investigation.
Medium Priority Suspicious activity exists, but there is not enough evidence of serious impact.
Low Priority Limited suspicious activity with low potential impact.

Analyst Assessment

Use the evidence to determine what the analyst should consider during triage.

Triage Finding

The combination of repeated failed login attempts, a successful login, an unusual source IP and a previously unknown device increases the likelihood that the account may have been compromised.

Recommended Action

The incident should be escalated for further investigation. The security team should review authentication logs, account activity and related systems and apply appropriate containment if compromise is confirmed.

Lab Result

Priority: High Priority

Reason: The alert involves an administrative account and contains multiple indicators of potentially unauthorized access. The available evidence justifies rapid investigation and possible escalation.

Remember: triage establishes priority from available evidence. It does not by itself prove that an account has been compromised.
