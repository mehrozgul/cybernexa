Incident Scenario

Start by analyzing the security event below.

Suspicious Account Activity Detected

Potential Security Incident

The security monitoring system has detected several failed login attempts against an employee account. Shortly after the failed attempts, a successful login was recorded from an unusual geographic location.

security-monitor.log
[09:14:21] Failed login: employee01
[09:14:25] Failed login: employee01
[09:14:31] Failed login: employee01
[09:15:04] Successful login: employee01
[09:15:05] Source: 185.XX.XX.42
[09:15:05] Location: Unusual Geographic Region
[09:15:08] Alert: Suspicious Authentication Activity

Task 01 — Identify the Incident

Determine what type of security event is represented by the available evidence.

TASK 01

Review the authentication activity

Select the observations that indicate suspicious activity. A proper Incident Response investigation begins with identifying relevant evidence.

Task 02 — Perform Triage

Triage means evaluating and prioritizing the incident.

TASK 02

Determine the initial priority

Based on the evidence, choose the most appropriate initial response priority.

Low Priority Minor event with no suspicious indicators.
Medium Priority Suspicious authentication activity requiring investigation.
High Priority Confirmed severe compromise with major organizational impact.
No Incident The login activity is completely normal.

Task 03 — Containment

Select appropriate actions to limit the potential impact of the suspicious account activity.
