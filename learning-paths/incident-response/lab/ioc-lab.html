IOC Analysis Lab

In this practical lab, you will examine simulated security evidence, identify Indicators of Compromise, classify different IOC types and determine which indicators require further investigation.

Lab Objective

Understand how a security analyst identifies and analyzes Indicators of Compromise from incident evidence.

Your Mission

Review the simulated incident evidence below. Identify suspicious indicators, determine their IOC types and explain why they may require investigation.

Incident Evidence

A workstation has generated several unusual security events.

Security Alert

Security monitoring detected an unusual outbound connection from workstation WS-07.

[ALERT] Host: WS-07 Time: 14:32:18 Process: powershell.exe Destination: 203.0.113.25 Port: 443 Status: Connection Allowed

Additional Evidence

Endpoint monitoring also detected a newly created executable and communication with an unfamiliar domain.

[ENDPOINT] File: C:\Temp\update.exe SHA256: a84f91c2...92cd [DNS] Domain: suspicious-example.com [EMAIL] Sender: attacker@example.net

Identify the IOCs

The following table contains the indicators found in the simulated incident.

Indicator Type Evidence Source Why Investigate?
203.0.113.25 IP ADDRESS Network Alert Unusual outbound communication.
suspicious-example.com DOMAIN DNS Log Unfamiliar external domain.
a84f91c2...92cd FILE HASH Endpoint Identifies the suspicious executable.
attacker@example.net EMAIL Email Security Suspicious sender identity.
C:\Temp\update.exe FILE PATH Endpoint Newly created executable.
powershell.exe PROCESS Endpoint Requires context and investigation.

Analyst Tasks

Select the statements that correctly describe the investigation process.

Investigation Result

Review the expected analyst approach after completing the investigation.

Expected Analysis

The indicators should be treated as evidence requiring investigation rather than automatic proof of compromise. Analysts should correlate each indicator with additional security information before determining its significance.

  • 203.0.113.25 → suspicious IP indicator
  • suspicious-example.com → suspicious domain indicator
  • a84f91c2...92cd → file hash indicator
  • attacker@example.net → email indicator
  • C:\Temp\update.exe → suspicious file path
  • powershell.exe → process requiring contextual investigation
