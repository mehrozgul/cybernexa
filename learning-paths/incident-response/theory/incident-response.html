Learn Incident Response

Follow the topics below in order to build a clear understanding of Incident Response.

Incident Response is an organized approach used by security teams to handle cybersecurity incidents.

In this learning path, you will learn how an incident is detected, evaluated, contained, removed and recovered from.

Each topic contains a dedicated theory page and a practical lab so you can understand the concept and then apply it.
