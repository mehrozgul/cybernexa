01

What is Disk Forensics?

Core Definition

Disk forensics is the process of examining data stored on digital storage media such as hard drives, SSDs, USB drives and forensic disk images. Investigators analyze file systems, files, metadata, deleted information and other artifacts to understand what happened on a device.

02

Why Disk Forensics Matters

A storage device can contain much more information than the files visible to a normal user. File-system structures, timestamps, deleted records, logs and application artifacts may provide important evidence during an investigation.

File Analysis

Examine files and directories to identify relevant information.

Deleted Data

Investigate remnants of files that are no longer visible through normal file browsing.

File System Analysis

Examine structures such as NTFS, FAT and ext-based file systems.

Timeline Analysis

Use timestamps and other artifacts to understand the sequence of activity.

03

Disk Images

Investigators commonly work with a forensic image instead of repeatedly analyzing the original storage device. A disk image is a forensic copy representing the data from a storage medium.

Physical Image

Represents data from the storage medium at a low level, including allocated and potentially unallocated areas.

Logical Image

Contains selected files or logical portions of a storage system rather than the complete physical medium.

Evidence Copy

Investigators preserve an original source and perform analysis on appropriate forensic copies.

Hash Verification

Cryptographic hashes can be used to verify that evidence has not changed during handling.

05

File Systems

A file system organizes data on a storage device. Understanding the file system helps investigators interpret directories, timestamps, allocation information and other storage artifacts.

NTFS

Commonly used by modern Windows systems and contains important forensic metadata.

FAT / FAT32

Older and widely supported file systems that may still appear on removable media.

ext4

A commonly encountered Linux file system with its own metadata and storage structures.

Partitions

Storage devices may contain multiple partitions, each potentially containing a different file system.

06

Deleted Files

Deleting a file does not necessarily mean that every trace of its data immediately disappears. Depending on the storage medium, file system and subsequent activity, remnants may remain available for forensic analysis.

⚠ Important Forensic Principle

Deleted-data recovery is not guaranteed. Overwritten data, storage technology, encryption and other factors can affect what information remains recoverable.

07

Important Disk Artifacts

File Timestamps

Timestamps can help investigators understand when files were created, modified or accessed.

Directory Structure

Directory organization can provide context about files and user activity.

Recycle Bin

Deleted Windows files may leave artifacts associated with the Recycle Bin.

Unallocated Space

Areas not currently assigned to active files may contain remnants of previously stored information.

08

Hashing in Disk Forensics

Hash functions generate a fixed-length value from digital data. Investigators can use hashes to help verify the integrity of evidence and identify known files.

MD5

Historically common for forensic identification and integrity workflows, although not collision-resistant.

SHA-1

Older hashing algorithm that has known collision weaknesses.

SHA-256

A modern cryptographic hash commonly used for stronger integrity verification.

Hash Comparison

Matching hashes can provide evidence that the compared data has remained unchanged.

09

Professional Investigation Example

Imagine an organization investigating suspicious activity on a workstation. Investigators preserve the source, create an appropriate forensic image, verify its integrity and analyze the image for relevant files, timestamps and other artifacts.

The investigator then correlates the discovered artifacts with other evidence and documents the results in a structured forensic report.

Module Summary

Preserve the Evidence. Analyze the Disk. Explain the Timeline.

Disk forensics focuses on extracting and interpreting digital evidence from storage media. A reliable investigation depends on proper acquisition, preservation, verification, analysis and documentation.
