Simulated Network Evidence
Review the following evidence and identify the observation that is best supported by the available data.
Time Source IP Destination IP Port Protocol
10:15:02 192.168.1.20 192.168.1.1 53 DNS
10:15:05 192.168.1.20 192.168.1.50 443 HTTPS
10:16:12 192.168.1.20 192.168.1.80 22 SSH
Practical Evidence Analysis
Based only on the evidence above, select the observation that is most appropriate for a forensic analyst.
A. The system definitely suffered a compromise. This conclusion requires additional evidence and cannot be established from these three records alone.
B. The host communicated with DNS, HTTPS and SSH services. These observations are directly supported by the destination ports and protocol fields.
C. The SSH connection proves an attacker was present. A connection to SSH alone does not establish malicious activity or identify an attacker.
D. The destination system is confirmed compromised. The evidence only shows communication, not successful compromise.
