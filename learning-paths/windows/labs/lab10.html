Lab Objective

Objective In this lab, you will inspect basic Windows security features and learn how to check security status, Windows Defender, firewall configuration, UAC and Windows update status.
01

Open Windows Security

1 Open Windows Security

Click the Windows Start menu and search for Windows Security.

Open the Windows Security application.

Expected Result The Windows Security dashboard should open and display the available security areas.
02

Check Virus & Threat Protection

2 Open Virus & Threat Protection

In Windows Security, select Virus & threat protection.

Review the displayed protection status and available scan options.

Observe Check whether real-time protection and other available protection features are enabled.
03

Check Firewall & Network Protection

3 Open Firewall Settings

Select Firewall & network protection in Windows Security.

Review the available network profiles such as Domain, Private and Public, depending on the Windows configuration.

Expected Result You should be able to view the firewall status and network protection options.
04

Check Firewall Using PowerShell

4 Open PowerShell

Open PowerShell. Depending on the Windows configuration, administrator privileges may be required for some commands.

PowerShell Get-NetFirewallProfile
What This Does The command displays firewall profile configuration information.
05

Check Windows Defender Status

5 Run Defender Status Command

Open PowerShell and run the following command:

PowerShell Get-MpComputerStatus
What to Observe Review the displayed Microsoft Defender status information available on your system.
06

Check Windows Update

6 Open Windows Update

Open:

Windows Settings Settings → Windows Update

Review whether updates are available for your system.

07

Check UAC Configuration

7 Open User Account Control Settings

Search Windows for:

Windows Search User Account Control

Open Change User Account Control settings and review the current notification level.

08

Check Security Events

8 Open Event Viewer

Press:

Run Windows Key + R
eventvwr.msc

Navigate to:

Event Viewer Windows Logs → Security
What to Observe Review the security events available on your system. Do not delete or modify logs during this learning exercise.
✓

Lab Completion Checklist

  • Opened Windows Security.
  • Reviewed Virus & Threat Protection.
  • Reviewed Firewall & Network Protection.
  • Checked firewall profile information.
  • Checked Microsoft Defender status.
  • Reviewed Windows Update.
  • Reviewed UAC configuration.
  • Opened Windows Security logs in Event Viewer.

Lab Safety
