Windows Event Viewer Lab 08

In this lab, you will open Windows Event Viewer, explore Windows logs, inspect event details, filter events and perform a basic security-log investigation.

Lab Objective

The objective of this lab is to understand how Windows Event Viewer works and how event logs can be inspected for troubleshooting and basic cybersecurity analysis.

Expected Outcome After completing this lab, you should be able to open Event Viewer, identify major Windows logs, inspect events, understand Event IDs and perform basic filtering.
✓

Requirements

Windows PC

A Windows system with Event Viewer available.

Administrator Access

Some logs or actions may require appropriate permissions.

01

Open Event Viewer

Start by opening the Windows Event Viewer.

  1. Press Win + R on your keyboard.
  2. Type eventvwr.msc.
  3. Press Enter.
  4. Wait for the Event Viewer window to open.
Run Command eventvwr.msc
02

Explore Windows Logs

In the left navigation panel, locate:

Event Viewer Windows Logs
  1. Expand Windows Logs.
  2. Locate Application.
  3. Locate Security.
  4. Locate System.
  5. Locate Setup, if available.
03

Open the Security Log

The Security log is particularly useful for cybersecurity learning because it contains security auditing events when auditing is configured.

  1. Select Windows Logs.
  2. Click Security.
  3. Wait for the event list to load.
  4. Select one event from the list.
Observe

Look at the event columns such as Level, Date and Time, Source and Event ID.

04

Inspect an Event

Select an event and inspect its information.

  1. Double-click an event.
  2. Read the General tab.
  3. Check the Event ID.
  4. Check the Source.
  5. Check the event date and time.
  6. Open the Details tab and inspect the available information.
05

Filter Events

Filtering helps reduce a large number of events and focus on events relevant to your investigation.

  1. Right-click the selected log.
  2. Select Filter Current Log....
  3. Review the available filtering options.
  4. Select an appropriate event level or time range.
  5. Apply the filter.
Important

Filtering changes what is displayed; it does not delete the original events from the log.

06

Identify Event Information

Select an event and record the following information.

Event ID

Record the numeric Event ID shown by the event.

Level

Record whether the event is Information, Warning, Error or Critical.

Source

Identify the component or provider that generated the event.

Date & Time

Record when the event occurred.

🔎

Basic Security Investigation

Now perform a basic investigation using the Security log. Look for authentication-related events that are present on your own Windows system.

  1. Open Windows Logs → Security.
  2. Use Filter Current Log....
  3. Review events related to account or logon activity.
  4. Open an event that interests you.
  5. Record its Event ID, time, level and description.
  6. Read the General and Details tabs.
Security Principle Do not assume that one event alone proves malicious activity. Event logs should be analyzed together with other evidence and the context of the system.
📝

Record Your Findings

Create a small record of the event you investigated.

Event ID

Write the Event ID observed on your system.

Event Level

Write the level of the event.

Source

Write the event source.

Finding

Write a short explanation of what the event represents.

  • Opened the Security log.
  • Inspected an event.
  • Identified Event ID and Event Level.
  • Checked event source and timestamp.
  • Used event filtering.
  • Performed a basic security-log investigation.
  • Recorded investigation findings.
