Windows Logs Lab 12

Practice opening Event Viewer, identifying Windows logs, inspecting event information and querying logs through PowerShell.

Beginner
Practical
Event Viewer
PowerShell
🎯

Lab Objective

In this lab you will learn how to access Windows Event Viewer, inspect different Windows logs, identify event details and use PowerShell to retrieve recent events.

Expected Outcome By the end of this lab, you should be able to locate Windows logs and understand the basic information contained inside a Windows event.
1

Open Event Viewer

1
Open Run Press Windows + R on your keyboard.
2
Enter Event Viewer Command Type the following command and press Enter.
Run eventvwr.msc
2

Open Windows Logs

1
Locate Windows Logs In Event Viewer, expand the "Windows Logs" section from the left-side navigation.
2
Inspect Available Logs You should see logs such as Application, Security, Setup, System and Forwarded Events, depending on the Windows configuration.
3

Inspect System Log

Select the System log and inspect the list of events.

1
Select System Open Windows Logs → System.
2
Select an Event Click any available event and inspect its details.
Observe Look for the Event ID, Level, Source, Date and Time, and the event description.
4

Inspect Application Log

Open Windows Logs → Application and select an event.

Goal Understand that application-related events can be recorded separately from system events.
5

Query Logs with PowerShell

Open PowerShell and retrieve the most recent System events.

PowerShell Get-EventLog -LogName System -Newest 10
Expected Result PowerShell should display recent System events with information such as Index, Time, EntryType, Source and InstanceId.
6

List Available Event Logs

Use PowerShell to display available classic Windows event logs.

PowerShell Get-EventLog -List
7

Retrieve Application Events

PowerShell Get-EventLog -LogName Application -Newest 10
Observe Compare the output with the System log and notice that the source and event information can differ.
🔐

Security Log Observation

If you have appropriate permissions, open:

Event Viewer Windows Logs → Security

Inspect the available events without modifying or deleting any logs.

Security Focus Security logs can contain auditing information related to authentication and other security activity when auditing is configured.
🔎

Basic Event Analysis

Select one event and identify the following information:

  • Event ID
  • Event Level
  • Event Source
  • Date and Time
  • Event Description

Lab Tasks

  • Open Event Viewer using eventvwr.msc.
  • Locate Windows Logs.
  • Open the System log.
  • Inspect one System event.
  • Open the Application log.
  • Inspect one Application event.
  • Open PowerShell.
  • Run Get-EventLog -List.
  • Run the System log command.
  • Identify Event ID, Level, Source and Time.
✓

Lab Completion

Completion Checklist You have successfully completed the Windows Logs lab when you can open Event Viewer, locate Windows Logs, inspect an event and retrieve recent events using PowerShell.
