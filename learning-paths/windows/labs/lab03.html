Command Prompt (CMD) Lab 03

Practice essential Windows Command Prompt commands for user identification, directory navigation, file management, system information and basic network troubleshooting.

Beginner
Windows
CMD

Lab Objective

Goal Learn and practice basic CMD commands used to identify the current user, navigate directories, create folders, display files, inspect system information and test network connectivity.
01

Open Command Prompt

1

Launch CMD

Press the Windows key, type cmd, and open Command Prompt.

Windows cmd
02

Identify the Current User

2

Use whoami

The whoami command displays the account currently being used.

CMD whoami
Example Output cybernexa\student
03

View Directory Contents

3

Use dir

The dir command lists files and folders in the current directory.

CMD dir
Expected Result A list of files and directories will be displayed.
04

Navigate Directories

4

Use cd

The cd command changes the current working directory.

CMD cd Desktop
cd ..
Meaning cd Desktop → Move into Desktop cd .. → Move one level back
05

Create a Directory

5

Use mkdir

The mkdir command creates a new directory.

CMD mkdir CyberNexa
Verify dir
06

Display System Information

6

Use systeminfo

The systeminfo command displays detailed information about the Windows operating system and computer.

CMD systeminfo
Information Includes OS information Computer information System configuration details
07

Check Network Configuration

7

Use ipconfig

The ipconfig command displays basic IP configuration information.

CMD ipconfig
Look For IPv4 Address Subnet Mask Default Gateway
08

Test Network Connectivity

8

Use ping

The ping command can be used to test whether a destination responds over the network.

CMD ping 127.0.0.1
Expected Result Reply from 127.0.0.1

The address 127.0.0.1 refers to the local computer.

09

View Running Processes

9

Use tasklist

The tasklist command displays currently running processes.

CMD tasklist
Expected Result A list of running processes will be displayed.
C

CMD Command Reference

whoami

Displays the current user account.

dir

Lists files and directories.

cd

Changes the current directory.

mkdir

Creates a new directory.

cls

Clears the CMD screen.

ipconfig

Displays IP configuration.

ping

Tests network connectivity.

tasklist

Displays running processes.

systeminfo

Displays system information.

hostname

Displays the computer hostname.

Why CMD Matters in Cybersecurity

Command-line knowledge is useful in cybersecurity because security analysts often need to inspect users, network configuration, processes and system information quickly.

whoami

Helps identify the current user context.

ipconfig

Helps inspect network configuration.

tasklist

Helps inspect running processes.

systeminfo

Helps collect system information.

Lab Safety: Perform practical activities only on your own Windows system or an authorized lab environment. These commands are basic system-administration and information-gathering commands.
