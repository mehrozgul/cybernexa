Windows Services Lab 06

Practice identifying, inspecting and managing Windows Services using the Services console, Command Prompt and PowerShell.

Lab Objectives

By completing this lab, you will practice the basic Windows Services concepts covered in the theory section.

Objective 01 Open the Windows Services management console.
Objective 02 Identify service names and current states.
Objective 03 Query services using Command Prompt.
Objective 04 Inspect services using PowerShell.
01

Open Services Console

1

Press: Windows + R to open the Run dialog.

2

Enter the following command:

Run services.msc
3

Press Enter. The Windows Services management console should open.

02

Inspect a Service

In the Services window, select a service such as Windows Update if it is available.

1

Right-click the selected service.

2

Select Properties.

3

Observe the service name, description, current status and startup type.

Important: Do not change or disable system services during this beginner lab unless you understand the effect and are working in a safe test environment.
CMD

Query Services with CMD

Open Command Prompt and run the following command:

Command Prompt sc query

This command displays information about Windows Services.

1

Open Command Prompt.

2

Run sc query.

3

Observe the service names and their states.

CMD

Query a Specific Service

Use the following command to inspect the Windows Update service:

Command Prompt sc query wuauserv

Observe the service state in the command output.

PS

Inspect Services with PowerShell

Open PowerShell and use the following command:

PowerShell Get-Service

This command displays the services available on the Windows system.

PS

Inspect a Specific Service

Run:

PowerShell Get-Service wuauserv

Identify the service name and current status.

Expected learning: You should be able to distinguish between a service that is currently running and one that is stopped.
🔎

Filter Running Services

PowerShell can also be used to display services according to their status.

PowerShell Get-Service | Where-Object {$_.Status -eq "Running"}

The command filters the service list and displays services whose status is Running.

🔐

Security Observation

From a cybersecurity perspective, understanding services helps an analyst determine what background functionality is active on a Windows system.

  • Identify services that are currently running.
  • Check whether the service is required.
  • Observe the service startup configuration.
  • Understand which services provide networking or system functionality.
  • Investigate unexpected service changes in an authorized security environment.
🧪

Final Lab Task

Complete the following tasks on your Windows machine:

  • Open services.msc.
  • Find Windows Update.
  • Record its current status.
  • Record its startup type.
  • Run sc query from Command Prompt.
  • Run Get-Service from PowerShell.
  • Run Get-Service wuauserv.
  • Identify at least three running services.
