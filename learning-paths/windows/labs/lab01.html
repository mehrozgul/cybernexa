Windows Basics Lab 01

Practice the basic Windows system concepts using built-in tools, system information, user accounts and command-line utilities.

🎯

Lab Objective

What You Will Learn In this lab, you will identify basic Windows system information, explore the Windows interface and use basic CMD commands to inspect the system.
💻

Lab Requirements

Windows 10 / 11
Computer / Laptop

Lab Tasks

Check Windows Version

Identify the Windows version installed on your computer.

Display the basic network configuration of the computer.

1

Step 1 — Open Command Prompt

  1. Press Windows + R.
  2. Type cmd.
  3. Press Enter.
  4. Command Prompt will open.
2

Step 2 — Check Windows Version

Use the following command to display the Windows version information.

winver
Expected Result A Windows About dialog will appear showing the Windows version and build information.
3

Step 3 — Check System Information

Use the systeminfo command to display detailed system information.

systeminfo
Expected Result Host Name
OS Name
OS Version
System Manufacturer
System Model
System Type
4

Step 4 — Check Current User

Use the whoami command to identify the account currently running the command prompt.

whoami
Expected Result COMPUTER-NAME\username
5

Step 5 — Check Network Configuration

Use the ipconfig command to view the computer's basic IP configuration.

ipconfig
Expected Result IPv4 Address
Subnet Mask
Default Gateway
$

Basic Windows Commands

winver

Opens Windows version information.

systeminfo

Displays detailed system information.

whoami

Displays the current user.

ipconfig

Displays basic network configuration.

hostname

Displays the computer hostname.

cls

Clears the Command Prompt screen.

🔐

Cybersecurity Connection

Basic Windows commands are useful in cybersecurity because security analysts often need to identify the operating system, current user, host information and network configuration during system analysis.
