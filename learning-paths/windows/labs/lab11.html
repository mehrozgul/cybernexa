Active Directory Basics Lab 11

Practice basic Active Directory concepts in an authorized Windows Server virtual lab environment. This lab focuses on understanding the domain, organizational units, users and groups.

Beginner
Practical
Windows Server
AD DS
🎯

Lab Objective

The objective of this lab is to understand the basic workflow of Active Directory Domain Services and practice creating an Organizational Unit, user and security group in an authorized Windows Server lab environment.

⚠

Lab Requirements

Windows Server

A Windows Server virtual machine with Active Directory Domain Services available.

Administrator Access

Use an administrator account inside your own authorized lab environment.

Server Manager

Server Manager can be used to install and manage the AD DS role.

Virtual Lab

A local VirtualBox or VMware environment is recommended for safe practice.

01

Check the Server

First identify the Windows Server system and verify that you are working inside your authorized lab.

PowerShell hostname
whoami
ipconfig
Expected Result

The commands should display the server hostname, current user and network configuration.

02

Verify Active Directory Tools

Open Server Manager and check whether the Active Directory Users and Computers console is available.

  1. Open Server Manager.
  2. Open Tools.
  3. Look for Active Directory Users and Computers.
  4. Open the console.
03

Explore the Domain

In Active Directory Users and Computers, locate your lab domain and inspect its available containers.

Domain
Users
Computers
Builtin
04

Create an Organizational Unit

Create an Organizational Unit for the lab users.

  1. Right-click your domain.
  2. Select New → Organizational Unit.
  3. Enter the name: CyberNexa-Users
  4. Confirm the creation.
Expected Result

A new OU named CyberNexa-Users should appear inside the domain.

05

Create a Test User

Create a dedicated test account for the lab. Do not use real credentials or another person's account.

  1. Open the CyberNexa-Users OU.
  2. Right-click the OU.
  3. Select New → User.
  4. Use a test name such as: CyberNexa Test User
  5. Complete the wizard using a lab-only password.
06

Create a Security Group

Create a security group that can later be used for access-control exercises.

  1. Right-click the CyberNexa-Users OU.
  2. Select New → Group.
  3. Name the group: CyberNexa-Students
  4. Select the appropriate security-group option.
  5. Create the group.
07

Add the Test User to the Group

Add the test user to the CyberNexa-Students security group.

  1. Open the CyberNexa-Students group properties.
  2. Open the Members section.
  3. Add the CyberNexa test user.
  4. Confirm the membership.
PowerShell Get-ADGroupMember -Identity "CyberNexa-Students"
08

Verify the User

Use PowerShell to verify that the test account exists in Active Directory.

PowerShell Get-ADUser -Identity "CyberNexaTestUser"
Expected Result

PowerShell should return information about the test user if the account exists.

What You Learned

  • What Active Directory is.
  • What a Domain Controller does.
  • How domains organize identities and computers.
  • What Organizational Units are.
  • How user accounts are represented in Active Directory.
  • How security groups organize users.
  • How group membership can be verified.
  • Why Active Directory is important for Windows security.
