Task Manager Lab 07

Practice using Windows Task Manager to inspect running processes, system performance, startup applications and user sessions.

Beginner

Windows

Lab Objective

Goal In this lab, you will learn how to open Task Manager, inspect running processes, observe resource usage, review startup applications and identify active users.
01

Step 1 — Open Task Manager

Use the direct keyboard shortcut to open Task Manager.

Keyboard Shortcut Ctrl + Shift + Esc
  • Press Ctrl + Shift + Esc.
  • Task Manager should open.
  • If the simplified view appears, select "More details".
02

Step 2 — Explore Processes

Open the Processes section and observe the applications and processes currently running on your computer.

  • Open the Processes tab.
  • Locate the Apps section.
  • Observe background processes.
  • Observe CPU and Memory columns.
  • Identify a process that is currently using system resources.
03

Step 3 — Check Performance

Open the Performance section and observe the current utilization of your system.

CPU

Record the approximate CPU utilization shown on your system.

Memory

Observe how much memory is currently being used.

Disk

Observe the current disk activity.

Network

Observe current network activity.

04

Step 4 — Review Startup Apps

Open Startup Apps and inspect the applications configured to launch when Windows starts.

  • Open the Startup Apps section.
  • Identify applications marked as Enabled.
  • Observe the Startup Impact column where available.
  • Note any unfamiliar application.
  • Do not disable an application unless you understand its purpose.
05

Step 5 — Check Users

Open the Users section and observe the accounts currently signed in to the system.

  • Open the Users section.
  • Identify the currently signed-in account.
  • Observe resource usage associated with the account.
06

Step 6 — Explore Details

The Details section provides more detailed information about individual processes.

  • Open the Details section.
  • Locate the process name.
  • Find its Process ID (PID).
  • Observe its status and user name.
  • Compare CPU and memory usage with the Processes section.
07

Step 7 — Explore Services

Task Manager provides access to Windows service information.

PowerShell Get-Service
  • Open PowerShell.
  • Run the command shown above.
  • Observe the service names and statuses.
🔐

Security Observation

Task Manager can provide useful visibility during basic Windows security investigation. During this exercise, look for information that may require further investigation rather than immediately assuming that an unfamiliar item is malicious.

Processes

Look for unusually high resource usage or unfamiliar process names.

Startup

Look for unfamiliar applications configured to start automatically.

Users

Check which accounts currently have active sessions.

Services

Observe service names and their current status.
