Windows File System Lab 02

Practice Windows file-system navigation, directory creation, file creation, file inspection and basic file management using Command Prompt.

Lab Objective

In this lab, you will learn how to navigate the Windows file system, create directories, create files, view directory contents and verify file locations using CMD.

Lab Requirements

Operating System

A Windows computer with Command Prompt available.

Privileges

A normal user account is sufficient for the operations in this lab.

01

Step 1 — Open Command Prompt

1

Start CMD

Press Windows + R, type cmd and press Enter.

02

Step 2 — Check Current Location

Use the cd command to display the current directory.

CMD cd C:\Users\Student

The displayed path represents your current working directory.

03

Step 3 — View Directory Contents

Use dir to view files and folders inside the current directory.

CMD dir
04

Step 4 — Create Lab Directory

Create a dedicated folder for this practical exercise.

CMD mkdir CyberNexa-Lab02

The command creates a new directory named CyberNexa-Lab02.

05

Step 5 — Enter the Directory

CMD cd CyberNexa-Lab02

You are now working inside the newly created directory.

06

Step 6 — Create a Text File

Create a simple text file using the following command.

CMD echo CyberNexa Windows Lab > notes.txt

This creates notes.txt inside the current directory.

07

Step 7 — Verify the File

Use dir again to verify that the file was created.

CMD dir

You should see notes.txt in the directory listing.

08

Step 8 — Display File Contents

Use the type command to display the contents of the text file.

CMD type notes.txt

The text stored inside the file should appear in the Command Prompt.

09

Step 9 — Create Another Folder

CMD mkdir Evidence
dir

The Evidence folder will now appear in the current directory.

10

Step 10 — Move the File

Move the text file into the Evidence directory.

CMD move notes.txt Evidence

The file should now be located inside the Evidence folder.

11

Step 11 — Verify the Final Structure

CMD dir
cd Evidence
dir

The final structure should contain the Evidence directory and notes.txt inside it.
