Windows Users & Groups Lab 05

Practice identifying Windows users and groups, inspecting account information and understanding group membership using CMD and PowerShell.

Beginner
Windows
CMD
PowerShell
Identity Security
🎯

Lab Objective

Goal In this lab, you will learn how to identify the current Windows user, list local users, inspect local groups and check group membership using built-in Windows commands.
01

Identify the Current User

1 Open Command Prompt

Press: Windows + R and type:

Run cmd
2 Run whoami
CMD whoami
Expected Result

Windows displays the currently authenticated user in computer\username format.

02

List Local Users

1 Run the following command
CMD net user
Expected Result

Windows displays the local user accounts configured on the computer.

03

Inspect a User Account

1 Choose a username

First run:

CMD net user
2 Inspect the account
CMD Example net user YOUR_USERNAME
Expected Result

Windows displays information associated with the selected local user account.

04

List Local Groups

1 Run the command
CMD net localgroup
Expected Result

Windows displays the local groups available on the system.

05

Check Administrators Group

1 Run the command
CMD net localgroup administrators
Expected Result

Windows displays the members of the local Administrators group.

PS

Inspect Users with PowerShell

1 Open PowerShell

Open PowerShell from the Windows Start menu.

2 List local users
PowerShell Get-LocalUser
G

Inspect Local Groups with PowerShell

1 List local groups
PowerShell Get-LocalGroup
2 Check Administrators members
PowerShell Get-LocalGroupMember -Group "Administrators"
Expected Result

PowerShell displays the accounts that belong to the local Administrators group.

✓

Lab Verification Checklist

  • I identified the current Windows user.
  • I listed local Windows users.
  • I inspected a user account.
  • I listed local groups.
  • I checked the Administrators group.
  • I used PowerShell to list local users.
  • I used PowerShell to list local groups.
  • I checked group membership using PowerShell.
🔐

Cybersecurity Connection

In cybersecurity, users and groups are important because excessive privileges can increase the impact of a security incident. Security professionals therefore examine account privileges, group membership and unnecessary accounts during system security assessments.
