Windows PowerShell Lab 04

Practice essential PowerShell commands for navigating directories, creating files and folders, viewing processes, checking services and collecting basic Windows system information.

Lab Objective

In this lab, you will use PowerShell to perform basic system administration tasks and understand how PowerShell commands can be used for Windows system analysis.

Directory Navigation
File Management
Processes

✓

Requirements

  • Windows 10 or Windows 11.
  • PowerShell available on the system.
  • Basic knowledge of Windows file system.
  • No additional software is required.
01

Step 1 — Open PowerShell

1
Open PowerShell

Open the Windows Start menu and search for PowerShell. Open PowerShell normally.

Expected Result

A PowerShell terminal window should open.

02

Step 2 — Check Current Location

Use Get-Location to display your current directory.

PowerShell Get-Location
Expected Result

PowerShell displays the current working directory.

03

Step 3 — List Files and Folders

Use Get-ChildItem to view files and folders.

PowerShell Get-ChildItem
Expected Result

A list of files and directories in the current location should appear.

04

Step 4 — Create a Lab Directory

Create a folder named CyberNexaLab.

PowerShell New-Item -ItemType Directory CyberNexaLab
Expected Result

A new folder named CyberNexaLab should be created.

05

Step 5 — Enter the Lab Directory

Move into the newly created directory.

PowerShell Set-Location CyberNexaLab
06

Step 6 — Create a File

Create a text file named security.txt.

PowerShell New-Item security.txt
Expected Result

A new security.txt file should appear in the directory.

07

Step 7 — View Running Processes

Use Get-Process to display currently running processes.

PowerShell Get-Process
Security Relevance

Process information can help security professionals understand what programs are currently running on a Windows system.

08

Step 8 — View Windows Services

Use Get-Service to display Windows services.

PowerShell Get-Service
Security Relevance

Services are important because they provide background functionality to Windows and installed applications.

09

Step 9 — Collect System Information

Use Get-ComputerInfo to view system information.

PowerShell Get-ComputerInfo
10

Step 10 — Use PowerShell Help

Use the built-in help system to learn about a command.

PowerShell Get-Help Get-Process
Expected Result

PowerShell displays help information for Get-Process.

🧪

Mini Practical Task

Complete the following tasks without copying the commands from the previous steps.

Cybersecurity Connection

PowerShell knowledge is useful for cybersecurity because security analysts may need to inspect processes, services, system information and other Windows components during system analysis and incident investigation.
