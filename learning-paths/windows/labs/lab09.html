Windows Firewall Lab 09

Learn how to inspect Windows Firewall profiles, open the Advanced Firewall console, examine firewall rules and safely create and remove a test firewall rule on your own Windows system.

Beginner
Defensive Security
Windows
PowerShell
🎯

Lab Objective

In this lab you will inspect the Windows Firewall configuration and practice creating a temporary local firewall rule for learning purposes.

  • Open Windows Firewall with Advanced Security.
  • Check the current firewall profiles.
  • View existing firewall rules.
  • Create a temporary test rule.
  • Verify the rule.
  • Remove the test rule after the lab.
01

Open Windows Firewall

1

Open Run

Press:

Keyboard Windows + R
2

Open Advanced Firewall

Enter the following command:

Run wf.msc
Expected Result:
Windows Defender Firewall with Advanced Security should open.
02

Check Firewall Profiles

Open PowerShell as Administrator and run:

PowerShell Get-NetFirewallProfile
Look For:
Domain, Private and Public profiles and their enabled status.
03

Check Firewall Status

Run the following command:

PowerShell Get-NetFirewallProfile | Select-Object Name, Enabled
Expected Information:
The command displays each firewall profile and whether Windows Firewall is enabled for that profile.
04

View Firewall Rules

Use PowerShell to display firewall rules:

PowerShell Get-NetFirewallRule
Learning Point:
Windows contains many predefined firewall rules. Each rule can have properties such as direction, action, profile and enabled status.
05

View Enabled Rules

To display enabled firewall rules, run:

PowerShell Get-NetFirewallRule | Where-Object Enabled -eq "True"
Expected Result:
PowerShell displays firewall rules that are currently enabled.
06

Create a Temporary Test Rule

For this controlled local lab, create a temporary inbound rule that blocks TCP port 5555.

PowerShell — Administrator New-NetFirewallRule -DisplayName "CyberNexa-Lab-Test-5555" -Direction Inbound -Protocol TCP -LocalPort 5555 -Action Block
This rule is only a learning example. Port 5555 is used here as a test port. Do not use this procedure to interfere with systems you do not own or administer.
07

Verify the Test Rule

Search for the rule that you created:

PowerShell Get-NetFirewallRule -DisplayName "CyberNexa-Lab-Test-5555"
Expected Result:
The rule should appear with its configured name, direction and action.
08

Remove the Test Rule

After completing the lab, remove the temporary rule.

PowerShell — Administrator Remove-NetFirewallRule -DisplayName "CyberNexa-Lab-Test-5555"
Expected Result:
The temporary CyberNexa lab rule should no longer exist.
09

Verify Rule Removal

PowerShell Get-NetFirewallRule -DisplayName "CyberNexa-Lab-Test-5555"
Expected Result:
The temporary test rule should no longer be listed.
