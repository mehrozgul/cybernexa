System Hardening Lab 13

Practice basic Windows system-hardening tasks in a controlled environment. The goal is to review security settings, accounts, services, updates, firewall and logging.

Lab 13
Beginner
Defensive Security
Windows
🎯

Lab Objective

In this lab you will perform a basic Windows hardening review. You will inspect the current system configuration and identify security improvements.

Expected Learning By the end of this lab, you should understand how common Windows security controls contribute to system hardening.
01

Check Current User

Open Command Prompt and identify the currently logged-in user.

CMD whoami
Expected Result Windows displays the current user account.
02

Review System Information

Check basic information about the Windows system.

CMD systeminfo
Observe Review Windows version, installation information, memory and other system details.
03

Review Running Services

Use PowerShell to view Windows services.

PowerShell Get-Service
Security Check Identify services that are running and determine whether unnecessary services exist. Do not disable a service unless its purpose is understood.
04

Review Running Processes

Check currently running processes.

PowerShell Get-Process
Observe Review the processes and identify applications or processes that you recognize. Unexpected processes should be investigated rather than immediately terminated.
05

Check Windows Firewall

Open Windows Firewall settings.

Windows Windows Security → Firewall & network protection
Check Verify that the firewall is enabled for the appropriate network profiles.
06

Review Windows Security

Open Windows Security and review the current protection status.

Windows Start → Windows Security

Virus & Threat Protection

Review the current antivirus protection status.

Firewall & Network Protection

Review firewall status and network profiles.

07

Check Windows Update

Review whether Windows has pending updates.

Windows Settings → Windows Update
Hardening Principle Keeping the operating system updated helps reduce exposure to known security vulnerabilities.
08

Review Local Accounts

Review local user accounts on the Windows system.

PowerShell Get-LocalUser
Security Check Identify accounts that are required and accounts that may no longer be needed. Do not delete accounts without understanding their purpose.
09

Review Administrator Membership

Check members of the local Administrators group.

CMD net localgroup Administrators
Principle Administrative privileges should be limited to users who require them.
10

Review Security Logs

Open Event Viewer and review the Security log.

Windows Event Viewer → Windows Logs → Security
Observe Review recent authentication and security-related events and note the Event IDs displayed by Windows.
11

Review Network Configuration

Check the current network configuration.

CMD ipconfig /all
Observe Review network adapters, IP addresses, DNS servers and other configuration information.
✓

Final Hardening Checklist

  • Current user account identified.
  • Windows system information reviewed.
  • Running services reviewed.
  • Running processes reviewed.
  • Windows Firewall status checked.
  • Windows Security status reviewed.
  • Windows Update status checked.
  • Local accounts reviewed.
  • Administrator group reviewed.
  • Security logs reviewed.
  • Network configuration reviewed.
✓

Lab Completed

What You Learned You practiced the basic Windows system-hardening workflow: reviewing accounts, services, processes, firewall, security protection, updates, logs and network configuration.
