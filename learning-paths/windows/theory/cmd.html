What is Command Prompt?

Simple Definition Command Prompt (CMD) is a command-line interface included with Windows that allows users to interact with the operating system by entering text commands.
?

Why Learn CMD?

CMD is useful for system administration, troubleshooting, file management and basic security investigation. Cybersecurity professionals often use command-line tools to inspect systems and network configurations.

How to Open Command Prompt

Windows provides several simple ways to open Command Prompt.

Start Menu

Open the Start menu, search for Command Prompt and launch it.

Run Dialog

Press Windows + R, type cmd and press Enter.

Terminal

Windows Terminal can also be used to open a Command Prompt session.

Administrator CMD

Some administrative operations require Command Prompt to be launched with elevated privileges.

File and Directory Navigation

CMD provides commands for moving through directories and viewing files.

dir

Displays files and folders in the current directory.

cd

Changes the current directory.

cd ..

Moves to the parent directory.

cd \

Moves to the root of the current drive.

tree

Displays a graphical representation of directories.

cls

Clears the Command Prompt screen.

F

File and Folder Management

CMD can be used to create, copy, move and remove files and directories.

mkdir

Creates a new directory.

rmdir

Removes a directory.

copy

Copies files from one location to another.

move

Moves files or directories.

del

Deletes files.

ren

Renames a file or directory.

U

User and Account Information

CMD provides commands that can help identify the current user and inspect local account information.

whoami

Displays the currently logged-in user.

hostname

Displays the computer name.

whoami /user

Displays information about the current user account.

net user

Displays local user accounts.

N

Basic Network Commands

Network-related CMD commands are important for troubleshooting and basic cybersecurity analysis.

ipconfig

Displays basic IP configuration.

ipconfig /all

Displays detailed network configuration.

ping

Tests connectivity to a destination.

tracert

Shows the path packets take to a destination.

nslookup

Queries DNS information.

arp -a

Displays the local ARP cache.

P

Process and System Information

These commands help identify running processes and gather information about the Windows system.

tasklist

Displays currently running processes.

taskkill

Terminates a specified process.

systeminfo

Displays detailed system information.

ver

Displays the Windows version.

CMD vs Graphical Interface

CMD

  • Uses text commands.
  • Efficient for repetitive tasks.
  • Useful for automation and troubleshooting.
  • Requires knowledge of commands.

GUI

  • Uses graphical elements.
  • Easier for beginners for many tasks.
  • Provides visual interaction.
  • Some administrative tasks may be slower manually.
!

Security Note

Important Some CMD commands can modify or delete files, terminate processes or change system configuration. Always understand a command before executing it, especially when using an elevated Command Prompt.

Quick Summary

  • CMD is a command-line interface included with Windows.
  • Commands allow users to interact with the operating system.
  • dir and cd are basic directory navigation commands.
  • mkdir, copy, move, del and ren manage files and folders.
  • whoami and hostname provide basic identity information.
  • ipconfig, ping, tracert and nslookup are useful network commands.
  • tasklist and taskkill are used for process management.
  • systeminfo provides detailed Windows system information.
  • CMD knowledge is useful for troubleshooting and cybersecurity.
  • Commands should be executed carefully, especially with administrative privileges.
