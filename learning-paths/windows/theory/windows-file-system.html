What is a File System?

Simple Definition A file system is the method an operating system uses to organize, store, name and access files and directories on a storage device.
W

Windows File System

Windows uses file systems to organize data on storage devices. NTFS is the primary file system commonly associated with modern Windows installations.

Files

Files contain data such as documents, images, programs and configuration information.

Directories

Directories, commonly called folders, organize files and other directories.

Drives

Drives provide storage locations such as C:, D: or removable storage.

Paths

A path identifies the location of a file or directory within the file system.

C:

Windows Drives

Windows identifies storage volumes using drive letters. The system drive is commonly represented as C:.

C: System Drive
D: Additional Drive
E: Removable Media
USB Storage
/

Windows Paths

A Windows path specifies where a file or folder is located. Windows commonly uses a drive letter followed by folders separated with backslashes.

Example Windows Path C:\Users\Student\Documents
C:\Users\Student\Downloads
C:\Windows\System32

Important Windows Folders

C:\Windows

Contains important operating-system files and Windows components.

C:\Users

Contains user profiles and user-specific folders.

Program Files

Common location for installed applications.

System32

Contains many important Windows system executables and libraries.

U

User Folders

Each Windows user normally has a profile directory containing personal files and configuration data.

Desktop
Documents
Downloads
Pictures

N

NTFS

Simple Definition NTFS (New Technology File System) is a file system used by Windows that provides features such as file organization, permissions, metadata and other file-management capabilities.

Permissions

NTFS supports access permissions that help control who can access files.

Metadata

File-system metadata stores information about files and directories.

Reliability

NTFS includes mechanisms designed to improve file-system reliability.

Security

NTFS permissions are important when managing Windows system security.

.X

File Extensions

File extensions indicate the type or format of a file and help Windows determine which application can open it.

.txt

Plain text file.

.exe

Executable program file.

.dll

Dynamic-link library used by programs.

.log

Common extension for log files.

.bat

Windows batch script.

.ps1

PowerShell script file.

>

Basic File System Commands

CMD provides several commands for navigating and managing files and directories.

dir

Lists files and folders in the current directory.

cd

Changes the current directory.

mkdir

Creates a new directory.

rmdir

Removes a directory when permitted.

copy

Copies files from one location to another.

move

Moves files to another location.

PS

PowerShell File Commands

PowerShell Get-ChildItem
Set-Location
New-Item
Copy-Item
Move-Item

PowerShell provides commandlets that can be used to inspect and manage files and directories.

File System Security

Understanding the Windows file system is important for cybersecurity because attackers and defenders often interact with files, directories, permissions and system locations.

Sensitive Files

Important configuration and system files should be protected from unauthorized access.

Permissions

Incorrect permissions can allow unauthorized users to access or modify data.

Logs

Log files can provide useful information during security investigation.

Executables

Executable files should be treated carefully because malicious programs can execute code.

Quick Summary

  • A file system organizes and manages files and directories.
  • Windows commonly uses NTFS for its main storage volumes.
  • Drives are identified using letters such as C:.
  • Windows paths identify the location of files and folders.
  • C:\Windows contains important operating-system files.
  • C:\Users contains user profiles and personal folders.
  • File extensions indicate common file types.
  • CMD and PowerShell can be used to manage files and folders.
  • NTFS supports file permissions and security features.
  • File-system knowledge is important for Windows cybersecurity.
