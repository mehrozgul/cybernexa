What is PowerShell?

Simple Definition PowerShell is a command-line shell and scripting environment developed by Microsoft. It is designed for system administration, automation and configuration management.
?

Why is PowerShell Important?

PowerShell allows administrators and security professionals to manage Windows systems efficiently through commands and scripts.

Automation

Repeated administrative tasks can be automated using PowerShell scripts.

System Management

PowerShell can be used to manage processes, services, files, users and system configuration.

Security

Security professionals can use PowerShell to inspect systems, processes, services and logs.

Administration

Administrators can manage Windows environments efficiently from the command line.

PowerShell vs CMD

CMD

  • Traditional Windows command shell.
  • Mainly designed for command execution.
  • Common commands include dir, cd and ipconfig.
  • Limited scripting capabilities compared with PowerShell.

PowerShell

  • Modern command-line shell and scripting environment.
  • Designed for administration and automation.
  • Uses cmdlets such as Get-Process and Get-Service.
  • Supports powerful scripting and object-based command processing.

Opening PowerShell

PowerShell can be opened from the Start menu by searching for PowerShell. On modern Windows systems, Windows Terminal can also provide a PowerShell environment.

Essential PowerShell Commands

These commands provide a foundation for working with PowerShell.

Get-Location

Displays the current working directory.

Get-ChildItem

Lists files and directories.

Set-Location

Changes the current location.

New-Item

Creates a new file or directory.

Get-Process

Displays running processes.

Get-Service

Displays Windows services.

Get-ComputerInfo

Displays detailed computer information.

Get-Date

Displays the current date and time.

Clear-Host

Clears the PowerShell console.

Get-Help

Displays help information for commands.

PowerShell cmdlets commonly follow a Verb-Noun naming convention. The verb describes the action and the noun describes the object.

PowerShell Variables

Variables are used to store values in PowerShell. PowerShell variables begin with the dollar sign $.

Example $name = "CyberNexa"
$number = 10
$name

PowerShell Pipeline

Simple Definition The PowerShell pipeline uses the pipe symbol | to pass the output of one command to another command.
Example Get-Process | Where-Object {$_.CPU -gt 100}
