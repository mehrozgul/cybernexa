What is Active Directory?

Simple Definition Active Directory Domain Services (AD DS) is a Microsoft directory service used to centrally manage identities, computers, groups and access within a Windows domain.
DC

What is a Domain Controller?

A Domain Controller (DC) is a Windows Server system that runs Active Directory Domain Services and authenticates users and computers in a domain.

A domain is a logical environment in which users, computers and other resources can be centrally managed. Domain members can use centralized authentication and security policies.

Organizational Units (OUs)

An Organizational Unit is a container inside Active Directory that can be used to organize users, computers and other directory objects.

Users OU

Can be used to organize user accounts according to departments or organizational structure.

Computers OU

Can be used to organize domain computers and apply appropriate management policies.

IT OU

Can contain accounts and computers associated with an IT department.

HR OU

Can contain accounts and computers associated with an HR department.

U

Active Directory Users

User accounts represent individual identities in an Active Directory environment. They can be used for authentication and access to domain resources.

PowerShell Example Get-ADUser -Filter *

The command is available when the Active Directory PowerShell module is installed.

G

Active Directory Groups

Groups allow administrators to organize users and assign permissions more efficiently. Instead of assigning access individually to every user, permissions can often be assigned to groups.

Security Group

  • Used for access control.
  • Can contain users and other objects.
  • Can be assigned permissions to resources.

Distribution Group

  • Primarily used for email distribution.
  • Not normally used for assigning permissions.
  • Useful for communication purposes.
PC

Domain Computers

Computers can be joined to an Active Directory domain. Once joined, the computer can participate in centralized authentication, management and security policies.

Authentication in Active Directory

Authentication is the process of verifying the identity of a user or computer. In a domain environment, the Domain Controller participates in centralized authentication.

Group Policy Basics

Group Policy provides centralized configuration and management of Windows users and computers in a domain.

Password Policies

Organizations can configure requirements related to passwords.

Security Settings

Administrators can centrally configure selected Windows security settings.

User Configuration

Policies can control selected user environment settings.

Computer Configuration

Policies can apply configuration to domain computers.

DNS

Why DNS Matters to Active Directory

DNS is an important dependency for Active Directory. Domain clients use DNS to locate domain services and communicate with domain controllers.

Important Concept In an Active Directory environment, correct DNS configuration is essential for reliable domain operation and service discovery.

Active Directory and Cybersecurity

Active Directory is an important cybersecurity topic because enterprise Windows environments commonly rely on centralized identity and access management. Security teams need to understand accounts, groups, permissions, authentication, policies and domain infrastructure.

Quick Summary

  • Active Directory is Microsoft's directory service for centralized identity and resource management.
  • Active Directory Domain Services is commonly abbreviated as AD DS.
  • A Domain Controller provides important domain services including authentication.
  • A domain provides a logical environment for centrally managed users and computers.
  • Organizational Units help organize directory objects.
  • User accounts represent identities in the domain.
  • Groups simplify centralized access management.
  • Group Policy provides centralized configuration and management.
  • DNS is an important dependency for Active Directory.
  • Understanding Active Directory is important for Windows administration and cybersecurity.
