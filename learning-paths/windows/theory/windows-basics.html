What is Windows?

Simple Definition Windows is a family of operating systems developed by Microsoft. It provides an environment for running applications, managing hardware, files, users and system resources.
OS

Windows as an Operating System

An operating system acts as an interface between the user, applications and computer hardware. Windows manages system resources and provides services required by applications.

Core Windows Components

Windows contains several major components that work together to provide a complete operating environment.

Kernel

The kernel is a core part of the operating system responsible for managing hardware, memory, processes and system operations.

File System

Windows uses file systems such as NTFS to organize, store and manage files and directories.

Services

Windows services are background processes that provide specific system or application functionality.

Registry

The Windows Registry stores configuration information used by the operating system and installed applications.

Windows File System

The Windows file system organizes data into drives, folders and files. NTFS is commonly used on modern Windows systems.

Windows Users and Accounts

Windows uses user accounts to identify users and control access to system resources.

Administrator

An administrator account has elevated privileges and can perform many system configuration tasks.

Standard User

A standard user normally has fewer privileges and is restricted from certain administrative operations.

CMD vs PowerShell

Command Prompt

  • Traditional Windows command shell
  • Simple command-line operations
  • Commonly used for basic troubleshooting
  • Uses commands such as dir and ipconfig

PowerShell

  • Modern Windows shell and scripting environment
  • Designed for automation and administration
  • Provides many system-management commands
  • Uses cmdlets such as Get-Process
C

Essential Windows Commands

These commands are useful for beginners when working with Windows through CMD.

whoami

Displays the current username.

dir

Lists files and directories.

cd

Changes the current directory.

mkdir

Creates a directory.

cls

Clears the Command Prompt screen.

ipconfig

Displays IP configuration information.

ping

Tests network connectivity to a destination.

tasklist

Displays currently running processes.

systeminfo

Displays detailed system information.

hostname

Displays the computer's hostname.

$

Simple Command Workflow

dir

This simple workflow demonstrates checking the current user, moving to a directory, creating a new folder, entering it and viewing its contents.

Windows Task Manager

Task Manager is a Windows utility used to view running applications, processes and system resource usage.

Processes

Shows applications and background processes currently running.

Performance

Displays information about CPU, memory, disk and network usage.

Startup Apps

Shows applications configured to start when Windows starts.

Users

Shows users currently signed in to the system.

S

Windows Services

Windows services are background processes that provide operating-system or application-related functionality.

PowerShell Get-Service

Understanding services is important for system administration and later Windows security studies.
