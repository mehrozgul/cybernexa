What is Windows Firewall?

Simple Definition Windows Firewall is a host-based firewall included with Windows that helps control network traffic entering or leaving a computer according to configured rules.
🔐

Why is Windows Firewall Important?

A firewall helps reduce unwanted network access to a computer. It can allow legitimate traffic while blocking traffic that does not match configured security rules.

Windows Firewall Profiles

Windows uses different network profiles to apply appropriate firewall settings depending on the type of network connection.

Domain

Used when a Windows computer is connected to an organization-managed domain network.

Private

Normally used for trusted networks such as a home or controlled private network.

Public

Used for less-trusted networks such as public Wi-Fi environments.

Firewall Rules

Firewall rules define how Windows Firewall should handle particular network traffic. Rules can specify applications, ports, protocols, addresses and network profiles.

Allow Rule

Allows traffic that matches the rule conditions.

Block Rule

Blocks traffic that matches the configured conditions.

Inbound Rule

Controls incoming network traffic.

Outbound Rule

Controls outgoing network traffic.

#

Firewall and Network Ports

Firewall rules can be associated with network protocols and ports. Ports identify logical communication endpoints used by network services.

Examples TCP 80 → HTTP
TCP 443 → HTTPS
TCP 22 → SSH
TCP 3389 → RDP

Managing Windows Firewall

Windows Firewall can be managed through graphical tools and PowerShell. The advanced firewall console provides detailed control over inbound and outbound rules.

Run wf.msc

The command opens Windows Defender Firewall with Advanced Security.

PS

Windows Firewall with PowerShell

PowerShell provides commands for viewing and managing Windows Firewall configuration.

PowerShell Get-NetFirewallProfile
Get-NetFirewallRule
Get-NetFirewallRule | Where-Object Enabled -eq "True"

Why Windows Firewall Matters in Cybersecurity

Understanding Windows Firewall is important for cybersecurity because endpoint systems need mechanisms to control network communication. Firewall knowledge is useful for system administration, defensive security and SOC investigations.

Quick Summary

  • Windows Firewall is a host-based firewall.
  • It controls network traffic according to rules.
  • Windows provides Domain, Private and Public profiles.
  • Inbound traffic enters the Windows system.
  • Outbound traffic leaves the Windows system.
  • Firewall rules can allow or block traffic.
  • Rules can use applications, ports, protocols and addresses.
  • The Advanced Security console can be opened using wf.msc.
  • PowerShell can be used to inspect firewall configuration.
  • Firewall knowledge is important for endpoint security.
