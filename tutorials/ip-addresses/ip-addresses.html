Understanding IP Addresses

Learn how IP addresses identify devices on networks, how IPv4 addresses work, the difference between public and private addresses, subnet masks, CIDR, gateways, DNS, NAT and the role of IP addressing in cybersecurity.

What is an IP Address?

An IP address is a logical address used to identify a device or network interface on an IP network. It allows network traffic to identify where data should come from and where it should go.

In simple words, an IP address works like a network address for a device. When one device communicates with another device, IP addressing helps the network determine the destination.

Remember: MAC addresses identify network interfaces at the local data-link level, while IP addresses provide logical addressing used for routing between networks.

IPv4 Address

IPv4 is the most commonly encountered IP addressing system in introductory networking. An IPv4 address contains 32 bits.

These 32 bits are normally represented as four decimal octets separated by dots.

192.168.1.10

Each octet can contain a value from 0 to 255.

192 . 168 . 1 . 10 ↑ ↑ ↑ ↑ octet octet octet octet

IPv4 Binary Representation

Computers ultimately process IP addresses as binary values. Every IPv4 address contains 32 binary bits.

192.168.1.10 192 = 11000000 168 = 10101000 1 = 00000001 10 = 00001010 Complete: 11000000.10101000.00000001.00001010

Understanding binary becomes particularly important when learning subnetting and CIDR.

Private vs Public IP Addresses

Private IP

Used inside local networks such as home, university and office networks.

Private addresses are not directly routable across the public Internet.

Public IP

Used for communication across the public Internet.

A public IP may identify a router or other Internet-connected service from outside the local network.

Common Private IPv4 Ranges

Range Address Block
10.0.0.0/8 10.0.0.0 – 10.255.255.255
172.16.0.0/12 172.16.0.0 – 172.31.255.255
192.168.0.0/16 192.168.0.0 – 192.168.255.255

Loopback Address

The IPv4 loopback range is used by a computer to communicate with itself.

127.0.0.1

The name localhost commonly refers to the local machine.

ping 127.0.0.1

This can be useful when testing local networking components without communicating with another host.

Subnet Mask

A subnet mask helps determine which portion of an IPv4 address represents the network and which portion represents hosts within that network.

IP Address : 192.168.1.10 Mask : 255.255.255.0 CIDR : /24

In a typical /24 network, the first 24 bits represent the network portion.

CIDR Notation

CIDR stands for Classless Inter-Domain Routing. CIDR notation represents an IP network together with the number of network-prefix bits.

192.168.1.0/24

The /24 indicates that the first 24 bits form the network prefix.

/24

Common small LAN network.

/16

Larger network prefix.

/8

Very large IPv4 address block.

/32

Represents one IPv4 address.

Default Gateway

A default gateway is normally the router that a host uses when it needs to communicate with destinations outside its local network.

Computer: 192.168.1.20 Default Gateway: 192.168.1.1

If a computer wants to reach a remote network, it typically sends the traffic toward its configured gateway.

DNS and IP Addresses

Humans usually prefer domain names such as:

example.com

Networks communicate using IP addresses. DNS translates domain names into IP addresses so clients can locate services.

Domain Name ↓ DNS ↓ IP Address ↓ Network Connection

NAT and Private IP Addresses

Network Address Translation, or NAT, allows private addresses inside a network to communicate through public addressing at a router or gateway.

Laptop 192.168.1.20 ↓ Router / NAT ↓ Public Internet

NAT is commonly used in home and organizational networks where multiple internal devices share Internet connectivity.

Finding Your IP Address

Windows

ipconfig

Linux

ip addr

Linux — concise interface information

ip -br addr

IP Addresses in Cybersecurity

IP addressing is fundamental to security monitoring and network analysis.

  • Security logs often contain source and destination IPs.
  • Firewalls use IP addresses in filtering rules.
  • Network monitoring systems observe communication between IP addresses.
  • Incident responders investigate suspicious hosts using IP information.
  • Network scanners identify hosts and services within authorized environments.

Example: Reading a Security Log

2026-09-26 10:20 SRC=192.168.1.20 DST=192.168.1.1 ACTION=ALLOW PORT=443

From this record we can identify a source IP, destination IP, action and destination port.

Common Mistakes

  • Assuming every 192.168.x.x address is publicly reachable.
  • Confusing an IP address with a MAC address.
  • Treating a private IP as a unique Internet-wide address.
  • Ignoring subnet masks when analyzing network membership.
  • Assuming an IP address permanently identifies a person.

Key Points to Remember

  • IPv4 uses 32 bits.
  • Each IPv4 octet ranges from 0 to 255.
  • Private IP addresses are used inside local networks.
  • Public IP addresses are used for Internet connectivity.
  • 127.0.0.1 is the IPv4 loopback address.
  • Subnet masks identify network and host portions.
  • CIDR expresses the network prefix length.
  • Routers commonly act as default gateways.
  • DNS maps domain names to IP addresses.
  • NAT commonly translates private addressing for Internet access.
