Lab Objective

In this practical lab, you will work with common IP addressing concepts and commands used during basic network troubleshooting and cybersecurity analysis.

  • Find your IPv4 configuration on Windows.
  • Identify a private IPv4 address.
  • Test the IPv4 loopback address.
  • Understand subnet mask and CIDR notation.
  • Identify the default gateway.
  • View IP configuration on Linux.
  • Read source and destination IPs from a security log.

Requirements

Windows

Windows PC with Command Prompt available.

Linux

Linux system or virtual machine with terminal access.

Safety: All commands in this lab are basic local-information and connectivity commands. Only perform network testing on systems and networks you are authorized to use.

Task 01 — Find Your IPv4 Address

1

Windows: Use ipconfig

Open Command Prompt on Windows. Type the following command and press Enter.

COMMAND 
ipconfig
EXAMPLE OUTPUT 
Ethernet adapter Ethernet:

IPv4 Address. . . . . . : 192.168.1.20
Subnet Mask . . . . . . : 255.255.255.0
Default Gateway . . . . : 192.168.1.1

Find these three values in your own output:

  • IPv4 Address
  • Subnet Mask
  • Default Gateway
Why this matters: These values help you understand the network configuration of your computer.

Task 02 — Identify a Private IP Address

2

Recognize Private IPv4 Ranges

Compare the IP address you found in Task 01 with the standard private IPv4 ranges.

Private Range Address Block
10.0.0.0/8 10.0.0.0 – 10.255.255.255
172.16.0.0/12 172.16.0.0 – 172.31.255.255
192.168.0.0/16 192.168.0.0 – 192.168.255.255

Practice

Determine whether the following addresses belong to private IPv4 ranges:

ADDRESSES 
192.168.1.20
10.10.10.5
172.20.5.10
Remember: Private addresses are commonly used inside local networks and are not directly routable across the public Internet.

Task 03 — Test the Loopback Address

3

Ping 127.0.0.1

The IPv4 loopback address allows the computer to communicate with itself.

Open Command Prompt and run:

COMMAND 
ping 127.0.0.1
EXPECTED RESULT 
Reply from 127.0.0.1:
bytes=32 time<1ms TTL=128

Reply from 127.0.0.1:
bytes=32 time<1ms TTL=128

A successful response indicates that the local TCP/IP networking stack can respond to the loopback request.

Important: 127.0.0.1 refers to the local machine. It does not represent another computer on your network.

Task 04 — Understand Subnet Mask and CIDR

4

Read the Network Configuration

Use the following example:

EXAMPLE 
IP Address : 192.168.1.10
Subnet Mask: 255.255.255.0
CIDR       : /24

IP Address

192.168.1.10 identifies the host interface in the example network.

Subnet Mask

255.255.255.0 separates the network portion from the host portion.

CIDR

/24 means the first 24 bits represent the network prefix.

Network

The example belongs to the 192.168.1.0/24 network.

Quick Practice

What is the CIDR notation for:

255.255.255.0

Answer: /24

Task 05 — Identify the Default Gateway

5

Find Your Gateway

Run ipconfig again and locate the Default Gateway value.

COMMAND 
ipconfig
EXAMPLE 
IPv4 Address. . . . . . : 192.168.1.20
Subnet Mask . . . . . . : 255.255.255.0
Default Gateway . . . . : 192.168.1.1

In this example, 192.168.1.1 is the default gateway.

Computer 192.168.1.20 ↓ Default Gateway 192.168.1.1 ↓ Other Network / Internet
Concept: When a host needs to communicate with a destination outside its local network, traffic is normally sent toward its configured default gateway.

Task 06 — Find IP Information on Linux

6

Linux IP Commands

Open a Linux terminal and run the following command:

COMMAND 1 
ip addr

This displays IP addresses and interface information.

COMMAND 2 — CONCISE OUTPUT 
ip -br addr
EXAMPLE 
lo       UNKNOWN  127.0.0.1/8
eth0     UP       192.168.1.20/24

In the example above:

  • lo is the loopback interface.
  • 127.0.0.1 is the loopback address.
  • 192.168.1.20/24 is an example IPv4 address with a /24 prefix.

Task 07 — Read a Security Log

7

Analyze Source and Destination IPs

Security logs commonly contain source and destination IP information.

SAMPLE SECURITY LOG 
2026-09-26 10:20
SRC=192.168.1.20
DST=192.168.1.1
ACTION=ALLOW
PORT=443

Identify Each Field

Field Meaning Value
SRC Source IP 192.168.1.20
DST Destination IP 192.168.1.1
ACTION Traffic action ALLOW
PORT Destination port 443
Cybersecurity connection: Security analysts use source and destination IP information when reviewing network activity, firewall logs and security events.

Bonus Concept — DNS and IP Addresses

DNS allows users to work with domain names while network communication ultimately uses IP addressing.

Domain Name ↓ DNS ↓ IP Address ↓ Network Connection
Example: A user may enter a domain name in a browser. DNS can provide the IP address associated with the requested service.

Bonus Concept — NAT

Network Address Translation allows private addressing inside a network to communicate through public addressing at a router or gateway.

Laptop 192.168.1.20 ↓ Router / NAT ↓ Public Internet

NAT is commonly used when multiple internal devices share Internet connectivity.

Key Points to Remember

  • IPv4 uses 32 bits.
  • Each IPv4 octet ranges from 0 to 255.
  • Private IP addresses are used inside local networks.
  • 127.0.0.1 is the IPv4 loopback address.
  • A subnet mask identifies network and host portions.
  • CIDR expresses the network prefix length.
  • A router commonly acts as a default gateway.
  • DNS maps domain names to IP addresses.
  • NAT commonly translates private addressing for Internet connectivity.
  • IP addresses are important in network monitoring and security analysis.
