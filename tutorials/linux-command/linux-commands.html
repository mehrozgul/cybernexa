Essential Linux Commands

Build a strong Linux command-line foundation for cybersecurity, system administration, troubleshooting, file analysis, process monitoring and network security.

Why Linux Matters in Cybersecurity

Linux is widely used in servers, security tools, network infrastructure, cloud systems and cybersecurity laboratories.

Security professionals frequently use the command line to inspect files, investigate processes, examine network connections, analyze logs and automate repetitive tasks.

Important: Do not try to memorize every Linux command. Learn what a command does, understand its options and practice it repeatedly in a safe Linux environment.

1. pwd — Print Working Directory

The pwd command displays the directory in which you are currently working.

pwd
Linux Terminal
$ pwd /home/gul

This is useful because many commands operate relative to your current directory.

2. ls — List Files and Directories

ls displays files and directories in the current location.

ls

Detailed listing

ls -l

Show hidden files

ls -la

Security analysts often inspect directories for configuration files, logs and unexpected files.

3. cd — Change Directory

The cd command changes the current working directory.

cd /var/log

Return to the parent directory:

cd ..

Return to the home directory:

cd ~

4. cat — Display File Contents

The cat command can display the contents of a text file.

cat security.log

This can be useful for quickly examining small configuration files or logs.

Security note: Do not blindly execute commands or scripts copied from untrusted sources just because you found them in a terminal example.

5. grep — Search Text

grep searches text for matching patterns. It is one of the most useful commands for log analysis.

grep "failed" security.log

Case-insensitive search:

grep -i "failed" security.log

Count matching lines:

grep -c "failed" security.log

6. find — Search for Files

The find command searches directories according to conditions such as filename, type or modification time.

find . -name "*.log"

Search for a specific configuration file:

find /etc -name "hosts"

In security work, file discovery can help locate logs, configuration files and other artifacts during authorized investigations.

7. whoami — Current User

whoami displays the username of the current user.

whoami
Example
$ whoami gul

8. id — User and Group Information

The id command displays user identity and group information.

id

This is important when understanding Linux permissions and access control.

9. chmod — File Permissions

Linux uses permissions to control who can read, write or execute files.

ls -l script.sh

A permission string may look like:

-rwxr-xr--

The permission categories are commonly represented for the owner, group and others.

Example

chmod u+x script.sh

This adds execute permission for the file owner.

10. ps — Process Information

ps displays information about running processes.

ps

A commonly used view is:

ps aux

Process information is useful during system troubleshooting and security investigations.

11. top — Live Process Monitoring

The top command provides a live view of running processes and resource usage.

top

It can help identify processes consuming unusually high CPU or memory resources.

12. ss — Network Connections

The ss command displays socket and network connection information.

ss -tuln

This can help identify listening TCP and UDP services on a Linux system.

13. ip — Network Configuration

The ip command is a modern Linux networking utility.

ip addr

Show a concise address view:

ip -br addr

View routing information:

ip route

14. curl — Network Requests

curl is commonly used to communicate with network services and HTTP endpoints.

curl https://example.com

Display only HTTP headers:

curl -I https://example.com

In authorized testing environments, curl is useful for understanding how web servers respond to requests.

15. wget — Retrieve Files

wget is commonly used to retrieve resources over supported network protocols.

wget https://example.com/file.txt

Always verify that downloaded files come from trusted sources before opening or executing them.

Linux Commands for Security Work

# Current user whoami # Network interfaces ip -br addr # Routing table ip route # Listening services ss -tuln # Running processes ps aux # Search a security log grep -i "failed" security.log # Find log files find . -name "*.log"

Practical Security Investigation Example

Imagine an analyst receives a Linux server and needs to perform a basic local inspection.

whoami pwd ip -br addr ip route ss -tuln ps aux

These commands provide information about the current user, working location, network interfaces, routes, listening services and running processes.

The analyst can then investigate relevant logs or configuration files using commands such as cat, grep and find.

Key Points to Remember

  • pwd → current directory
  • ls → list files
  • cd → change directory
  • cat → display file contents
  • grep → search text
  • find → find files
  • whoami → current user
  • id → user/group information
  • chmod → change permissions
  • ps → process information
  • top → live process monitoring
  • ss → network sockets/connections
  • ip → network configuration
  • curl → network/HTTP requests
  • wget → retrieve resources
