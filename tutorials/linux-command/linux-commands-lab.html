Essential Linux Commands Lab

Practice essential Linux commands for file management, navigation, user identification, permissions, process monitoring, network inspection, log analysis and basic cybersecurity investigation.

LEVEL Beginner
CATEGORY Linux
PLATFORM Linux / VM
TYPE Hands-on Lab
Lab Progress 0 / 10 Tasks

Lab Objectives

By completing this lab, you will practice the most important Linux commands introduced in the tutorial.

  • Navigate the Linux file system.
  • View files and directories.
  • Read text files and logs.
  • Search text with grep.
  • Find files with find.
  • Identify the current Linux user.
  • Understand user and group information.
  • Inspect file permissions.
  • Inspect running processes.
  • Inspect network configuration and connections.
Safety: Perform this lab only on your own Linux machine, virtual machine or another system where you have authorization. Do not modify systems you do not own or administer.

Task 01 — Find Your Current Directory

1

Use pwd

The pwd command displays the directory in which you are currently working.

COMMAND 
pwd
Linux Terminal
$ pwd /home/gul

Your result may be different because it depends on the username and current directory.

Task 02 — List Files and Directories

2

Use ls

The ls command displays files and directories in the current location.

BASIC LIST 
ls
DETAILED LIST 
ls -l
SHOW HIDDEN FILES 
ls -la
Security connection: Security analysts may inspect directories for configuration files, logs or unexpected files.

Task 03 — Navigate the File System

3

Use cd

The cd command changes the current working directory.

CHANGE DIRECTORY 
cd /var/log
GO TO PARENT DIRECTORY 
cd ..
GO TO HOME DIRECTORY 
cd ~
Practice: Run pwd after each cd command to verify your location.

Task 04 — Read a File

4

Use cat

Create a small practice file first. 

printf "Login successful\nLogin failed\nLogin failed\n" > security.log

Now display the file: 

cat security.log
Expected Example
$ cat security.log Login successful Login failed Login failed
Why useful? The cat command is useful for quickly viewing small text files and logs.

Task 05 — Search a Security Log

5

Use grep

Use grep to search for failed login messages. 

grep "failed" security.log

Perform a case-insensitive search: 

grep -i "failed" security.log

Count matching lines: 

grep -c "failed" security.log
Example
$ grep -c "failed" security.log 2
Cybersecurity connection: grep is frequently used during log analysis to find events matching a specific pattern.

Task 06 — Find Log Files

6

Use find

Search the current directory for log files. 

find . -name "*.log"

You can also search for a specific file: 

find /etc -name "hosts"
Important: When searching system directories, you may encounter permission-denied messages. That does not necessarily mean the command failed.

Task 07 — Identify the Current User

7

Use whoami and id

First identify your current username. 

whoami

Then display user and group information. 

id
Example
$ whoami gul $ id uid=1000(gul) gid=1000(gul) groups=1000(gul)
Security connection: User and group information helps analysts understand permissions and access control.

Task 08 — Inspect File Permissions

8

Use ls -l and chmod

Create a practice script: 

printf '#!/bin/bash\necho "CyberNexa Lab"\n' > script.sh

View its permissions: 

ls -l script.sh

Add execute permission for the owner: 

chmod u+x script.sh

Check the permissions again: 

ls -l script.sh
Remember: Linux permissions commonly control read, write and execute access for the owner, group and others.

Task 09 — Inspect Running Processes

9

Use ps and top

Display running processes: 

ps

Display a more detailed process list: 

ps aux

For live process monitoring: 

top
Cybersecurity connection: Process inspection can help identify unusual programs, resource usage and suspicious activity during an authorized investigation.
Exit top: Press q to leave the top interface.

Task 10 — Inspect Network Information

10

Use ip, ss and ip route

View network interfaces and IP addresses: 

ip addr

Use a concise format: 

ip -br addr

View the routing table: 

ip route

View listening TCP and UDP sockets: 

ss -tuln
Example
$ ip -br addr lo UNKNOWN 127.0.0.1/8 eth0 UP 192.168.1.20/24 $ ip route default via 192.168.1.1 dev eth0 $ ss -tuln Netid State Local Address:Port tcp LISTEN 0.0.0.0:22
Cybersecurity connection: Network interfaces, routes and listening services are important during authorized system inspection.

Bonus Task — curl

curl can communicate with HTTP and other network services. 

curl https://example.com

To display only HTTP headers: 

curl -I https://example.com
Important: Only send requests to systems and services you are authorized to access or test.

Bonus Task — wget

wget can retrieve resources from supported network locations. 

wget https://example.com/file.txt
Security note: Never download and execute files from untrusted sources. Verify the source before opening downloaded content.

Practical Security Investigation

Now perform a basic local inspection using several commands together. 

whoami
pwd
ip -br addr
ip route
ss -tuln
ps aux

What Information Did You Collect?

whoami

Current username.

pwd

Current working directory.

ip -br addr

Network interfaces and IP addresses.

ip route

Routing information.

ss -tuln

Listening TCP and UDP sockets.

ps aux

Running processes.

Investigation workflow: These commands give an analyst a basic picture of the local user's identity, filesystem location, network configuration, routes, listening services and running processes.

Key Points to Remember

  • pwd → current directory
  • ls → list files and directories
  • cd → change directory
  • cat → display file contents
  • grep → search text
  • find → search for files
  • whoami → current user
  • id → user and group information
  • chmod → change permissions
  • ps → process information
  • top → live process monitoring
  • ss → network sockets
  • ip → network configuration
  • curl → network/HTTP requests
  • wget → retrieve resources
